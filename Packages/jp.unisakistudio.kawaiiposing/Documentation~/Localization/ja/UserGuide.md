# 可愛いポーズツール — 使い方

可愛いポーズツールは、デスクトップと3点VR向けに85姿勢を収録しています。内訳は立ち15、中腰・椅子20、床座り17、仰向け寝17、うつ伏せ寝16です。

このガイドでは、導入、アバター設定、VRChat内の操作、ポーズ編集、更新、トラブルへの対処を説明します。購入したZIPの `START_HERE.html` から導入手順をすぐに開けます。

## はじめに

- VRChat Creator Companion（VCC）またはALCOMで作成・管理した、Unity 2022.3のVRChat **アバター** 用プロジェクトを使用してください。
- 必要パッケージは、VRChat Avatars SDK 3.10.4以上、Modular Avatar 1.xの1.15.1以上、NDMF 1.xの1.14.0以上です。
- Humanoidアバターのデスクトップモードと3点VR（ヘッドセットとコントローラー2個）向けです。フルボディトラッキング中の姿勢固定には対応していません。
- 導入・更新前に既存プロジェクトをバックアップし、Unityのコンパイルエラーを先に解消してください。
- インストーラーは商品と依存パッケージを各配布元からダウンロードするため、インターネット接続が必要です。アバターモデル、VRChat SDK、Modular Avatar、NDMFはこのZIPに含みません。

## 1. ライセンスと商品の導入

1. ZIP全体を、Unityプロジェクトの外にある通常のフォルダーへ展開します。
2. 対象のアバタープロジェクトをUnityで開き、**Assets > Import Package > Custom Package** から `Installer/KawaiiPosing_Installer.unitypackage` をインポートするか、ファイルをUnityで開きます。
3. インポートと導入の案内を読みます。ライセンスの確認画面には、登録する商品のライセンスが表示されます。確認画面の **言語…**（英語表示では **Language...**） でインストーラーの言語を変更できます。
4. ライセンス登録を確認します。商品が使う共通のゆにさきポーズシステムも対象です。その後インストーラー自身のファイルの削除を案内する場合がありますが、この整理で登録済みの商品ライセンスは削除されません。
5. パッケージ自動追加の確認を読みます。追加するパッケージ・配布元と、削除する旧ファイルやフォルダーが表示されます。目的の内容であれば続行してください。
6. Unityのインポートとコンパイルが終わるまで待ちます。自動追加が完了しない場合はVCCまたはALCOMでこのプロジェクトを開き、**可愛いポーズツール** と **Modular Avatar** を追加します。共通の **ゆにさきポーズシステム** と **NDMF** は依存パッケージです。`Optional-VCC-Links` にはWindowsのVCC利用者向けに商品の元の配布元ショートカットを同梱しています。
7. 確認を取り消した場合は、準備ができたらインストーラーを再インポートしてください。Activatorが残っている間は、**Tools > Unisaki Studio** のライセンス登録コマンドも使用できます。旧版ではこのサブメニューは **ゆにさきスタジオ** と表示されます。

### このダウンロードで導入するもの

**可愛いポーズツール 3.2.0と、ゆにさきポーズシステム 3.2.0です。** 現在開発中で、まだリリースしていません。導入ダイアログ、UnityのInspectorとメニュー、標準姿勢名、ゲーム内メニュー、オフライン文書を30言語に対応させます。リリース日は未定です。ツールの表示言語はInspector最上部で選びます。公開後は、インストーラーがこれらの版と対応する依存パッケージをVPM配布元から取得します。ローカルでのリリース準備ではパッケージを公開しません。

可愛いポーズツールには、姿勢データ、設定ツール、アバター調整用プリセットが含まれます。インストーラーは商品の既存のローカルライセンスを登録し、新しいGumroadライセンスキーの入力は必要ありません。公開の問い合わせに、インストーラーのファイルやライセンスデータを添付しないでください。

表示言語は現在のOSユーザーのUnity EditorPrefsに保存し、このパソコンの別Unityプロジェクトでも共有します。保存済みの選択がなければOSの言語を使用し、非対応の言語では英語を使います。商品ライセンスの保存方法は従来どおりで、Windowsでは現在のユーザーの `Software/UnisakiStudio` レジストリキー、macOS／Linuxではユーザー別のライセンスファイルを使用します。言語を変えてもライセンスは削除されません。 すべてのポーズツールとアバターで同じ言語を使用します。どのツールのInspectorで変更しても共通で反映され、アバターごとの言語指定は使用しません。 言語ボタンは言語が未選択の場合の最初の導入確認だけに表示されます。以後の言語変更はInspectorで行います。

## 2. アバターへツールを追加する

1. **Hierarchy** で **VRC Avatar Descriptor** のあるアバター、またはその子を選びます。Project内のPrefabアセットやPrefab Modeではなく、シーンに配置したアバターを使います。
2. アバターを右クリックし、**Unisaki Studio > Add Kawaii Posing** を選びます。日本語メニューの版では **ゆにさきスタジオ > 可愛いポーズツール追加** を選択します。
3. アバター内にツールが追加されます。表示文言が翻訳されていても、保存されたオブジェクト名は **可愛いポーズ** のままの場合があります。
4. 対応するアバタープリセットが案内されたら、初期調整として適用します。それ以外は **アバター調整** でプリセットを選ぶか、ポーズを手動調整してください。
5. プレビルドを案内する場合があります。プレビルドは任意で、通常のアバタービルドでも必要なデータを生成します。繰り返すビルドを短縮したいときに利用してください。
6. ツールのオブジェクトを選んで姿勢と機能を設定し、VRChat SDKから通常どおりアップロードします。

## 3. 姿勢と機能を選ぶ

Inspectorには主に次の3タブがあります。

| タブ | 主な用途 |
| --- | --- |
| **機能** | ゲーム内メニューの項目、便利機能、呼吸、アイコン設定、ExpressionParametersの使用量 |
| **ポーズ一覧** | 使用する姿勢、分類・検索、順番、一括追加、プレビュー、詳細、アニメーション調整 |
| **アバター調整** | アバター固有補正・膝補正、元の姿勢や自作モーションの取り込み、プリセット |

使う予定のメニュー項目だけを有効にしてください。たとえば **左右反転** をメニューに追加すると、VRChat内で反転を切り替えられます。すべての姿勢を常に反転させる設定ではありません。

可愛いポーズツールにはアバタープリセットと対応姿勢のIKがあります。仰向け寝の標準姿勢 **Legs Out（足伸ばし）**・**Relaxed（リラックス）**・**One Knee Up（膝立て）** の3つには、横向きの寝返りモーションを設定済みです。対応するプリセットを使い、これらの項目を編集・置き換えた場合は各姿勢の寝返り設定を確認してください。

### プリセットと体格の調整

プリセットは **アバター調整** の下部にあります。アバター名で検索し、プリセットを適用して現在のポーズ設定を置き換えます。切り替え前に調整内容を保存・バックアップしてください。プリセットは初期調整です。体格、衣装、アバターの改変内容によって手動調整が必要な場合があります。

姿勢の **アニメーション調整** を開くと、プレビューしながら身体と手足の位置を編集できます。終了時にそのウィンドウから調整アニメーションを保存してください。対応姿勢では、手足の自動調整（IK）を全体・姿勢ごとに切り替えられます。IKの現在の結果を調整に反映すると、調整アニメーションを作成して対象姿勢のIKをオフにし、手作業で仕上げられます。元のクリップは保持します。

**膝が逆向きに曲がるのを防ぐ** には、最低膝曲げ角度などの詳細設定があります。アバター固有補正は対応する補正データがある場合に使用でき、姿勢IKと併用できない補正もあります。

### 元の姿勢と自作モーション

**アバターの元の立ち・しゃがみ・伏せ姿勢を使う** は、生成時にアバターのBaseレイヤーからモーションを検出します。**自分で用意したモーションを使う** は別の取り込み設定を開き、モーションの種類ごとに指定します。一つの種類に一つのモーションを選択してください。同じ種類の手動指定がある場合は、自動取り込みより優先します。

自動取り込みはビルド用のコピーに反映します。検出したアニメーションをシーン上の手動指定一覧へ書き戻したり、元のControllerを変更したりしません。自動検出へ戻したい種類は手動指定を解除してください。特殊なBaseレイヤーや他の移動システムとの併用では、個別の調整が必要な場合があります。

## 4. VRChatで使う

アバターの **Expressions** メニューから **可愛いポーズ** を開き、使いたい分類ごとに姿勢を選びます。姿勢の選択と機能の選択は別の操作です。

- **3点VR：** 頭を上げ下げして、立ち・中腰／椅子・床座り・寝姿勢を切り替えます。切り替えが早すぎる／遅すぎる場合は、ツールの設定メニューで高さの閾値を調整してください。
- **デスクトップ：** **C** でしゃがみ、**Z** で寝姿勢へ切り替えます。Zで座り止まりになる場合は、設定メニューの寝の高さ閾値を上げてください。
- **うつ伏せ・仰向け：** 顔の向きで切り替えます。両方を選択していると、その場でジャンプしても切り替えられます。Unityの **機能 > 便利機能** でジャンプ切り替えをオフにできます。同期パラメーターの追加消費はありません。
- **固定：** 必要に応じて首・腕・足を固定します。コントローラーのジェスチャーではなく、姿勢に設定された手の形を使いたい場合はジェスチャー無効をオンにします。
- **左右反転：** 選択した姿勢を反転し、相手や構図に合わせられます。

### 足の高さと床の高さ

**足の高さ** は頭の位置を保ちながら足側を調整します。頭が適切な高さでも、足が浮く／埋まる場合に使用してください。

**床の高さ** は頭を含む身体全体を動かします。ソファ、ベッド、高い場所など、コライダーのない家具でも利用できます。共通システムの現在の中央基準の操作では、**50%が元の高さ**、0%が3 m下、100%が3 m上です。50%付近へ戻すと補正が終了します。旧版では動作が異なる場合があるため、導入済みの版を確認し、商品と共通システムを併せて更新してください。

### 撮影モード

Unityで **撮影モード** のメニュー項目を有効にしてからアップロードします。VRChatで姿勢を選び、**距離** で前方へ最大3 m移動、**向き** で回転します。撮影位置を決める間の足固定は任意です。**撮影モードを終了** すると距離・向きを戻し、足固定を解除します。

撮影モードの初期設定は自分の画面のみです。位置と向きを他の人にも見せる場合は、アップロード前にUnityで **撮影モードを同期する** を有効にしてください。同期に16 bitを使います。**撮影モード中は頭を非表示にしない** は自分の画面だけに適用し、同期パラメーターを使いません。

### 呼吸と寝返り

呼吸は **機能 > 便利機能 > 呼吸の動きをつける** で、姿勢の分類ごとに設定できます。なし・弱・中・強・急、または自分で用意した呼吸アニメーションを選びます。動きだけなら同期パラメーターは不要です。呼吸のメニュー切り替えには1 bitを使います。

寝返りには、対応する寝姿勢と **寝返り** メニューが必要です。姿勢の寝返りを有効にし、必要に応じて横向きのアニメーションを指定します。VRChatで対象の姿勢と寝返りを選び、首固定を解除してください。頭を左右に傾けると寝返りします。その姿勢で寝返りを使用している間は、通常のMotionTime操作を使えません。

前述の仰向け寝の標準3姿勢には、横向きモーションを設定済みです。他の姿勢には対応するモーションと姿勢設定が必要です。取り込んだプリセットや自作プリセットでは割り当てが異なる場合があります。

## 5. ポーズの編集・追加・プレビュー

**ポーズ一覧** で分類を選ぶか検索タブを使います。元の日本語名と、用意されている翻訳名で検索できます。各姿勢の **詳細** から、アニメーション、アイコン、順番、再生位置などを編集します。

複数のアニメーションは、クリップを追加欄へドラッグするか、Projectで選択して選択中クリップの読み込みコマンドから一括追加できます。同じクリップの参照は重複させません。詳細で移動先の順番を選ぶか、上下のボタンで並べ替えます。

**プレビュー** は調整ウィンドウを開かずにSceneで姿勢を表示します。この簡易プレビューではModular AvatarやNDMFを実行しないため、衣装、床の補正、その他のビルド時の機能は、最終的なアバタービルドでも確認してください。

アバターから生成した姿勢アイコンは姿勢を見分けやすくしますが、生成時間とアバターのデータ量が増える場合があります。容量を抑えるにはアイコンの解像度を下げてください。Androidでは姿勢アイコンを生成しません。アバターや衣装を変更した場合は、必要に応じてアイコンを作り直してください。

## 6. パラメーター使用量

Inspectorには、アバター全体ではなくポーズツールの使用量を表示します。衣装など他のシステムも別にパラメーターを使う場合があります。複数ツールで共用する設定は重複して数えません。多くの姿勢を追加した独自構成では、姿勢選択に追加のbitが必要になることがあります。

| 機能 | 同期パラメーターの追加bit数 |
| --- | ---: |
| 姿勢選択（標準の最小構成） | 8 |
| 左右反転 | 1 |
| ジェスチャー無効 | 1 |
| 呼吸の動き | 0 |
| 呼吸のメニュー切り替え | 1 |
| 足の高さ | 8 |
| 床の高さ | 8 |
| 撮影モード（自分の画面のみ） | 0 |
| 撮影モードを同期する | 16 |
| 撮影モード中は頭を非表示にしない | 0 |
| VRChat標準の揺れを止める | 0 |
| 寝返り | 10 |

寝返りは首の向きによる姿勢崩れ抑制と1 bitを共用し、両方を有効にしても、この2機能の合計は10 bitです。選択した構成の実際の使用量は、導入済みの版の表示を確認してください。

## 7. 更新とプレビルド

1. プロジェクトをバックアップし、作業中のシーンを保存します。
2. VCCまたはALCOMで **可愛いポーズツール** と共通の **ゆにさきポーズシステム** を併せて更新します。SDK・Modular Avatar・NDMFも対応する版に揃えます。
3. コンパイルの完了後、既存のツールを選び、姿勢・設定・パラメーター使用量を確認します。
4. プレビルドを使う場合は **プレビルドを更新** を押してから、アバターを再アップロードします。

既存のツール設定は維持します。旧8-bit Prefabは互換性のため保持し、既存の参照を削除・置き換えする必要はありません。新規追加は通常のPrefabを使い、不要な機能をオフにすることでパラメーター使用量を抑えられます。

プレビルドの更新警告は、キャッシュした生成データの作成後に設定が変わったことを示します。プレビルドを更新するとデータを再生成します。警告を非表示にしても、プレビルドの更新や原因の解消は行いません。毎回手動でプレビルドしなくても、通常のアバタービルドで必要なデータを生成します。

## 8. 困ったときは

| 症状 | 確認すること |
| --- | --- |
| ツール追加のメニューがない | 商品 **と** ゆにさきポーズシステムの両方を導入し、Unity Consoleのコンパイルエラーを解消してください。ライセンスのインストーラーだけでは姿勢データは入りません。 |
| インストーラーを取り消した／ファイルを削除した | 準備ができたら購入したインストーラーを再インポートし、確認をもう一度読んでください。 |
| 別プロジェクトでライセンスが見つからない | 同じOSアカウントで購入したインストーラーをインポートしてください。パソコンやアカウントを変えた場合は、そちらにもライセンスを登録します。言語設定は別のパソコンへ自動転送しません。 |
| VRChatに姿勢がない | 対象のシーン上のアバター内にツールを追加し、必要な姿勢を有効にします。Inspectorの警告を確認し、そのアバターをアップロードしてください。SDKと他の移動系ツールも確認します。 |
| Zで寝姿勢にならない | ゲーム内設定の寝の高さ閾値を上げてください。 |
| 手や膝の位置が合わない | 対応アバタープリセットを試し、対応するIKやアニメーション調整を使ってください。最終ビルドで衣装の変形も確認します。 |
| 寝返りが動かない | 対応する寝姿勢を使い、姿勢側の寝返り設定とメニュー項目の両方を有効にし、首固定を解除します。まず対応する標準3姿勢のいずれかで確認してください。 |
| 撮影時の移動が他の人に見えない | Unityで **撮影モードを同期する** を有効にし、パラメーター使用量を確認して再アップロードします。 |
