可愛いポーズツール

3点トラッキングやデスクトップでも、可愛い座り姿勢や寝姿勢を使えるVRChat向けポーズ固定ツールです。立ち15・中腰20・座り17・うつ伏せ寝16・仰向け寝17の、合計85姿勢を収録しています。

このREADMEは開発中のv3.2.0向けです。正式リリース日は未定です。導入済みのバージョンはInspector上部で確認できます。

表示言語とオフライン文書

Inspector最上部の「Language / 言語」で表示言語を選びます。一つの選択がInspectorと生成するVRChatメニューの両方に適用されます。ゲーム内の表示を変更するにはアバターを再アップロードしてください。

未選択の場合はパソコンの言語を使い、対応していない言語では英語を使います。Windows・macOS・Linuxに対応します。最後に選んだ言語はEditorPrefsに保存し、このパソコンの同じOSユーザーの別プロジェクトでも使用します。すべてのポーズツールとアバターで同じ言語を使用します。どのツールのInspectorで変更しても共通で反映され、アバターごとの言語指定は使用しません。他のパソコンには同期しません。ライセンスの保存方法は変更しません。 言語ボタンは言語が未選択の場合の最初の導入確認だけに表示されます。以後の言語変更はInspectorで行います。

README・変更履歴・使い方は同梱の言語一覧から選べます。Inspectorの「使い方」と「変更履歴」も選択言語に従います。元の利用規約と参照翻訳は従来どおり別に用意しています。

主な機能

  • 撮影モード：アバターを前方へ最大3m動かし、向きを調整できます。自分の画面だけなら0 bit、他の人にも位置と向きを見せる場合は16 bitです。
  • 撮影中の頭の表示：近くにいる自分のアバターの頭が非表示になるのを、撮影モード中だけ防げます。
  • 床の高さ：頭を含む身体全体を上下3m移動できます。50%が元の高さと初期値、0%が3m下、100%が3m上です。頭の位置を保って足側を動かす「足の高さ」と使い分けられます。
  • 寝返り：対応する寝姿勢で、頭の傾きに合わせて左右に寝返りできます。
  • 呼吸：胸などに呼吸の動きを付けられます。姿勢の分類ごとに「なし・弱・中・強・急・カスタム」を選べます。
  • VRChat標準の揺れを止める：標準の待機中の揺れを抑えながら、ポーズツールの呼吸やほかのカスタム動作を使えます。
  • 首の向きの違いによる姿勢崩れを抑制：首固定を解除したとき、元のポーズと首の向きが異なることによる姿勢崩れを抑えます。
  • 機能の選択：必要なゲーム内メニューだけを追加し、ExpressionParametersの使用量をInspectorで確認できます。
  • ポーズ一覧の検索・一括追加・並べ替え：分類をまたいだ検索、複数クリップの読み込み、移動先の順番指定ができます。
  • Sceneでの簡易プレビュー：ポーズ一覧の「プレビュー」から、その場で姿勢を確認できます。
  • 手足の自動調整（IK）：対応するポーズで、アバターの体格に合わせて手足の位置を調整します。ポーズごとのON/OFFや、結果を調整アニメーションへ反映する操作もできます。

付属ポーズで寝返りする

仰向け寝の「足伸ばし」「リラックス」「膝立て」に、寝返り用の横向き姿勢を設定しています。それぞれ「横向き寝」「昼寝」「猫寝」をもとにした寝返りです。

「機能 > メニュー追加 > 寝返り」を有効にしてアップロードし、VRChatで対応する姿勢と「寝返り」を選んでください。首固定は解除して使います。

自分で対応させる場合は「ポーズ一覧 > 詳細 > 寝返りを使う」をオンにし、「寝返り時の横向き」にアニメーションを指定します。寝返りを使用するポーズでは、通常のMotionTime設定は使えなくなります。

体格に合わせた調整

付属の手足の自動調整を使用できますが、全ポーズがIKを必要とするわけではありません。アニメーション調整画面の「手足の自動調整を使う」で全体を、「このポーズのIKを使う」で個別に切り替えられます。

「IKを調整に反映」は、その時点の自動調整の結果を新しい調整アニメーションに書き込み、対象ポーズのIKをオフにします。その後に手作業で仕上げられます。全体と対象ポーズの自動調整が有効で、適用できるIK設定があるときに使用できます。

「アバター調整」には「膝が逆向きに曲がるのを防ぐ」と、詳細の「最低膝曲げ角度（°）」もあります。

導入方法

  1. 購入したストアの商品ページからファイルをダウンロードします。
  2. 同梱の「可愛いポーズツール.unitypackage」をUnityへインポートし、ライセンスとパッケージ配布元の登録を行います。
  3. VCCまたはALCOMで、使用するUnityプロジェクトに「可愛いポーズツール」とModular Avatarを追加します。共通の「ゆにさきポーズシステム」とNDMFも依存パッケージとして導入されます。
  4. Hierarchyで対象のアバターを右クリックし、「ゆにさきスタジオ > 可愛いポーズツール追加」を選びます。
  5. アバターの中に追加された「可愛いポーズ」を選び、Inspectorで使いたい機能とポーズを設定します。
  6. 通常どおりアバターをアップロードします。

必要環境はUnity 2022.3、VRChat Avatars SDK 3.10.4以上、Modular Avatar 1.15.1以上の1.x系、NDMF 1.14.0以上の1.x系です。VCCやALCOMで必要なパッケージを併せて更新してください。

以前のバージョンから更新する場合

本商品と「ゆにさきポーズシステム」を併せて更新します。配置済みのツールの設定は引き継がれます。Inspectorで使用する機能とExpressionParametersの使用量を確認し、プレビルドを使っていた場合は「プレビルドを更新」を押してから再アップロードしてください。

v3.1.0から、新規追加は通常の「可愛いポーズ」Prefabに統一しました。「機能」で不要な項目をオフにすると、姿勢選択のみの最小構成は8 bitになります。姿勢数が多い構成では、姿勢選択に追加のbitが必要になる場合があります。

旧8bit版Prefabは、既存のアバターやプリセットの参照を保つため「Editor/Legacy」に残しています。既存のPrefabを削除・置き換えする必要はありません。Unityの新規追加メニューに8bit版は表示されません。

設定する場所

タブできること
機能ゲーム内メニューの追加、便利機能、呼吸の設定、アイコン画像とExpressionParametersの使用量の確認
ポーズ一覧使用するポーズの選択、詳細設定、検索、一括追加、順番変更、プレビュー、アニメーション調整
アバター調整アバター固有の補正、膝の補正、元の姿勢や自作モーションの取り込み、プリセットの変更

「設定を開く」を押すと、その項目の下に詳しい設定が開きます。呼吸は「機能 > 便利機能 > 呼吸の動きをつける」から設定します。

「アバターの元の立ち・しゃがみ・伏せ姿勢を使う」は、アバターに元からある姿勢の自動取り込みです。自分で用意したモーションを使う場合は、別の「取り込み設定を開く」から、立ち・しゃがみ（Crouching）・伏せ（Prone）などの種類ごとに指定します。

プリセットは「アバター調整」の一番下にあります。「このプリセットに変更する」で現在のポーズ設定を置き換えるので、調整済みの内容は保存してから切り替えてください。

機能ごとの使用量

  • 呼吸の動きは0 bitです。ゲーム内で止めたり再開したりする「メニュー追加 > 呼吸」を使う場合のみ、ON/OFFの同期に1 bitを使用します。
  • 撮影モードは自分の画面だけなら0 bitです。「便利機能 > 撮影モードを同期する」を選ぶと16 bitを使用します。「撮影モード中は頭を非表示にしない」は0 bitです。
  • 「足の高さ」「床の高さ」はそれぞれ8 bitです。床の高さは中央から動かすと上下へ移動し、50%付近へ戻すと補正が終了します。
  • 「寝返り」は単独で10 bitです。「首の向きの違いによる姿勢崩れを抑制」と1 bitを共用するため、両方を使っても合計10 bitです。
  • 「左右反転」「ジェスチャー無効」はそれぞれ1 bitです。

Inspectorの合計は、アバターに導入したポーズツールの分です。衣装など、ほかのギミックの分は含みません。複数のポーズツールを併用しても共通の設定は重複して数えません。

プレビュー・ポーズの編集

「ポーズ一覧」の各ポーズにある「プレビュー」で、Sceneに姿勢を表示できます。細かく直したい場合は「アニメーション調整」を開き、姿勢を確認しながら調整して保存します。

簡易プレビューではMAやNDMFのビルド処理を実行しません。ビルド時に組み込まれる衣装や床の位置補正などは、アップロード前のビルド結果でも確認してください。

左側の虫眼鏡タブでポーズ名を検索できます。「詳細」の「順番」で移動先を選べるほか、上下の移動ボタンでも並べ替えできます。複数のアニメーションは、追加欄へのドラッグ＆ドロップ、または「Projectで選択中のクリップを読み込む」でまとめて追加できます。

「ポーズ画像を更新」は確認ダイアログの後に画像を生成します。「ポーズアイコン生成」はゲーム内メニューで姿勢を見分けやすくする機能で、画像生成の分だけビルドに時間がかかります。容量を抑えたい場合は「アイコン画像の容量を減らす」を選択してください。Android向けではポーズアイコンを生成しません。

ゲーム内での基本操作

  • Expressionsメニューで、各分類の姿勢を選びます。VRでは頭の高さに応じて立ち・中腰・座り・寝姿勢が切り替わります。
  • 寝姿勢では顔の向きに応じて仰向け・うつ伏せを切り替え、両方のポーズを選んでいるときは、その場でジャンプしても切り替えられます。ジャンプによる切り替えはUnityの「機能 → 便利機能 → ジャンプで寝姿勢を切り替える」でオフにできます（初期設定はオン）。分類が切り替わる高さは、設定メニューの閾値で調整できます。
  • デスクトップではCキー・Zキーで姿勢を切り替えます。Zキーで寝姿勢にならない場合は、設定メニューの「寝の高さ閾値」を上げて調整してください。
  • 「ジェスチャー無効」をオンにすると、コントローラーの指の形に代えて、ポーズに設定された手の形を使います。
  • 「足の高さ」は頭の位置を保ちながら足側を調整します。「床の高さ」は頭を含む身体全体を上下へ移動します。設定メニューではこの順に並んでいます。
  • 「撮影モード」の「距離」で前へ移動すると、アバターがこちらを向きます。「向き」で回転させ、必要なタイミングで「足固定」をオンにしてください。「撮影モードを終了」で距離・向きを戻し、足固定を解除します。
  • 「呼吸」は呼吸の動きが有効な場合に使用できます。強さはUnity側で設定し、ゲーム内ではON/OFFを切り替えます。

プレビルドと警告

「プレビルドを更新」は、生成したデータを再利用してアバタービルドを速くする機能です。プレビルドなしでも、通常のビルド時に必要なデータを生成します。

設定変更後は、Inspector上部の「設定の確認」やHierarchyのマークで更新をお知らせします。「警告の表示設定」は「設定の確認」の枠内にあります。表示を消しても設定の問題が解消されたり、生成データが更新されたりするわけではありません。

使用上の注意

  • フルボディトラッキング中の姿勢固定には対応していません。
  • 体格、衣装、アバターの改変内容によって追加調整が必要になることがあります。
  • 特殊なBaseレイヤーやほかの姿勢変更ギミックとは、意図どおりに統合できない場合があります。固定がうまく動かない場合は「アバター調整 > 各固定機能の他ギミックとの統合」も確認してください。
  • 撮影モードの移動・回転と床の高さは、未選択時の標準・独自モーションも補正対象です。VRChat内の視点や標準モーション置換後の挙動は、実機で確認してください。
  • 「VRChat標準の揺れを止める」は標準の待機動作が対象です。ほかの原因による揺れをすべて止める機能ではありません。
