# 変更履歴

## [3.2.0] - 未リリース

### 追加

- Inspector、編集操作、導入ダイアログ、標準姿勢名、生成するVRChatメニューを30言語で表示できるようにしました。
- Inspectorとゲーム内メニューの言語選択を統一しました。初期値はパソコンの言語を使い、最後の選択を同じOSユーザーの別プロジェクトでも使用します。
- README・変更履歴・オフラインの使い方を選択言語で開けるようにしました。
- 標準姿勢128件の表示名と各機能の説明を、既存の用語に合わせて用意しました。

### 互換性

- アバターの既存設定、独自の名前、アセット参照、パラメーター識別子、ライセンスの保存方法を維持します。

## [3.1.2] - 2026-11-09

- 「足の高さ」をオフにしても、EXメニューの「設定 → あおむけ時自動頭固定」で頭の固定を切り替えられるようになりました。以前の版でこの項目が消えたアバターも、更新後にビルドすると項目が戻ります。
- ゆにさきポーズシステム 3.1.2 に対応しました。「首の向きの違いによる姿勢崩れを抑制」を使っているとき、伏せから立ち上がったあとも顔が上を向いたままになる問題を修正しました。

ALCOM / VCCで「可愛いポーズツール」を3.1.2に更新してください。「ゆにさきポーズシステム」も3.1.2が必要です。以前プレビルドを使っていた場合は「プレビルドを更新」を押してシーンを保存し、アバターを再度ビルド・アップロードしてください。

## [3.1.1] - 2026-11-08

- 「左右反転」をオフにしても、有効にした「床の高さ」と「寝返り」がVRChatのEXメニューの「設定」に表示されるようになりました。
- 旧版でポーズを並べ替えたり、削除・改名したりしても、「足伸ばし」「リラックス」「膝立て」にそれぞれ正しい寝返りを引き継ぎます。完全にUnpackした場合も、元のポーズを特定できれば引き継ぎます。自作ポーズや、ご自身でオフにした寝返り、差し替えた横向きモーションは保持されます。
- VRChatのアバター選択時に、一瞬うつ伏せになる問題を修正しました。うつ伏せだけを選んだ状態でジャンプすると一瞬仰向けになる問題も修正しました。ジャンプでの切り替えは「機能 → 便利機能 → ジャンプで寝姿勢を切り替える」でオフにできます。初期設定はオンです。
- 更新後に共通ポージング用のAnimator Controllerの参照が外れた場合、復元できるときは警告を表示して設定から作り直します。複数のアバターで共有しているControllerの参照も保持します。
- 自分で保存した同名の「可愛いポーズ」Prefabがあっても、ツールの追加メニューから正式なPrefabを配置できるようになりました。
- 「添い寝ツール追加」を選んだとき、連携に必要な添い寝ツールが見つからない場合は、先に導入する商品を案内します。

ALCOM / VCCで「可愛いポーズツール」と「ゆにさきポーズシステム」を両方3.1.1に更新してください。以前プレビルドを使っていた場合は、シーン上の「可愛いポーズ」で「プレビルドを更新」を押してシーンを保存します。VRChatに反映するには、アバターを再度ビルド・アップロードしてください。

## [3.1.0] - 2026-11-07

- 収録85姿勢のうち53姿勢で、アバターの体格に合わせて手足をIKで自動調整します。
- 仰向け寝の「足伸ばし」「リラックス」「膝立て」が、頭の傾きによる寝返りに対応しました。
- 撮影モードでアバターの位置と向きを調整できます。位置・向きの同期と、撮影中の自分の頭の表示も選べます。
- 「床の高さ」で身体全体を上下3mまで移動できます。「足の高さ」と使い分けられます。
- 呼吸の動き、標準の待機中の揺れを止める設定、首の向きによる姿勢崩れを抑える設定を追加しました。
- 使用する機能とパラメーター使用量をInspectorで確認できます。ポーズ検索・一括追加・並べ替え・Sceneでの簡易プレビューにも対応しました。
- デスクトップモードの立ち・中腰・座りの切り替えを高速化しました。
- 設定変更後のプレビルド警告、Inspectorのスクロール負荷、生成物整理時の長時間停止を改善しました。
- ゆにさきポーズシステム 3.1.0 に対応しました。

## [3.1.0-beta.2] - オープンベータ版（2026-11-05）

- GitHub Releases・VPMでのオープンベータ配布を開始。収録85姿勢のうち53姿勢で、体格に合わせて手足をIKで自動調整します。
- 共通パッケージ3.1.0-beta.2に対応。プレビルド後の変更表示、Inspectorのスクロール負荷、生成物整理時の停止を改善しました。

## [3.1.0-beta.1] - オープンベータ版（2026-11-04）

- ゆにさきポーズシステム3.1.0-beta.1に対応。
- デスクトップモードの通常姿勢切り替えを1評価方式へ変更。通常のビルドとプレビルドで有効になり、VRや特殊条件は従来の経路を維持。
- alpha.3以前のプレビルドを更新対象として認識。
- 撮影中に床の高さを変えたときの視点を保持し、撮影終了後に最新の床の高さへ復帰。
- 自動取り込み、取り込みモーションの調整、生成Controllerの管理に関するalpha.3までの改善を反映。

## [3.1.0-alpha.2] - クローズドテスト版（2026-10-26）

### 修正・変更

- 共通ポーズシステムを3.1.0-alpha.2へ更新し、デバッグ修正を反映。
- 床の高さを上下3mへ拡張。50%が元の高さと初期値です。
- 標準・独自の未選択姿勢も撮影・床高さの補正対象に追加。
- 手動補正、同名ポーズ、初期ポーズ、旧プリセットの寝返り設定などの問題を修正。

## [3.1.0-alpha.1] - 公開前

### 追加

- 体格に合わせた手足の自動調整（IK）を追加。
- IKの全体・ポーズ別ON/OFFと、調整アニメーションへの反映を追加。
- 仰向け寝の「足伸ばし」「リラックス」「膝立て」を、頭の傾きによる寝返りに対応。
- ポーズごとの寝返り設定と、横向きアニメーションの指定を追加。
- 前方への移動と回転を調整する撮影モードを追加。
- 撮影モードの同期設定を追加。ローカルのみは0 bit、同期時は16 bit。
- 撮影モード中、自分のアバターの頭を非表示にしない設定を追加。
- 頭を含む身体全体を上げる「床の高さ」を追加。
- 呼吸の動きと強さの設定、ゲーム内ON/OFFメニューを追加。
- VRChat標準の揺れを止める設定を追加。
- 首の向きの違いによる姿勢崩れを抑制する設定を追加。
- 膝の逆曲がり防止と最低曲げ角度の設定を追加。
- 機能ごとのON/OFFとExpressionParameters使用量の表示を追加。
- Sceneでの簡易プレビュー、ポーズ検索、一括追加、移動先の順番指定を追加。
- Inspector内での変更履歴表示を追加。

### 変更

- Inspectorを「機能」「ポーズ一覧」「アバター調整」の3タブに整理。
- 呼吸の詳細、自作モーションの取り込み、プリセットの設定位置を整理。
- 足の高さ調整で生成するアニメーションの重複を削減。
- ポーズ画像更新に確認ダイアログを追加し、警告設定を「設定の確認」内に集約。
- 8bit版の新規追加メニューを廃止し、通常Prefabの機能選択に統一。既存の参照は維持。
- ゆにさきポーズシステム3.1.0-alpha.1に対応。VRChat Avatars SDKの最低バージョンを3.10.4へ変更。

### 修正

- ポーズ名の入力が別のポーズへ移る問題と、並べ替え時に詳細が閉じる問題を修正。
- プレビューが重なる問題、配置位置がずれる問題、一部アバターでエラーになる問題を修正。
- 設定変更後の警告・プレビルド状態の更新と、一部のビルドエラーを修正。
