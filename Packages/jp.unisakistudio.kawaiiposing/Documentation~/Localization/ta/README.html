Kawaii Posing Tool

மூன்று புள்ளிக் கண்காணிப்பிலும் டெஸ்க்டாப்பிலும் அழகான உட்காரும்/படுக்கும் போஸ்களைப் பயன்படுத்த உதவும் VRChat போஸ் பூட்டுக் கருவி. நிற்றல் 15, குனிதல் 20, உட்காருதல் 17, குப்புறப் படுத்தல் 16, மல்லாந்து படுத்தல் 17 என மொத்தம் 85 போஸ்கள் உள்ளன.

இந்த README உருவாக்கத்தில் உள்ள v3.2.0-க்கானது. அதிகாரப்பூர்வ வெளியீட்டுத் தேதி இன்னும் தீர்மானிக்கப்படவில்லை. நிறுவிய பதிப்பை Inspector மேல்பகுதியில் பார்க்கலாம்.

காட்சி மொழியும் இணையமில்லா ஆவணங்களும்

Inspector-இன் உச்சியிலுள்ள «Language / 言語» மூலம் காட்சி மொழியைத் தேர்ந்தெடுக்கவும். ஒரே தேர்வு Inspector-க்கும் உருவாக்கப்படும் VRChat பட்டிக்கும் பொருந்தும். விளையாட்டில் மொழியை மாற்ற அவதாரை மீண்டும் பதிவேற்றவும்.

தேர்வு செய்யாவிட்டால் கணினியின் மொழி பயன்படுத்தப்படும்; ஆதரிக்காத மொழிகளுக்கு ஆங்கிலம் பயன்படுத்தப்படும். Windows, macOS, Linux ஆதரிக்கப்படுகின்றன. கடைசித் தேர்வு EditorPrefs-இல் சேமிக்கப்பட்டு இந்தக் கணினியில் அதே OS பயனரின் பிற திட்டங்களிலும் பயன்படுத்தப்படும். எல்லா போஸ் கருவிகளும் அவதார்களும் ஒரே மொழியைப் பயன்படுத்துகின்றன. எந்தக் கருவியின் Inspector-இல் மொழியை மாற்றினாலும் பொதுவான அமைப்பு புதுப்பிக்கப்படும்; தனித்தனி அவதார்களின் மொழித் தேர்வுகள் பயன்படுத்தப்படாது. பிற கணினிகளுடன் ஒத்திசைக்காது. உரிமம் சேமிக்கும் முறை மாறாது. மொழி சேமிக்கப்படாதபோது முதல் நிறுவல் உறுதிப்படுத்தலில் மட்டுமே மொழிப் பொத்தான் காட்டப்படும். பின்னர் மொழியை Inspector-இல் மாற்றலாம்.

இணைக்கப்பட்ட மொழிப் பட்டியலில் README, மாற்றப் பதிவு, வழிகாட்டியைத் தேர்ந்தெடுக்கலாம். Inspector-இன் வழிகாட்டி மற்றும் மாற்றப் பதிவு இணைப்புகளும் தேர்ந்த மொழியைப் பின்பற்றும். அசல் பயன்பாட்டு விதிகளும் குறிப்புக்கான மொழிபெயர்ப்புகளும் முன்புபோலத் தனியே வழங்கப்படுகின்றன.

முக்கிய வசதிகள்

  • புகைப்பட முறை: அவதாரை அதிகபட்சம் 3m முன்னோக்கி நகர்த்தித் திசையை மாற்றலாம். உங்கள் திரையில் மட்டும் 0 bit; மற்றவர்களுக்கும் இடம்/திசையைக் காட்ட 16 bit.
  • புகைப்படத்தின்போது தலைக் காட்சி: அருகிலுள்ள உங்கள் அவதாரின் தலை மறைவதைப் புகைப்பட முறையின்போது மட்டும் தடுக்கலாம்.
  • தரை உயரம்: தலை உட்பட முழு உடலையும் மேலே/கீழே 3m நகர்த்தலாம். 50% அசல் உயரமும் இயல்புநிலையும்; 0% 3m கீழே; 100% 3m மேலே. தலையிடத்தை வைத்துப் பாதப் பகுதியை நகர்த்தும் «பாத உயரம்»-இலிருந்து தனியே பயன்படுத்தலாம்.
  • புரளல்: ஆதரிக்கும் படுக்கும் போஸ்களில் தலைச் சாய்வுக்கு ஏற்ப இடம்/வலம் புரளலாம்.
  • மூச்சு: மார்பு போன்றவற்றில் மூச்சு அசைவைச் சேர்க்கலாம். ஒவ்வொரு வகைக்கும் «இல்லை, மெலிது, நடுத்தரம், வலிமை, விரைவு, தனிப்பயன்» தேர்ந்தெடுக்கலாம்.
  • VRChat இயல்புநிலை அசைவை நிறுத்து: இயல்புநிலை ஓய்வு அசைவைக் குறைத்துக்கொண்டு போஸ் கருவியின் மூச்சையும் பிற தனிப்பயன் இயக்கங்களையும் பயன்படுத்தலாம்.
  • தலைச் சுழற்சியால் போஸ் சிதைவதைக் குறை: கழுத்துப் பூட்டை விடுவித்தபின் அசல் போஸிலிருந்து கழுத்துத் திசை மாறுவதால் ஏற்படும் சிதைவைக் குறைக்கும்.
  • வசதித் தேர்வு: தேவையான விளையாட்டுப் பட்டிகளை மட்டும் சேர்த்து ExpressionParameters பயன்பாட்டை Inspector-இல் பார்க்கலாம்.
  • போஸ் தேடல், கூட்டுச் சேர்த்தல், வரிசைமாற்றம்: எல்லா வகைகளிலும் தேடல், பல கிளிப் இறக்குமதி, இலக்கு வரிசைத் தேர்வு கிடைக்கும்.
  • எளிய Scene முன்னோட்டம்: போஸ் பட்டியலின் «முன்னோட்டம்» மூலம் அங்கேயே பார்க்கலாம்.
  • தானியங்கிக் கை-கால் திருத்தம் (IK): ஆதரிக்கும் போஸ்களில் அவதார் உடலமைப்புக்கு ஏற்ப கை-கால் இடங்கள் திருத்தப்படும். ஒவ்வொரு போஸுக்கும் இயக்க/நிறுத்தவும் முடிவைத் திருத்த அசைவூட்டத்தில் பதிக்கவும் முடியும்.

இணைக்கப்பட்ட போஸ்களில் புரளுதல்

மல்லாந்த போஸ்களான «கால்கள் நீட்டி», «தளர்வாய்», «ஒரு முழங்கால் மேலே» ஆகியவற்றுக்குப் புரளலுக்கான பக்கவாட்டு போஸ்கள் அமைக்கப்பட்டுள்ளன. முறையே «横向き寝» (பக்கவாட்டுப் படுத்தல்), «துயில்», «பூனைத் தூக்கம்» அடிப்படையில் உருவாக்கப்பட்டவை.

«வசதிகள் > பட்டி வசதிகள் > புரளு» இயக்கிப் பதிவேற்றி VRChat-இல் ஆதரிக்கும் போஸையும் «புரளு»-வையும் தேர்ந்தெடுக்கவும். கழுத்துப் பூட்டை விடுவித்துப் பயன்படுத்தவும்.

நீங்களே அமைக்க «போஸ்கள் > விவரங்கள் > புரளலை இயக்கு» இயக்கி «புரளலுக்கான பக்கவாட்டு போஸ்»-இல் அசைவூட்டத்தை அமைக்கவும். புரளலைப் பயன்படுத்தும் போஸில் வழக்கமான MotionTime அமைப்பு கிடைக்காது.

உடலமைப்புக்கேற்பத் திருத்துதல்

இணைக்கப்பட்ட தானியங்கிக் கை-கால் திருத்தத்தைப் பயன்படுத்தலாம்; எல்லாப் போஸ்களுக்கும் IK தேவையில்லை. அசைவூட்டத் திருத்தத் திரையின் «தானியங்கிக் கை-கால் திருத்தத்தை இயக்கு» மூலம் மொத்தத்திற்கும் «இந்த போஸுக்கு IK இயக்கு» மூலம் தனிப்போஸுக்கும் மாற்றலாம்.

«IK முடிவைத் திருத்தத்தில் பதியவும்» அப்போதைய தானியங்கித் திருத்த முடிவை புதிய திருத்த அசைவூட்டத்தில் எழுதி அந்தப் போஸுக்கு IK அணைக்கும். பின்னர் கைமுறையில் முடிக்கலாம். மொத்த மற்றும் தனிப்போஸ் தானியங்கித் திருத்தங்கள் இயக்கப்பட்டு பொருந்தும் IK அமைப்புகள் இருந்தால் கிடைக்கும்.

«அவதார் அமைவு»-இல் «முழங்கால் பின்னோக்கி மடங்குவதைத் தடு», அதன் விவரங்களில் «குறைந்தபட்ச முழங்கால் மடக்கம் (பாகை)» ஆகியவையும் உள்ளன.

நிறுவும் முறை

  1. வாங்கிய கடையின் தயாரிப்புப் பக்கத்திலிருந்து கோப்புகளைப் பதிவிறக்கவும்.
  2. இணைக்கப்பட்ட «可愛いポーズツール.unitypackage»-ஐ Unity-இல் இறக்குமதி செய்து உரிமத்தையும் தொகுப்பு விநியோகக் களஞ்சியத்தையும் பதிவு செய்யவும்.
  3. VCC அல்லது ALCOM-இல் பயன்படுத்தும் Unity திட்டத்தில் Kawaii Posing Tool மற்றும் Modular Avatar சேர்க்கவும். பொதுவான Unisaki Posing System மற்றும் NDMF சார்புகளாக நிறுவப்படும்.
  4. Hierarchy-இல் இலக்கு அவதாரில் வலது கிளிக் செய்து «Unisaki Studio > Kawaii Posing சேர்» தேர்ந்தெடுக்கவும்.
  5. அவதாருக்குள் சேர்த்த «可愛いポーズ» தேர்ந்து Inspector-இல் வேண்டிய வசதிகளையும் போஸ்களையும் அமைக்கவும்.
  6. வழக்கம்போல் அவதாரைப் பதிவேற்றவும்.

தேவையானவை: Unity 2022.3, VRChat Avatars SDK 3.10.4 அல்லது புதியது, Modular Avatar 1.x-இல் 1.15.1 அல்லது புதியது, NDMF 1.x-இல் 1.14.0 அல்லது புதியது. VCC அல்லது ALCOM-இல் தேவையான தொகுப்புகளையும் ஒன்றாகப் புதுப்பிக்கவும்.

பழைய பதிப்பிலிருந்து புதுப்பித்தல்

இந்தத் தயாரிப்பையும் Unisaki Posing System-ஐயும் ஒன்றாகப் புதுப்பிக்கவும். ஏற்கெனவே அமைத்த கருவியின் அமைப்புகள் பாதுகாக்கப்படும். Inspector-இல் வசதிகளையும் ExpressionParameters பயன்பாட்டையும் சரிபார்த்து, முன்கட்டமைப்பைப் பயன்படுத்தினால் «முன்கட்டமைப்பைப் புதுப்பி» அழுத்தியபின் மீண்டும் பதிவேற்றவும்.

v3.1.0 முதல் புதிய சேர்த்தல்கள் வழக்கமான «可愛いポーズ» Prefab-இல் ஒருங்கிணைக்கப்பட்டன. «வசதிகள்»-இல் தேவையற்றவற்றை அணைத்தால் போஸ் தேர்வு மட்டுமுள்ள குறைந்தபட்ச அமைவு 8 bit. பல போஸ்களுள்ள அமைவுகளில் தேர்வுக்குக் கூடுதல் bit தேவைப்படலாம்.

தற்போதைய அவதார்/முன்னமைவு குறிப்புகளைப் பாதுகாக்க பழைய 8bit Prefab «Editor/Legacy»-இல் உள்ளது. தற்போதைய Prefab-ஐ நீக்கவோ மாற்றவோ தேவையில்லை. Unity-இன் புதிய சேர்த்தல் பட்டியில் 8bit பதிப்பு காட்டப்படாது.

தாவல்செய்யக்கூடியவை
வசதிகள்விளையாட்டுப் பட்டி சேர்த்தல், வசதி விருப்பங்கள், மூச்சு அமைப்புகள், சின்னப் படங்கள், ExpressionParameters பயன்பாட்டைப் பார்த்தல்
போஸ்கள்பயன்படுத்தும் போஸ் தேர்வு, விவர அமைப்புகள், தேடல், கூட்டுச் சேர்த்தல், வரிசைமாற்றம், முன்னோட்டம், அசைவூட்டத் திருத்தம்
அவதார் அமைவுஅவதார் திருத்தம், முழங்கால் திருத்தம், அசல் போஸ்/தனிப்பயன் இயக்க இறக்குமதி, முன்னமைவு மாற்றம்

«அமைப்புகளைத் திற» அழுத்தினால் உருப்படியின் கீழே விரிவான அமைப்புகள் திறக்கும். «வசதிகள் > வசதி விருப்பங்கள் > மூச்சு அசைவூட்டத்தை இயக்கு» மூலம் மூச்சை அமைக்கலாம்.

«அசல் நிற்றல், குனிதல், குப்புறப் போஸ்களைப் பயன்படுத்து» அவதாரின் அசல் போஸ்களைத் தானாக இறக்குமதி செய்யும். உங்கள் இயக்கங்களைப் பயன்படுத்தத் தனியான «இறக்குமதி அமைப்புகளைத் திற» மூலம் நிற்றல், குனிதல் (Crouching), குப்புற (Prone) போன்ற வகைகளுக்கு அமைக்கவும்.

முன்னமைவுகள் «அவதார் அமைவு»-இன் அடியில் உள்ளன. «இந்த முன்னமைவைப் பயன்படுத்து» தற்போதைய போஸ் அமைப்புகளை மாற்றுவதால் திருத்தங்களைச் சேமித்தபின் மாற்றவும்.

ஒவ்வொரு வசதியின் பயன்பாடு

  • மூச்சு அசைவு 0 bit. விளையாட்டில் நிறுத்த/தொடங்க «பட்டி வசதிகள் > மூச்சு» பயன்படுத்தினால் மட்டும் ஒத்திசைவுக்கு 1 bit.
  • புகைப்பட முறை உங்கள் திரையில் மட்டும் 0 bit. «வசதி விருப்பங்கள் > புகைப்பட முறையை ஒத்திசை» தேர்ந்தால் 16 bit. «புகைப்பட முறையில் தலையைக் காட்டு» 0 bit.
  • «பாத உயரம்», «தரை உயரம்» ஒவ்வொன்றும் 8 bit. தரை உயரத்தை மையத்திலிருந்து மாற்றினால் மேலே/கீழே நகரும்; சுமார் 50%-க்கு மீட்டால் திருத்தம் முடியும்.
  • «புரளு» மட்டும் 10 bit. «தலைச் சுழற்சியால் போஸ் சிதைவதைக் குறை» உடன் 1 bit பகிர்வதால் இரண்டையும் பயன்படுத்தினாலும் மொத்தம் 10 bit.
  • «பிரதிபலி», «சைகைகள் நிறுத்து» ஒவ்வொன்றும் 1 bit.

Inspector மொத்தம் அவதாரில் நிறுவிய போஸ் கருவிகளுக்கானது. உடைகள் உள்ளிட்ட பிற கருவிகள் அடங்காது. பல போஸ் கருவிகளைப் பயன்படுத்தினாலும் பொதுவான அமைப்புகள் இருமுறை எண்ணப்படாது.

முன்னோட்டமும் போஸ் திருத்தமும்

«போஸ்கள்»-இல் ஒவ்வொரு போஸின் «முன்னோட்டம்» மூலம் Scene-இல் காட்டலாம். நுணுக்கமாக மாற்ற «அசைவூட்டத் திருத்தம்» திறந்து போஸைப் பார்த்தபடி திருத்திச் சேமிக்கவும்.

எளிய முன்னோட்டம் MA அல்லது NDMF கட்டமைப்பை இயக்காது. கட்டமைப்பில் சேரும் உடைகளையும் தரை உயரத் திருத்தத்தையும் பதிவேற்றத்துக்கு முன் கட்டமைப்பு முடிவிலும் சரிபார்க்கவும்.

இடப்பக்க பூதக்கண்ணாடித் தாவலில் போஸ் பெயரைத் தேடலாம். «விவரங்கள்»-இன் «வரிசை»-இல் இலக்கைத் தேர்ந்தோ மேல்/கீழ் பொத்தான்களாலோ வரிசை மாற்றலாம். பல அசைவூட்டங்களைச் சேர்க்கும் பகுதியில் இழுத்துவிட்டோ «Project-இல் தேர்ந்த கிளிப்புகளை இறக்குமதி செய்» மூலமோ கூட்டாகச் சேர்க்கலாம்.

«போஸ் சிறுபடங்களைப் புதுப்பி» உறுதிப்படுத்தல் உரையாடலுக்குப் பிறகு படங்களை உருவாக்கும். «போஸ் சின்னங்களை உருவாக்கு» விளையாட்டுப் பட்டியில் போஸ்களை அறிய உதவும்; பட உருவாக்கத்தால் கட்டமைப்பு நேரம் அதிகரிக்கும். அளவைக் குறைக்க «சின்ன அளவைக் குறை» தேர்ந்தெடுக்கவும். Android-க்கு போஸ் சின்னங்கள் உருவாக்கப்படாது.

விளையாட்டின் அடிப்படைக் கட்டுப்பாடுகள்

  • Expressions பட்டியில் ஒவ்வொரு வகைக்கும் போஸ் தேர்ந்தெடுக்கவும். VR-இல் தலை உயரத்துக்கு ஏற்ப நிற்றல், குனிதல், உட்காருதல், படுத்தல் மாறும்.
  • படுக்கும்போது முகத் திசைக்கு ஏற்ப மல்லாந்த/குப்புற நிலை மாறும்; இரு போஸ்களையும் தேர்ந்திருந்தால் ஒரே இடத்தில் குதித்தும் மாற்றலாம். Unity-இன் «வசதிகள் → வசதி விருப்பங்கள் → குதித்துப் படுக்கும் போஸ்களை மாற்று» மூலம் அணைக்கலாம் (இயல்பாக இயக்கப்படும்). வகை மாறும் உயரத்தை அமைப்புப் பட்டி வரம்புகளில் மாற்றலாம்.
  • டெஸ்க்டாப்பில் C, Z விசைகளால் போஸ் மாற்றவும். Z-இல் படுக்காவிட்டால் அமைப்புப் பட்டியின் «படுக்கும் உயர வரம்பு» அதிகரிக்கவும்.
  • «சைகைகள் நிறுத்து» இயக்கினால் கட்டுப்படுத்தியின் விரல் வடிவத்திற்குப் பதில் போஸின் கை வடிவம் பயன்படும்.
  • «பாத உயரம்» தலையிடத்தை வைத்துப் பாதப் பகுதியை மாற்றும். «தரை உயரம்» தலை உட்பட முழு உடலையும் மேலே/கீழே நகர்த்தும். அமைப்புப் பட்டியில் இவ்வரிசையில் உள்ளன.
  • «புகைப்பட முறை»-இன் «தூரம்» மூலம் முன்னால் நகர்ந்தால் அவதார் உங்களை நோக்கும். «திசை» மூலம் சுழற்றி தேவையானபோது «பாதங்களை பூட்டு» இயக்கவும். «புகைப்படம் முடி» தூரம்/திசையை மீட்டுப் பாதப் பூட்டை விடுவிக்கும்.
  • மூச்சு அசைவு இயக்கப்பட்டால் «மூச்சு» கிடைக்கும். வலிமையை Unity-இல் அமைத்து விளையாட்டில் இயக்கவும் நிறுத்தவும்.

முன்கட்டமைப்பும் எச்சரிக்கைகளும்

«முன்கட்டமைப்பைப் புதுப்பி» உருவாக்கிய தரவை மீண்டும் பயன்படுத்தி அவதார் கட்டமைப்பை வேகமாக்கும். முன்கட்டமைப்பு இல்லாவிட்டாலும் வழக்கமான கட்டமைப்பு தேவையான தரவை உருவாக்கும்.

அமைப்பு மாற்றத்துக்குப் பிறகு Inspector மேலுள்ள «அமைப்புகளைச் சரிபார்» அல்லது Hierarchy குறியீடு புதுப்பிக்கத் தெரிவிக்கும். «எச்சரிக்கைக் காட்சி அமைப்புகள்», «அமைப்புகளைச் சரிபார்» பெட்டிக்குள் உள்ளன. காட்சியை மறைப்பதால் அமைப்புச் சிக்கல் தீராது; உருவாக்கிய தரவும் புதுப்பிக்கப்படாது.

பயன்பாட்டுக் குறிப்புகள்

  • முழு உடல் கண்காணிப்பில் போஸ் பூட்டுதல் ஆதரிக்கப்படாது.
  • உடலமைப்பு, உடை, அவதார் மாற்றங்களுக்கு ஏற்ப கூடுதல் திருத்தம் தேவைப்படலாம்.
  • சிறப்பு Base அடுக்குகள் அல்லது பிற போஸ் மாற்றுக் கருவிகளுடன் எதிர்பார்த்த ஒருங்கிணைப்பு கிடைக்காமல் இருக்கலாம். பூட்டுகள் சரியாக இயங்காவிட்டால் «அவதார் அமைவு > பிற கருவிகளுடன் கண்காணிப்புப் பூட்டுகளை ஒருங்கிணை» சரிபார்க்கவும்.
  • புகைப்பட முறையின் நகர்வு/சுழற்சியும் தரை உயரமும் போஸ் தேர்ந்தெடுக்காத இயல்புநிலை/தனிப்பயன் இயக்கங்களையும் திருத்தும். VRChat செயலியில் பார்வையையும் இயல்புநிலை இயக்கம் மாற்றியபின் நடத்தையையும் சரிபார்க்கவும்.
  • «VRChat இயல்புநிலை அசைவை நிறுத்து» இயல்புநிலை ஓய்வு இயக்கத்துக்கானது; மற்ற எல்லாக் காரணங்களின் அசைவையும் நிறுத்தாது.

வழிகாட்டியும் ஆதரவும்

Inspector மேலுள்ள «உதவி / மாற்றப் பதிவு» மூலம் வழிகாட்டி, ஆதரவு, மாற்றப் பதிவைத் திறக்கலாம். பொது வசதிகளின் விரிவான விளக்கங்கள் Unity Project-இன் «Packages > Unisaki Posing System > README»-இலும் உள்ளன.

  • அதிகாரப்பூர்வ வழிகாட்டி
  • ஆதரவு

பிழைப் புகாரில் இந்தத் தயாரிப்பு மற்றும் Unisaki Posing System பதிப்புகள், Unity, VRChat SDK, Modular Avatar, NDMF பதிப்புகள், அவதார், மீண்டும் ஏற்படுத்தும் படிகள், Console பிழை ஆகியவற்றைச் சேர்க்கவும்.

முன்னமைவுகளை விநியோகித்தல்

அசைவூட்டத் திருத்த வசதியால் உருவாக்கிய தரவுக்கான வழிகாட்டல் இது.
