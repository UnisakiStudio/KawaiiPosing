# Kawaii Posing Tool — தமிழ் பயனர் வழிகாட்டி

Kawaii Posing டெஸ்க்டாப் மற்றும் மூன்று புள்ளி VR-க்கான 85 போஸ்களை வழங்குகிறது: நிற்றல் 15, குனிதல்/நாற்காலி 20, தரையில் அமர்தல் 17, மல்லாந்து படுத்தல் 17, குப்புறப் படுத்தல் 16.

இந்த வழிகாட்டி நிறுவல், அவதார் அமைவு, VRChat கட்டுப்பாடுகள், போஸ் திருத்தம், புதுப்பித்தல், பிழைத் தீர்வு ஆகியவற்றை விளக்குகிறது. வாங்கிய ZIP-இல் நிறுவலை விரைவாகத் தொடங்க `START_HERE.html` உள்ளது.

## தொடங்குமுன்

- VRChat Creator Companion (VCC) அல்லது ALCOM மூலம் உருவாக்கிய/நிர்வகிக்கும் Unity 2022.3 VRChat **அவதார்** திட்டத்தைப் பயன்படுத்தவும்.
- தேவையான தொகுப்புகள்: VRChat Avatars SDK 3.10.4 அல்லது புதியது; Modular Avatar 1.x-இல் 1.15.1 அல்லது புதியது; NDMF 1.x-இல் 1.14.0 அல்லது புதியது.
- டெஸ்க்டாப் மற்றும் மூன்று புள்ளி VR (தலைக்கவசமும் இரு கட்டுப்படுத்திகளும்) Humanoid அவதார்களுக்கான கருவி. முழு உடல் கண்காணிப்பின்போது போஸ் பூட்டுதல் ஆதரிக்கப்படாது.
- நிறுவல்/புதுப்பிப்புக்கு முன் தற்போதைய திட்டத்தை நகலெடுத்துப் பாதுகாக்கவும். Unity தொகுப்புப் பிழைகளை முதலில் தீர்க்கவும்.
- நிறுவி தயாரிப்பையும் சார்புகளையும் அவற்றின் களஞ்சியங்களிலிருந்து பதிவிறக்கும். இணையம் தேவை. அவதார் மாதிரிகள், VRChat SDK, Modular Avatar, NDMF இந்த ZIP-இல் இல்லை.

## 1. உரிமத்தையும் தயாரிப்பையும் நிறுவுதல்

1. முழு ZIP-ஐ Unity திட்டத்துக்கு வெளியே சாதாரண கோப்புறையில் பிரித்தெடுக்கவும்.
2. வேண்டிய அவதார் திட்டத்தை Unity-இல் திறக்கவும். **Assets > Import Package > Custom Package** மூலம் `Installer/KawaiiPosing_Installer.unitypackage` இறக்குமதி செய்யவும் அல்லது Unity மூலம் கோப்பைத் திறக்கவும்.
3. இறக்குமதி/நிறுவல் அறிவிப்புகளைப் படிக்கவும். எந்தத் தயாரிப்பு உரிமங்கள் நிறுவப்படும் என்பதை உரிம உறுதிப்படுத்தல் விளக்கும். நிறுவி மொழியை மாற்ற உரையாடலில் **மொழி…** (அல்லது **言語...**) பயன்படுத்தவும்.
4. உரிம நிறுவலை உறுதிப்படுத்தவும். தயாரிப்பு பயன்படுத்தும் பொதுவான Unisaki Posing System-க்கும் உரிமம் பொருந்தும். பின்னர் நிறுவி தன் அமைப்புக் கோப்புகளை நீக்க முன்வரலாம்; இந்தச் சுத்தப்படுத்தல் நிறுவிய தயாரிப்பு உரிமத்தை நீக்காது.
5. தானியங்கித் தொகுப்பு நிறுவியின் உறுதிப்படுத்தலைப் பார்க்கவும். சேர்க்கும் தொகுப்புகள்/களஞ்சியங்களையும் நீக்க முன்வைக்கும் பழைய கோப்புகள்/கோப்புறைகளையும் பட்டியலிடும். இவையே வேண்டியவை என்றால் தொடரவும்.
6. Unity இறக்குமதியும் தொகுப்பும் முடியும் வரை காத்திருக்கவும். தொகுப்பு நிறுவல் தானாக முடியாவிட்டால் திட்டத்தை VCC அல்லது ALCOM-இல் திறந்து **Kawaii Posing Tool**, **Modular Avatar** சேர்க்கவும். பொதுவான **Unisaki Posing System**, **NDMF** சார்புகள். Windows VCC பயனர்களுக்கான அசல் களஞ்சியக் குறுக்குவழிகள் `Optional-VCC-Links`-இல் உள்ளன.
7. உறுதிப்படுத்தலை ரத்து செய்திருந்தால் தயாரானபோது நிறுவியை மீண்டும் இறக்குமதி செய்யவும். செயலாக்கி இருக்கும் வரை **Tools > Unisaki Studio**-இன் உரிம நிறுவல் கட்டளையையும் பயன்படுத்தலாம். பழைய பதிப்புகளில் துணைப்பட்டியின் பெயர் **ゆにさきスタジオ**.

### இந்தப் பதிவிறக்கம் நிறுவுபவை

**Kawaii Posing Tool 3.2.0 உடன் Unisaki Posing System 3.2.0.** இந்தப் பதிப்பு உருவாக்கத்தில் உள்ளது; இன்னும் வெளியிடப்படவில்லை. முப்பது மொழிகளில் நிறுவல் உரையாடல்கள், Unity Inspector மற்றும் பட்டிகள், நிலையான போஸ் பெயர்கள், விளையாட்டுப் பட்டிகள், இணையமில்லா ஆவணங்களைச் சேர்க்கிறது. வெளியீட்டுத் தேதி தீர்மானிக்கப்படவில்லை. கருவி மொழியை மாற்ற Inspector உச்சியின் மொழித் தேர்வைப் பயன்படுத்தவும். வெளியிட்டபின் நிறுவி இந்தப் பதிப்புகளையும் பொருந்தும் சார்புகளையும் VPM களஞ்சியங்களிலிருந்து பதிவிறக்கும். உள்ளூரில் வெளியீட்டுக்குத் தயாரிப்பது தொகுப்புகளை வெளியிடாது.

Kawaii Posing Tool-இல் போஸ் நூலகம், அமைவுக் கருவிகள், அவதார் திருத்த முன்னமைவுகள் உள்ளன. நிறுவி தயாரிப்பின் தற்போதைய உள்ளூர் உரிமத்தைச் செயல்படுத்தும்; புதிய Gumroad உரிம விசைப் புலம் தேவையில்லை. பொது ஆதரவுக் கோரிக்கையில் நிறுவிக் கோப்புகளையோ உரிமத் தரவையோ வெளியிடாதீர்கள்.

மொழி விருப்பங்கள் தற்போதைய OS பயனருக்கான Unity EditorPrefs-இல் சேமிக்கப்பட்டு இந்தக் கணினியின் Unity திட்டங்களிடையே பகிரப்படும். சேமித்த தேர்வு இல்லாவிட்டால் நிறுவி OS மொழியைப் பின்பற்றும்; ஆதரிக்காத மொழிகளுக்கு ஆங்கிலம். தயாரிப்பு உரிமங்கள் தற்போதைய சேமிப்பையே வைத்திருக்கும்: Windows-இல் பயனரின் `Software/UnisakiStudio` பதிவக விசை; macOS/Linux-இல் பயனருக்கான உரிமக் கோப்புகள். மொழி மாற்றம் உரிமத்தை நீக்காது. எல்லா போஸ் கருவிகளும் அவதார்களும் ஒரே மொழியைப் பயன்படுத்துகின்றன. எந்தக் கருவியின் Inspector-இல் மொழியை மாற்றினாலும் பொதுவான அமைப்பு புதுப்பிக்கப்படும்; தனித்தனி அவதார்களின் மொழித் தேர்வுகள் பயன்படுத்தப்படாது. மொழி சேமிக்கப்படாதபோது முதல் நிறுவல் உறுதிப்படுத்தலில் மட்டுமே மொழிப் பொத்தான் காட்டப்படும். பின்னர் மொழியை Inspector-இல் மாற்றலாம்.

## 2. அவதாரில் கருவியைச் சேர்த்தல்

1. **Hierarchy**-இல் **VRC Avatar Descriptor** கொண்ட அவதாரையோ அதன் குழந்தைப் பொருளையோ தேர்ந்தெடுக்கவும். காட்சியிலுள்ள அவதாரைப் பயன்படுத்தவும்; Project சாளரத்தின் Prefab சொத்தையோ Prefab Mode-ஐயோ பயன்படுத்தாதீர்கள்.
2. அவதாரில் வலது கிளிக் செய்து **Unisaki Studio > Kawaii Posing சேர்** தேர்ந்தெடுக்கவும். நிறுவிய பதிப்பில் ஜப்பானிய பட்டிகள் இருந்தால் **ゆにさきスタジオ > 可愛いポーズツール追加** தேர்ந்தெடுக்கவும்.
3. கருவி அவதாருக்குள் சேர்க்கப்படும். காட்சிப் பெயர்கள் மொழிபெயர்க்கப்பட்டாலும் சேமித்த பொருளின் பெயர் **可愛いポーズ** ஆக இருக்கலாம்.
4. பொருந்தும் அவதார் முன்னமைவு வழங்கப்பட்டால் தொடக்கப் பொருத்தத்துக்குப் பயன்படுத்தவும். இல்லாவிட்டால் **அவதார் அமைவு** திறந்து முன்னமைவைத் தேர்ந்தெடுக்கவோ போஸ்களைக் கைமுறையில் திருத்தவோ செய்யவும்.
5. நிறுவி முன்கட்டமைப்பை வழங்கலாம். முன்கட்டமைப்பு விருப்பமானது; வழக்கமான அவதார் கட்டமைப்பும் தேவையான தரவை உருவாக்கும். அடுத்த கட்டமைப்புகளின் நேரத்தைக் குறைக்க முன்கட்டமைப்பை மீண்டும் பயன்படுத்தலாம்.
6. கருவிப் பொருளைத் தேர்ந்து வேண்டிய போஸ்கள்/வசதிகளை அமைத்து VRChat SDK மூலம் வழக்கம்போல் பதிவேற்றவும்.

### மொழித் தேர்வும் பழக்கமான பெயர்களும்

இந்தப் பதிப்பில் கருவி Inspector-இன் உச்சியில் **Language / 言語** உள்ளது. ஒரே தேர்வு Inspector-க்கும் உருவாக்கும் விளையாட்டுப் பட்டிக்கும் பொருந்தும். அவதார் தேர்ந்த மொழியைச் சேமிக்கும்; இந்தக் கணினியின் பிற கருவிகள்/திட்டங்களுக்கு கடைசித் தேர்வு நினைவில் இருக்கும். VRChat-இல் காணும் மொழியை மாற்ற அவதாரை மீண்டும் பதிவேற்றவும்.

## 3. போஸ்களையும் வசதிகளையும் தேர்ந்தெடுத்தல்

Inspector-இல் மூன்று முக்கியத் தாவல்கள் உள்ளன:

| தாவல் | பயன்பாடு |
| --- | --- |
| **வசதிகள்** | விளையாட்டுப் பட்டிக் கட்டுப்பாடுகள், விருப்ப நடத்தை, மூச்சு, சின்ன விருப்பங்கள், expression அளவுருப் பயன்பாடு. |
| **போஸ்கள்** | இயக்கிய போஸ்கள், வகை/தேடல், வரிசை, அசைவூட்டச் சேர்த்தல், முன்னோட்டம், விவரங்கள், அசைவூட்டத் திருத்தம். |
| **அவதார் அமைவு** | அவதார்/முழங்கால் திருத்தங்கள், அசல்/தனிப்பயன் இயக்க இறக்குமதி, முன்னமைவுகள். |

பயன்படுத்தத் திட்டமிட்ட பட்டிக் கட்டுப்பாடுகளை மட்டும் இயக்கவும். உதாரணமாக **பிரதிபலி** சேர்த்தால் VRChat-இல் பிரதிபலிப்பை மாற்றலாம்; எல்லாப் போஸ்களும் எப்போதும் பிரதிபலிக்கும்படி கட்டாயப்படுத்தாது.

Kawaii Posing-இல் அவதார் முன்னமைவுகளும் ஆதரிக்கும் போஸ்களுக்கு IK-யும் உள்ளன. மூன்று நிலையான மல்லாந்த போஸ்களுக்குப் பக்கவாட்டு இயக்கங்கள் ஏற்கெனவே அமைக்கப்பட்டுள்ளன: **கால்கள் நீட்டி (足伸ばし)**, **தளர்வாய் (リラックス)**, **ஒரு முழங்கால் மேலே (膝立て)**. பொருந்தும் முன்னமைவைப் பயன்படுத்தவும்; இவற்றைத் திருத்தியோ மாற்றியோ இருந்தால் ஒவ்வொன்றின் புரளல் அமைப்பையும் சரிபார்க்கவும்.

### முன்னமைவுகளும் பொருத்தமும்

முன்னமைவுகள் **அவதார் அமைவு** அடிப்பகுதியில் உள்ளன. அவதார் பெயரால் தேடி முன்னமைவைப் பயன்படுத்தினால் தற்போதைய போஸ் அமைப்புகள் மாற்றப்படும். மாற்றுவதற்கு முன் திருத்தங்களைச் சேமிக்கவோ நகலெடுக்கவோ செய்யவும். முன்னமைவு ஒரு தொடக்கம் மட்டுமே; உடல் விகிதங்கள், உடைகள், அவதார் மாற்றங்களுக்கு கைமுறைத் திருத்தம் தேவைப்படலாம்.

போஸின் **அசைவூட்டத் திருத்தம்** மூலம் உடல்/கை-கால் இடங்களைப் பார்த்துத் திருத்தவும். முடித்ததும் அந்தச் சாளரத்தில் திருத்த அசைவூட்டத்தைச் சேமிக்கவும். ஆதரிக்கும் இடங்களில் தானியங்கிக் கை-கால் திருத்தத்தை (IK) மொத்தமாகவும் ஒவ்வொரு போஸுக்கும் இயக்கலாம். தற்போதைய IK முடிவைத் திருத்தத்தில் பதிப்பது திருத்த அசைவூட்டத்தை உருவாக்கி அந்தப் போஸுக்கு IK அணைக்கும்; பின்னர் கைமுறையில் மேம்படுத்தலாம். அசல் கிளிப் பாதுகாக்கப்படும்.

**முழங்கால் பின்னோக்கி மடங்குவதைத் தடு** என்பதில் குறைந்தபட்ச முழங்கால் மடக்கக் கோணம் போன்ற கூடுதல் அமைப்புகள் உள்ளன. அவதாருக்கான திருத்தத் தரவு இருந்தால் மட்டுமே குறிப்பிட்ட திருத்தங்கள் கிடைக்கும்; சிலவற்றை போஸ் IK உடன் ஒருங்கே பயன்படுத்த முடியாது.

### அசல் மற்றும் தனிப்பயன் இயக்கங்கள்

**அசல் நிற்றல், குனிதல், குப்புறப் போஸ்களைப் பயன்படுத்து** உருவாக்கத்தின்போது அவதாரின் Base அடுக்கிலிருந்து இயக்கங்களைக் கண்டறியும். **உங்கள் இயக்கங்களைப் பயன்படுத்து** ஒவ்வொரு இயக்க வகைக்கும் தனியான இறக்குமதி அமைப்புகளைத் திறக்கும். ஒவ்வொரு வகைக்கும் ஓர் இயக்கத்தைத் தேர்ந்தெடுக்கவும். கைமுறைத் தேர்வுக்கு அந்த வகையின் தானியங்கி இறக்குமதியைவிட முன்னுரிமை.

தானியங்கி இறக்குமதி கட்டமைப்பு நகலுக்குப் பொருந்தும். கண்டறிந்த அசைவூட்டங்களைக் காட்சியின் கைமுறைத் தேர்வுப் பட்டியலில் எழுதாது; அசல் Controller-களையும் மாற்றாது. ஒரு வகையை மீண்டும் தானாகக் கண்டறிய விரும்பினால் அதன் கைமுறைத் தேர்வை அழிக்கவும். தனிப்பயன் Base அடுக்குகள் மற்றும் பிற நகர்வு அமைப்புகளுக்குத் தனித்திருத்தம் தேவைப்படலாம்.

## 4. VRChat-இல் கருவியைப் பயன்படுத்துதல்

அவதாரின் **Expressions** பட்டியைத் திறந்து **Kawaii Posing** செல்லவும். பயன்படுத்த விரும்பும் ஒவ்வொரு வகைக்கும் போஸ் தேர்ந்தெடுக்கவும். போஸ் தேர்வும் வசதித் தேர்வும் தனித்தனி செயல்கள்.

- **மூன்று புள்ளி VR:** நிற்றல், குனிதல்/நாற்காலி, தரையில் அமர்தல், படுத்தல் இடையே மாறத் தலையைத் தாழ்த்தவும் உயர்த்தவும். மிக விரைவாகவோ தாமதமாகவோ மாறினால் கருவியின் அமைப்புப் பட்டியில் உயர வரம்புகளை மாற்றவும்.
- **டெஸ்க்டாப்:** குனிய **C**, படுக்க **Z** பயன்படுத்தவும். Z அழுத்தியும் அமர்ந்திருந்தால் அமைப்புப் பட்டியில் படுக்கும் உயர வரம்பை அதிகரிக்கவும்.
- **குப்புற/மல்லாந்து படுத்தல்:** முகத் திசைக்கு ஏற்ப கருவி இவற்றைத் தேர்ந்தெடுக்கும். இரண்டும் தேர்ந்தால் ஒரே இடத்தில் குதித்து மாற்றலாம். வேண்டாவிட்டால் Unity-இன் **வசதிகள் > வசதி விருப்பங்கள்** மூலம் குதித்தல் மாற்றத்தை அணைக்கலாம்; கூடுதல் ஒத்திசைவு அளவுருப் பயன்பாடு இல்லை.
- **பூட்டுகள்:** தேவைக்கேற்ப தலை, கை, பாதப் பூட்டுகளைப் பயன்படுத்தவும். கட்டுப்படுத்தியின் சைகைக்குப் பதில் போஸின் கை வடிவம் வேண்டினால் சைகைகளை நிறுத்தவும்.
- **பிரதிபலி:** நண்பரை நோக்கவோ பட அமைப்புக்கு ஏற்றவாறோ தேர்ந்த போஸைப் பிரதிபலிக்கவும்.

### பாத உயரமும் தரை உயரமும்

**பாத உயரம்** தலையின் இடத்தை வைத்துப் பாதங்களை மாற்றும். தலை சரியான உயரத்தில் இருந்தும் பாதங்கள் மிதந்தாலோ புதைந்தாலோ பயன்படுத்தவும்.

**தரை உயரம்** தலை உட்பட முழு உடலையும் நகர்த்தும். collider இல்லாத சோபா, படுக்கை அல்லது உயர்ந்த மேற்பரப்புகளுக்கும் பயன்படுத்தலாம். பொது அமைப்பின் தற்போதைய மையக் கட்டுப்பாட்டில் **50% அசல் உயரம்**, 0% அதைவிட 3 m கீழே, 100% அதைவிட 3 m மேலே. இடப்பெயர்வை முடிக்க சுமார் 50%-க்கு மீட்கவும். பழைய பதிப்புகளின் நடத்தை மாறலாம்; நிறுவிய பதிப்பைச் சரிபார்த்து தயாரிப்புடன் பொது அமைப்பையும் புதுப்பிக்கவும்.

### புகைப்பட முறை

பதிவேற்றுவதற்கு முன் Unity-இல் **புகைப்பட முறை** பட்டி உருப்படியை இயக்கவும். VRChat-இல் போஸ் தேர்ந்து **தூரம்** மூலம் அதிகபட்சம் 3 m முன்னோக்கி நகர்த்தி **திசை** மூலம் அவதாரைச் சுழற்றவும். படத்தை அமைக்கும்போது பாதப் பூட்டு விருப்பமானது. **புகைப்படம் முடி** தூரம்/திசையை மீட்டுப் பாதப் பூட்டை விடுவிக்கும்.

புகைப்பட முறை இயல்பாக உள்ளூரில் மட்டும் இயங்கும். மற்றவர்களுக்கும் இடம்/சுழற்சியைக் காட்டப் பதிவேற்றும் முன் Unity-இல் **புகைப்பட முறையை ஒத்திசை** இயக்கவும்; 16 ஒத்திசைவு bit தேவை. **புகைப்பட முறையில் தலையைக் காட்டு** உங்கள் பார்வையை மட்டும் பாதிக்கும்; ஒத்திசைவு bit தேவையில்லை.

### மூச்சும் புரளலும்

**வசதிகள் > வசதி விருப்பங்கள் > மூச்சு அசைவூட்டத்தை இயக்கு** மூலம் ஒவ்வொரு போஸ் வகைக்கும் மூச்சை அமைக்கலாம். இல்லை, மெலிது, நடுத்தரம், வலிமை, விரைவு அல்லது தனிப்பயன் மூச்சு அசைவூட்டத்தைத் தேர்ந்தெடுக்கவும். அசைவுக்கே ஒத்திசைவு bit தேவையில்லை. பட்டியின் மூச்சுச் சுவிட்ச் 1 bit பயன்படுத்தும்.

புரளலுக்கு ஆதரிக்கும் படுக்கும் போஸும் **புரளு** பட்டி உருப்படியும் தேவை. போஸுக்குப் புரளலை இயக்கி தேவையானபோது பக்கவாட்டு அசைவூட்டத்தை அமைக்கவும். VRChat-இல் அந்தப் போஸைத் தேர்ந்து புரளலை இயக்கி தலை/கழுத்துப் பூட்டை விடுவிக்கவும். தலை பக்கவாட்டுச் சாய்வு புரளலைக் கட்டுப்படுத்தும். புரளும்போது அந்தப் போஸின் வழக்கமான MotionTime கட்டுப்பாடு கிடைக்காது.

மேலே குறிப்பிட்ட மூன்று நிலையான மல்லாந்த போஸ்களில் பக்கவாட்டு இயக்கங்கள் உள்ளன. மற்ற போஸ்களுக்கு பொருத்தமான இயக்கமும் போஸ் அமைப்பும் தேவை. இறக்குமதி/தனிப்பயன் முன்னமைவுகளில் தேர்வுகள் மாறலாம்.

## 5. போஸ் திருத்தல், சேர்த்தல், முன்னோட்டம்

**போஸ்கள்** தாவலில் வகையைத் தேர்ந்தெடுக்கவும் அல்லது தேடல் தாவலைப் பயன்படுத்தவும். தேடலில் அசல் ஜப்பானியப் பெயர்களையும் கிடைக்கும் மொழிபெயர்ப்புகளையும் பயன்படுத்தலாம். போஸின் **விவரங்கள்** திறந்து அசைவூட்டம், சின்னம், வரிசை, நேர விருப்பங்களைத் திருத்தவும்.

பல அசைவூட்டங்களைச் சேர்க்க கிளிப்புகளைச் சேர்க்கும் பகுதிக்கு இழுக்கவும்; அல்லது Project சாளரத்தில் தேர்ந்து தேர்ந்த கிளிப்களின் இறக்குமதிக் கட்டளையைப் பயன்படுத்தவும். ஒரே கிளிப்புக்கான நகல் குறிப்புகள் நீக்கப்படும். விவரங்களில் இலக்கு வரிசையை மாற்றவும் அல்லது மேல்/கீழ் கட்டுப்பாடுகளைப் பயன்படுத்தவும்.

**முன்னோட்டம்** முழுத் திருத்தச் சாளரம் இல்லாமல் Scene காட்சியில் போஸைக் காட்டும். இந்த எளிய முன்னோட்டம் Modular Avatar அல்லது NDMF இயக்காது. எனவே உடைகள், தரைத் திருத்தம், பிற கட்டமைப்புநேர வசதிகளை இறுதி அவதார் கட்டமைப்பில் சரிபார்க்கவும்.

அவதாரிலிருந்து உருவாக்கிய போஸ் சின்னங்கள் போஸ்களை அறிய உதவும்; ஆனால் உருவாக்க நேரமும் அவதார் தரவு அளவும் அதிகரிக்கலாம். இடம் சேமிக்கச் சின்னத் தெளிவுத்திறனைக் குறைக்கவும். Android கட்டமைப்புகள் போஸ் சின்னங்களை உருவாக்காது. அவதார் அல்லது உடை மாற்றியபின் தேவைக்கேற்ப சின்னங்களை மீண்டும் உருவாக்கவும்.

## 6. அளவுரு நினைவகம்

Inspector போஸ் கருவிகளின் பங்கை மட்டுமே காட்டும்; முழு அவதார் மொத்தத்தை அல்ல. உடைகளும் பிற அமைப்புகளும் கூடுதல் அளவுரு நினைவகத்தைப் பயன்படுத்தலாம். பல போஸ் கருவிகள் பகிரும் பொதுவான அமைப்புகள் இருமுறை எண்ணப்படாது. பல கூடுதல் போஸ்களுள்ள தனிப்பயன் அமைவுகளுக்கு தேர்வு bit அதிகம் தேவைப்படலாம்.

## 7. புதுப்பித்தலும் முன்கட்டமைப்பும்

1. திட்டத்தைக் காப்புப் பிரதி எடுத்து வேலைக் காட்சியைச் சேமிக்கவும்.
2. VCC அல்லது ALCOM-இல் **Kawaii Posing Tool**, பொதுவான **Unisaki Posing System** இரண்டையும் ஒன்றாகப் புதுப்பிக்கவும். தேவையான SDK, Modular Avatar, NDMF பதிப்புகளின் இணக்கத்தையும் பராமரிக்கவும்.
3. தொகுப்பு முடியும் வரை காத்திருக்கவும். நிறுவிய கருவியைத் தேர்ந்து போஸ்கள், அமைப்புகள், அளவுருப் பயன்பாட்டைச் சரிபார்க்கவும்.
4. முன்கட்டமைப்பைப் பயன்படுத்தினால் **முன்கட்டமைப்பைப் புதுப்பி** தேர்ந்து அவதாரை மீண்டும் பதிவேற்றவும்.

தற்போதைய கருவி அமைப்புகள் பாதுகாக்கப்படும். இணக்கத்திற்காகப் பழைய 8-bit Prefab-கள் இருக்கும்; தற்போதைய குறிப்புகளுக்காக கருவியை நீக்கவோ மாற்றவோ தேவையில்லை. புதிய நிறுவல்கள் வழக்கமான Prefab-ஐப் பயன்படுத்தும்; தேவையற்ற வசதிகளை அணைத்து அளவுருப் பயன்பாட்டைக் குறைக்கலாம்.

பழைய முன்கட்டமைப்பு எச்சரிக்கை, சேமித்த கட்டமைப்புத் தரவு உருவாக்கியபின் அமைப்புகள் மாறியதைக் குறிக்கும். முன்கட்டமைப்பைப் புதுப்பித்தால் தரவு மீண்டும் உருவாகும். எச்சரிக்கையை மறைப்பதால் முன்கட்டமைப்பு புதுப்பிக்கப்படாது; அடிப்படைச் சிக்கலும் தீராது. ஒவ்வொரு முறையும் கைமுறையில் முன்கட்டமைக்காவிட்டாலும் வழக்கமான அவதார் கட்டமைப்பு தேவையான தரவை உருவாக்கும்.
