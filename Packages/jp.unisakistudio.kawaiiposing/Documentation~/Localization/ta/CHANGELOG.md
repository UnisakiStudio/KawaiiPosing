- Inspector, திருத்தச் செயல்கள், நிறுவல் உரையாடல்கள், நிலையான போஸ் பெயர்கள், உருவாக்கும் VRChat பட்டிகள் ஆகியவை 30 மொழிகளில் காட்டப்படும்.

- README, மாற்றப் பதிவு, இணையமில்லா வழிகாட்டியைத் தேர்ந்த மொழியில் திறக்கலாம்.

## [3.1.1] - 2026-11-08

- «பிரதிபலி» அணைத்தாலும் இயக்கிய «தரை உயரம்», «புரளு» ஆகியவை VRChat EX பட்டியின் «அமைப்புகள்»-இல் காட்டப்படும்.
- பழைய பதிப்பில் போஸ்களை வரிசைமாற்றி, நீக்கி, பெயர்மாற்றியிருந்தாலும் «கால்கள் நீட்டி», «தளர்வாய்», «ஒரு முழங்கால் மேலே» ஆகியவற்றுக்கான சரியான புரளல் பாதுகாக்கப்படும். முழுமையாக Unpack செய்தாலும் அசல் போஸைக் கண்டறிய முடிந்தால் மீட்கப்படும். தனிப்பயன் போஸ்கள், நீங்களே அணைத்த புரளல், மாற்றிய பக்கவாட்டு இயக்கங்கள் பாதுகாக்கப்படும்.
- VRChat-இல் அவதார் தேர்ந்தவுடன் ஒரு கணம் குப்புற ஆவதும், குப்புறப் போஸ் மட்டும் தேர்ந்திருக்கும்போது குதித்தால் ஒரு கணம் மல்லாந்து ஆவதும் திருத்தப்பட்டன. «வசதிகள் → வசதி விருப்பங்கள் → குதித்துப் படுக்கும் போஸ்களை மாற்று» மூலம் குதித்தல் மாற்றத்தை அணைக்கலாம். இயல்பாக இயக்கப்பட்டிருக்கும்.
- புதுப்பித்தபின் பொது போஸ் Animator Controller குறிப்பு துண்டிக்கப்பட்டு மீட்க முடிந்தால் எச்சரித்தபின் அமைப்புகளிலிருந்து மீண்டும் உருவாக்கும். பல அவதார்கள் பகிரும் Controller குறிப்புகளும் பாதுகாக்கப்படும்.
- நீங்களே அதே «可愛いポーズ» பெயரில் Prefab சேமித்திருந்தாலும் கருவி சேர்த்தல் பட்டியில் அதிகாரப்பூர்வ Prefab-ஐச் சேர்க்கலாம்.
- «添い寝ツール追加» தேர்ந்தபோது தேவையான 添い寝ツール கிடைக்காவிட்டால் முதலில் நிறுவ வேண்டிய தயாரிப்பு காட்டப்படும்.

ALCOM / VCC-இல் Kawaii Posing Tool, Unisaki Posing System இரண்டையும் 3.1.1-க்குப் புதுப்பிக்கவும். முன்கட்டமைப்பைப் பயன்படுத்தியிருந்தால் காட்சியின் «可愛いポーズ»-இல் «முன்கட்டமைப்பைப் புதுப்பி» அழுத்திக் காட்சியைச் சேமிக்கவும். VRChat-இல் மாற்றங்களைப் பெற அவதாரை மீண்டும் கட்டமைத்துப் பதிவேற்றவும்.

## [3.1.0-alpha.1] - வெளியீட்டுக்கு முன்

### சேர்த்தவை

- உடலமைப்புக்கு ஏற்ப தானியங்கிக் கை-கால் திருத்தம் (IK) சேர்க்கப்பட்டது.
- மொத்த/தனிப்போஸ் IK இயக்கம்/நிறுத்தமும் திருத்த அசைவூட்டத்தில் முடிவைப் பதித்தலும் சேர்க்கப்பட்டன.
- மல்லாந்த போஸ்களான «கால்கள் நீட்டி», «தளர்வாய்», «ஒரு முழங்கால் மேலே» தலைச் சாய்வுப் புரளலை ஆதரிக்கின்றன.
- ஒவ்வொரு போஸுக்கும் புரளல் அமைப்பும் பக்கவாட்டு அசைவூட்டத் தேர்வும் சேர்க்கப்பட்டன.
- முன்னோக்கி நகர்வு மற்றும் சுழற்சிக்கான புகைப்பட முறை சேர்க்கப்பட்டது.
- புகைப்பட முறை ஒத்திசைவு அமைப்பு சேர்க்கப்பட்டது. உள்ளூரில் மட்டும் 0 bit; ஒத்திசைவுக்கு 16 bit.
- புகைப்பட முறையில் உங்கள் அவதாரின் தலையை மறைக்காத அமைப்பு சேர்க்கப்பட்டது.
