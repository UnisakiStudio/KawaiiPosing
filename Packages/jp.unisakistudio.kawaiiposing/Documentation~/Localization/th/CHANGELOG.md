## [3.2.0] - ยังไม่เผยแพร่

### เพิ่ม

- แสดง Inspector การแก้ไข กล่องติดตั้ง ชื่อท่ามาตรฐาน และเมนู VRChat ที่สร้างขึ้นได้ 30 ภาษา
- รวมการเลือกภาษา Inspector และเมนูในเกมเป็นตัวเลือกเดียว เริ่มจากภาษาคอมพิวเตอร์ และใช้ตัวเลือกล่าสุดในโปรเจกต์อื่นของผู้ใช้ OS เดียวกันด้วย
- เปิด README ประวัติการอัปเดต และคู่มือออฟไลน์ตามภาษาที่เลือกได้
- เตรียมชื่อแสดงของท่ามาตรฐาน 128 ท่าและคำอธิบายทุกฟังก์ชันให้สอดคล้องกับคำศัพท์เดิม

### ความเข้ากันได้

- รักษาการตั้งค่าอวาตาร์เดิม ชื่อกำหนดเอง การอ้างอิงแอสเซ็ต ตัวระบุพารามิเตอร์ และวิธีเก็บสิทธิ์ใช้งาน

## [3.1.2] - 2026-11-09

- แม้ปิด «ความสูงเท้า» ก็สลับล็อกศีรษะได้จาก «ตั้งค่า → ล็อกศีรษะอัตโนมัติเมื่อนอนหงาย» ในเมนู EX อวาตาร์ที่รายการหายในรุ่นก่อนจะได้คืนเมื่ออัปเดตแล้วบิลด์
- รองรับ Unisaki Posing System 3.1.2 แก้หน้ายังคงแหงนหลังลุกจากนอนคว่ำเมื่อใช้ «ลดท่าผิดรูปจากการหมุนศีรษะ»

อัปเดต Kawaii Posing Tool เป็น 3.1.2 ใน ALCOM / VCC และต้องใช้ Unisaki Posing System 3.1.2 ด้วย หากเคยใช้พรีบิลด์ ให้กด «อัปเดตพรีบิลด์» บันทึกซีน แล้วบิลด์และอัปโหลดอวาตาร์ใหม่

## [3.1.1] - 2026-11-08

- แม้ปิด «กลับซ้ายขวา» รายการ «ความสูงพื้น» และ «พลิกตัว» ที่เปิดไว้จะแสดงใน «ตั้งค่า» ของเมนู EX ใน VRChat
- แม้เรียง ลบ หรือเปลี่ยนชื่อท่าในรุ่นเก่า จะสืบทอดการพลิกตัวที่ถูกต้องให้ «เหยียดขา», «ผ่อนคลาย» และ «ชันเข่าข้างเดียว» หาก Unpack ทั้งหมดแต่ยังระบุท่าเดิมได้ก็สืบทอดได้ รักษาท่าสร้างเอง การพลิกที่คุณปิดเอง และการเคลื่อนไหวด้านข้างที่เปลี่ยนไว้
- แก้ปัญหานอนคว่ำชั่วขณะตอนเลือกอวาตาร์ใน VRChat และหงายชั่วขณะเมื่อกระโดดทั้งที่เลือกนอนคว่ำอย่างเดียว ปิดการสลับด้วยการกระโดดได้ใน «ฟังก์ชัน → ฟังก์ชันอำนวยความสะดวก → กระโดดเพื่อสลับท่านอน» ค่าเริ่มต้นเปิด
- หากการอ้างอิง Animator Controller ของท่าร่วมหลุดหลังอัปเดตและกู้ได้ จะแจ้งเตือนแล้วสร้างใหม่จากการตั้งค่า รักษาการอ้างอิง Controller ที่หลายอวาตาร์ใช้ร่วมกันด้วย
- แม้มี Prefab ชื่อ «可愛いポーズ» ที่คุณบันทึกเอง ก็เพิ่ม Prefab ทางการจากเมนูเพิ่มเครื่องมือได้
- หากเลือก «添い寝ツール追加» แล้วไม่พบ 添い寝ツール ที่จำเป็นต่อการเชื่อม จะแนะนำสินค้าที่ต้องติดตั้งก่อน

อัปเดตทั้ง Kawaii Posing Tool และ Unisaki Posing System เป็น 3.1.1 ใน ALCOM / VCC หากเคยใช้พรีบิลด์ ให้กด «อัปเดตพรีบิลด์» บน «可愛いポーズ» ในซีนแล้วบันทึก หากต้องการให้มีผลใน VRChat ให้บิลด์และอัปโหลดอวาตาร์ใหม่

## [3.1.0] - 2026-11-07

- ปรับแขนขาอัตโนมัติด้วย IK ตามรูปร่างอวาตาร์ใน 53 จาก 85 ท่าที่ให้มา
- ท่านอนหงาย «เหยียดขา», «ผ่อนคลาย» และ «ชันเข่าข้างเดียว» รองรับพลิกตัวตามการเอียงศีรษะ
- ปรับตำแหน่งและทิศทางอวาตาร์ในโหมดถ่ายภาพได้ เลือกซิงค์ตำแหน่ง/ทิศทางและแสดงศีรษะตัวเองขณะถ่ายได้ด้วย
- «ความสูงพื้น» ย้ายทั้งตัวขึ้นลงได้สูงสุด 3m ใช้แยกจาก «ความสูงเท้า» ได้
- เพิ่มการหายใจ ตัวเลือกหยุดการโยกตัวขณะอยู่นิ่งเริ่มต้น และลดท่าผิดรูปจากทิศคอ
- ตรวจฟังก์ชันและการใช้พารามิเตอร์ใน Inspector ได้ รองรับค้นหาท่า เพิ่มหลายท่า เรียงใหม่ และดูตัวอย่างแบบง่ายใน Scene
- เร่งการสลับยืน ย่อตัว และนั่งในโหมดเดสก์ท็อป
- ปรับปรุงคำเตือนพรีบิลด์หลังเปลี่ยนค่า ภาระการเลื่อน Inspector และการหยุดนานตอนจัดเก็บสิ่งที่สร้างไว้
- รองรับ Unisaki Posing System 3.1.0

## [3.1.0-alpha.1] - ก่อนเผยแพร่

### เพิ่ม

- เพิ่มปรับแขนขาอัตโนมัติ (IK) ตามรูปร่าง
- เพิ่มเปิด/ปิด IK ทั้งระบบและรายท่า พร้อมบันทึกผลลงแอนิเมชันปรับแต่ง
- ท่านอนหงาย «เหยียดขา», «ผ่อนคลาย» และ «ชันเข่าข้างเดียว» รองรับพลิกตัวตามการเอียงศีรษะ
- เพิ่มตั้งพลิกตัวรายท่าและกำหนดแอนิเมชันด้านข้าง
- เพิ่มโหมดถ่ายภาพสำหรับเคลื่อนหน้าและหมุน
- เพิ่มค่าซิงค์โหมดถ่ายภาพ เฉพาะเครื่อง 0 bit; ซิงค์ 16 bit
- เพิ่มตัวเลือกไม่ซ่อนศีรษะของคุณในโหมดถ่ายภาพ
- เพิ่ม «ความสูงพื้น» ยกทั้งตัวรวมศีรษะ
- เพิ่มการหายใจ ความแรง และเมนูเปิด/ปิดในเกม
- เพิ่มตัวเลือกปิดการโยกตัวเริ่มต้นของ VRChat
- เพิ่มตัวเลือกลดท่าผิดรูปจากการหมุนศีรษะ
- เพิ่มป้องกันเข่างอกลับด้านและมุมงอขั้นต่ำ
- เพิ่มเปิด/ปิดรายฟังก์ชันและแสดงการใช้ ExpressionParameters
- เพิ่มตัวอย่างง่ายใน Scene ค้นท่า เพิ่มพร้อมกัน และระบุลำดับปลายทาง
- เพิ่มประวัติการอัปเดตใน Inspector

### เปลี่ยนแปลง

- จัด Inspector เป็นสามแท็บ «ฟังก์ชัน», «ท่า», «ตั้งค่าอวาตาร์»
- จัดตำแหน่งรายละเอียดหายใจ นำเข้าการเคลื่อนไหวเอง และพรีเซ็ตใหม่
- ลดแอนิเมชันซ้ำที่สร้างจากการปรับความสูงเท้า
- เพิ่มยืนยันอัปเดตภาพท่า และรวมค่าคำเตือนใน «ตรวจสอบการตั้งค่า»
- ยกเลิกเมนูเพิ่มรุ่น 8bit ใหม่ รวมไปที่เลือกฟังก์ชันของ Prefab ปกติ รักษาการอ้างอิงเดิม
- รองรับ Unisaki Posing System 3.1.0-alpha.1 เปลี่ยนขั้นต่ำ VRChat Avatars SDK เป็น 3.10.4

### แก้ไข

- แก้ข้อความชื่อท่าไปลงท่าอื่น และรายละเอียดปิดเมื่อเรียงใหม่
- แก้ตัวอย่างซ้อน ตำแหน่งคลาด และข้อผิดพลาดกับบางอวาตาร์
- แก้การอัปเดตคำเตือน/สถานะพรีบิลด์หลังเปลี่ยนค่า และบิลด์ผิดพลาดบางกรณี
