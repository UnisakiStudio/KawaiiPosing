Kawaii Posing Tool

เครื่องมือล็อกท่าสำหรับ VRChat ให้ใช้ท่านั่งและนอนน่ารักแม้ติดตามเพียงสามจุดหรือใช้เดสก์ท็อป มีทั้งหมด 85 ท่า: ยืน 15 ย่อตัว 20 นั่ง 17 นอนคว่ำ 16 และนอนหงาย 17

README นี้สำหรับ v3.2.0 ที่อยู่ระหว่างพัฒนา ยังไม่กำหนดวันเผยแพร่อย่างเป็นทางการ ตรวจเวอร์ชันที่ติดตั้งได้ที่ด้านบนของ Inspector

  • หน้าสินค้า BOOTH
  • ประวัติการอัปเดต

ภาษาที่แสดงและเอกสารออฟไลน์

เลือกภาษาที่ «Language / 言語» ด้านบนสุดของ Inspector ตัวเลือกเดียวใช้กับทั้ง Inspector และเมนู VRChat ที่สร้างขึ้น ต้องอัปโหลดอวาตาร์ใหม่เพื่อเปลี่ยนภาษาในเกม

หากยังไม่เลือกจะใช้ภาษาของคอมพิวเตอร์ และใช้ภาษาอังกฤษเมื่อไม่รองรับภาษานั้น รองรับ Windows, macOS และ Linux ตัวเลือกล่าสุดจะบันทึกใน EditorPrefs และใช้ในโปรเจกต์อื่นของผู้ใช้ OS เดียวกันบนคอมพิวเตอร์นี้ด้วย เครื่องมือโพสท่าทั้งหมดและอวาตาร์ทุกตัวใช้ภาษาเดียวกัน การเปลี่ยนภาษาใน Inspector ของเครื่องมือใดก็ตามจะอัปเดตค่าที่ใช้ร่วมกัน โดยไม่ใช้ตัวเลือกภาษาเฉพาะอวาตาร์ ไม่ซิงค์ไปยังคอมพิวเตอร์อื่น และไม่เปลี่ยนวิธีเก็บสิทธิ์ใช้งาน ปุ่มภาษาจะแสดงเฉพาะในการยืนยันการติดตั้งครั้งแรกเมื่อยังไม่ได้บันทึกภาษา หลังจากนั้นให้เปลี่ยนภาษาใน Inspector

เลือก README ประวัติการอัปเดต และวิธีใช้ได้จากรายการภาษาที่ให้มา คู่มือและประวัติการอัปเดตใน Inspector ก็เปิดตามภาษาที่เลือกเช่นกัน ข้อตกลงต้นฉบับและคำแปลอ้างอิงยังแยกไว้ต่างหากตามเดิม

ฟังก์ชันหลัก

  • โหมดถ่ายภาพ: ย้ายอวาตาร์ไปข้างหน้าได้สูงสุด 3m และปรับทิศทาง เฉพาะหน้าจอคุณใช้ 0 bit; ให้ผู้อื่นเห็นตำแหน่ง/ทิศทางใช้ 16 bit
  • แสดงศีรษะขณะถ่าย: ป้องกันศีรษะอวาตาร์คุณถูกซ่อนเมื่ออยู่ใกล้ เฉพาะในโหมดถ่ายภาพ
  • ความสูงพื้น: ย้ายทั้งตัวรวมศีรษะขึ้นลง 3m โดย 50% คือความสูงเดิมและค่าเริ่มต้น, 0% ต่ำลง 3m, 100% สูงขึ้น 3m ใช้แยกจาก «ความสูงเท้า» ที่ขยับฝั่งเท้าโดยรักษาศีรษะได้
  • พลิกตัว: พลิกซ้ายขวาตามการเอียงศีรษะในท่านอนที่รองรับ
  • หายใจ: เพิ่มการหายใจให้หน้าอกและส่วนอื่น เลือก «ไม่มี, เบา, กลาง, แรง, เร็ว, กำหนดเอง» ตามประเภทท่า
  • ปิดการโยกตัวเริ่มต้นของ VRChat: ลดการโยกพักเริ่มต้นและยังใช้หายใจของเครื่องมือหรือการเคลื่อนไหวกำหนดเองอื่นได้
  • ลดท่าผิดรูปจากการหมุนศีรษะ: ลดการผิดรูปเมื่อปลดล็อกศีรษะแล้วทิศคอต่างจากท่าต้นฉบับ
  • เลือกฟังก์ชัน: เพิ่มเฉพาะเมนูเกมที่จำเป็น และตรวจการใช้ ExpressionParameters ใน Inspector
  • ค้นหา เพิ่มหลายท่า และเรียงท่า: ค้นข้ามประเภท นำเข้าหลายคลิป และระบุลำดับปลายทาง
  • ตัวอย่างแบบง่ายใน Scene: ตรวจท่าในตำแหน่งนั้นได้จาก «ตัวอย่าง» ในรายการท่า
  • ปรับแขนขาอัตโนมัติ (IK): ปรับตำแหน่งแขนขาตามรูปร่างอวาตาร์ในท่าที่รองรับ เปิด/ปิดรายท่าหรือบันทึกผลลงแอนิเมชันปรับแต่งได้

พลิกตัวด้วยท่าที่ให้มา

ท่านอนหงาย «เหยียดขา», «ผ่อนคลาย» และ «ชันเข่าข้างเดียว» มีท่าด้านข้างสำหรับพลิกตัว กำหนดจาก «横向き寝» (นอนตะแคง), «งีบหลับ» และ «งีบแบบแมว» ตามลำดับ

เปิด «ฟังก์ชัน > ฟังก์ชันเมนู > พลิกตัว» แล้วอัปโหลด ใน VRChat เลือกท่าที่รองรับและ «พลิกตัว» โดยปลดล็อกศีรษะไว้

หากตั้งเอง ให้เปิด «ท่า > รายละเอียด > เปิดพลิกตัว» และระบุแอนิเมชันใน «ท่าพลิกตัวด้านข้าง» ท่าที่ใช้พลิกตัวจะใช้ค่า MotionTime ปกติไม่ได้

ปรับให้เข้ากับรูปร่าง

ใช้การปรับแขนขาอัตโนมัติที่ให้มาได้ แต่ไม่ใช่ทุกท่าที่ต้องใช้ IK สลับทั้งระบบด้วย «เปิดการปรับแขนขาอัตโนมัติ» ในหน้าปรับแอนิเมชัน และรายท่าด้วย «เปิด IK สำหรับท่านี้»

«บันทึกผล IK ลงการปรับแต่ง» เขียนผลอัตโนมัติขณะนั้นลงแอนิเมชันปรับแต่งใหม่และปิด IK ของท่าเป้าหมาย จากนั้นทำต่อเองได้ ใช้ได้เมื่อเปิดอัตโนมัติทั้งระบบและท่าเป้าหมาย พร้อมมีค่าตั้ง IK ที่ใช้ได้

«ตั้งค่าอวาตาร์» มี «ป้องกันเข่างอกลับด้าน» และ «มุมงอเข่าต่ำสุด (องศา)» ในรายละเอียดด้วย

วิธีติดตั้ง

  1. ดาวน์โหลดไฟล์จากหน้าสินค้าในร้านที่ซื้อ
  2. นำเข้า «可愛いポーズツール.unitypackage» ที่ให้มาใน Unity เพื่อลงทะเบียนสิทธิ์ใช้งานและแหล่งแพ็กเกจ
  3. เพิ่ม Kawaii Posing Tool และ Modular Avatar ลงโปรเจกต์ Unity ที่ใช้ผ่าน VCC หรือ ALCOM ระบบร่วม Unisaki Posing System และ NDMF จะติดตั้งเป็นแพ็กเกจที่ต้องใช้ด้วย
  4. คลิกขวาอวาตาร์เป้าหมายใน Hierarchy แล้วเลือก «Unisaki Studio > เพิ่ม Kawaii Posing»
  5. เลือก «可愛いポーズ» ที่เพิ่มภายในอวาตาร์ แล้วกำหนดฟังก์ชันและท่าใน Inspector
  6. อัปโหลดอวาตาร์ตามปกติ

ต้องใช้ Unity 2022.3, VRChat Avatars SDK 3.10.4 ขึ้นไป, Modular Avatar สาย 1.x ตั้งแต่ 1.15.1 และ NDMF สาย 1.x ตั้งแต่ 1.14.0 ให้อัปเดตแพ็กเกจที่จำเป็นพร้อมกันผ่าน VCC หรือ ALCOM

อัปเดตจากเวอร์ชันก่อน

อัปเดตสินค้านี้พร้อม Unisaki Posing System การตั้งค่าเครื่องมือที่วางไว้จะคงเดิม ตรวจฟังก์ชันและการใช้ ExpressionParameters ใน Inspector หากเคยใช้พรีบิลด์ ให้กด «อัปเดตพรีบิลด์» ก่อนอัปโหลดใหม่

ตั้งแต่ v3.1.0 การเพิ่มใหม่รวมเป็น Prefab ปกติ «可愛いポーズ» ปิดสิ่งไม่จำเป็นใน «ฟังก์ชัน» แล้วชุดขั้นต่ำที่เลือกท่าอย่างเดียวจะใช้ 8 bit ชุดที่มีท่ามากอาจต้องใช้ bit สำหรับเลือกท่าเพิ่ม

Prefab รุ่น 8bit เก่ายังอยู่ใน «Editor/Legacy» เพื่อรักษาการอ้างอิงอวาตาร์และพรีเซ็ตเดิม ไม่ต้องลบหรือแทนที่ Prefab ที่มี รุ่น 8bit จะไม่แสดงในเมนูเพิ่มใหม่ของ Unity

ตำแหน่งตั้งค่า

แท็บสิ่งที่ทำได้
ฟังก์ชันเพิ่มเมนูเกม ฟังก์ชันอำนวยความสะดวก หายใจ รูปไอคอน และตรวจการใช้ ExpressionParameters
ท่าเลือกท่าที่ใช้ รายละเอียด ค้นหา เพิ่มพร้อมกัน เรียง ตัวอย่าง และปรับแอนิเมชัน
ตั้งค่าอวาตาร์แก้ไขเฉพาะอวาตาร์ แก้เข่า นำเข้าท่าเดิมหรือการเคลื่อนไหวของคุณ และเปลี่ยนพรีเซ็ต

กด «เปิดการตั้งค่า» เพื่อเปิดค่าละเอียดใต้รายการ ตั้งหายใจได้จาก «ฟังก์ชัน > ฟังก์ชันอำนวยความสะดวก > เพิ่มแอนิเมชันหายใจ»

«ใช้ท่ายืน ย่อตัว และนอนคว่ำเดิมของอวาตาร์» เป็นการนำเข้าท่าเดิมอัตโนมัติ หากใช้การเคลื่อนไหวของคุณ ให้เปิด «เปิดการตั้งค่านำเข้า» ที่แยกกัน แล้วระบุแต่ละประเภท เช่น ยืน ย่อตัว (Crouching) และนอนคว่ำ (Prone)

พรีเซ็ตอยู่ล่างสุดของ «ตั้งค่าอวาตาร์» คำสั่ง «ใช้พรีเซ็ตนี้» จะแทนที่การตั้งค่าท่าปัจจุบัน จึงควรบันทึกสิ่งที่ปรับไว้ก่อนเปลี่ยน

การใช้พารามิเตอร์รายฟังก์ชัน

  • การหายใจใช้ 0 bit เฉพาะเมื่อใช้ «ฟังก์ชันเมนู > หายใจ» เพื่อหยุด/เริ่มในเกม จึงใช้ 1 bit ซิงค์เปิด/ปิด
  • โหมดถ่ายภาพเฉพาะหน้าจอคุณใช้ 0 bit เลือก «ฟังก์ชันอำนวยความสะดวก > ซิงค์โหมดถ่ายภาพ» ใช้ 16 bit ส่วน «แสดงศีรษะในโหมดถ่ายภาพ» ใช้ 0 bit
  • «ความสูงเท้า» และ «ความสูงพื้น» ใช้อย่างละ 8 bit ขยับความสูงพื้นจากกึ่งกลางจะเคลื่อนขึ้นลง และคืนใกล้ 50% เพื่อจบการแก้ไข
  • «พลิกตัว» อย่างเดียวใช้ 10 bit ใช้ 1 bit ร่วมกับ «ลดท่าผิดรูปจากการหมุนศีรษะ» จึงเปิดทั้งคู่ก็รวม 10 bit
  • «กลับซ้ายขวา» และ «ปิดท่ามือ» ใช้อย่างละ 1 bit

ยอดรวม Inspector เป็นส่วนของเครื่องมือท่าในอวาตาร์ ไม่รวมเสื้อผ้าหรือเครื่องมืออื่น แม้ใช้เครื่องมือท่าหลายตัวก็ไม่นับการตั้งค่าร่วมซ้ำ

ตัวอย่างและแก้ไขท่า

ใช้ «ตัวอย่าง» ของแต่ละท่าใน «ท่า» เพื่อแสดงใน Scene หากต้องแก้ละเอียด ให้เปิด «ปรับแอนิเมชัน» ปรับขณะดูท่า แล้วบันทึก

ตัวอย่างอย่างง่ายไม่รันการบิลด์ MA/NDMF ตรวจเสื้อผ้าและการแก้ตำแหน่งพื้นซึ่งประกอบตอนบิลด์จากผลบิลด์ก่อนอัปโหลดด้วย

ค้นชื่อท่าในแท็บแว่นขยายด้านซ้าย เลือกปลายทางใน «รายละเอียด > ลำดับ» หรือใช้ปุ่มขึ้นลงเพื่อเรียงใหม่ เพิ่มหลายแอนิเมชันด้วยลากลงช่องเพิ่ม หรือ «นำเข้าคลิปที่เลือกใน Project»

«อัปเดตภาพตัวอย่างท่า» สร้างภาพหลังยืนยัน «สร้างไอคอนท่า» ช่วยแยกท่าในเมนูเกม แต่ใช้เวลาบิลด์เพิ่มตามการสร้างภาพ หากต้องการลดขนาด ให้เลือก «ลดขนาดไอคอน» ไม่สร้างไอคอนท่าสำหรับ Android

การควบคุมพื้นฐานในเกม

  • เลือกท่าแต่ละประเภทในเมนู Expressions ใน VR ความสูงศีรษะกำหนดการสลับยืน ย่อตัว นั่ง และนอน
  • ท่านอนสลับหงาย/คว่ำตามทิศใบหน้า หากเลือกทั้งคู่ กระโดดอยู่กับที่เพื่อสลับได้ด้วย ปิดได้ใน Unity ที่ «ฟังก์ชัน → ฟังก์ชันอำนวยความสะดวก → กระโดดเพื่อสลับท่านอน» (ค่าเริ่มต้นเปิด) ความสูงเปลี่ยนประเภทปรับจากเกณฑ์ในเมนูตั้งค่า
  • เดสก์ท็อปใช้ C และ Z เปลี่ยนท่า หาก Z ไม่นอน ให้เพิ่ม «เกณฑ์ความสูงท่านอน» ในเมนูตั้งค่า
  • เปิด «ปิดท่ามือ» เพื่อใช้รูปมือที่ตั้งในท่าแทนรูปนิ้วจากคอนโทรลเลอร์
  • «ความสูงเท้า» ปรับฝั่งเท้าโดยรักษาศีรษะ «ความสูงพื้น» ย้ายทั้งตัวรวมศีรษะขึ้นลง ทั้งคู่เรียงตามนี้ในเมนูตั้งค่า
  • เมื่อใช้ «ระยะ» ของ «โหมดถ่ายภาพ» เคลื่อนไปข้างหน้า อวาตาร์จะหันมาหาคุณ ใช้ «ทิศทาง» หมุนและเปิด «ล็อกเท้า» ตามจังหวะที่ต้องการ «จบการถ่ายภาพ» คืนระยะ/ทิศทางและปลดล็อกเท้า
  • «หายใจ» ใช้ได้เมื่อเปิดการเคลื่อนไหวหายใจ ตั้งความแรงใน Unity แล้วเปิด/ปิดในเกม

พรีบิลด์และคำเตือน

«อัปเดตพรีบิลด์» นำข้อมูลที่สร้างกลับมาใช้เพื่อเร่งบิลด์อวาตาร์ แม้ไม่พรีบิลด์ การบิลด์ปกติก็สร้างข้อมูลที่จำเป็น

หลังเปลี่ยนค่า «ตรวจสอบการตั้งค่า» ด้านบน Inspector หรือเครื่องหมายใน Hierarchy จะแจ้งให้อัปเดต «การแสดงคำเตือน» อยู่ในกรอบ «ตรวจสอบการตั้งค่า» การซ่อนไม่ได้แก้ปัญหาค่าตั้งหรืออัปเดตข้อมูลที่สร้างไว้

ข้อควรทราบในการใช้งาน

  • ไม่รองรับล็อกท่าขณะฟูลบอดี้แทร็กกิง
  • รูปร่าง เสื้อผ้า และการดัดแปลงอวาตาร์อาจต้องปรับเพิ่มเติม
  • Base พิเศษหรือเครื่องมือเปลี่ยนท่าอื่นอาจรวมกันไม่ได้ตามคาด หากล็อกผิดปกติให้ตรวจ «ตั้งค่าอวาตาร์ > รวมการล็อกการติดตามกับเครื่องมืออื่น» ด้วย
  • การเคลื่อนที่/หมุนโหมดถ่ายภาพและความสูงพื้นแก้ไขการเคลื่อนไหวเริ่มต้น/กำหนดเองเมื่อไม่เลือกท่าด้วย ตรวจมุมมองและผลหลังแทนการเคลื่อนไหวใน VRChat จริง
  • «ปิดการโยกตัวเริ่มต้นของ VRChat» มีผลกับการเคลื่อนไหวพักเริ่มต้น ไม่ได้หยุดการโยกจากทุกสาเหตุอื่น

คู่มือและการสนับสนุน

เปิดคู่มือ ติดต่อสอบถาม และประวัติการอัปเดตจาก «ช่วยเหลือ / ประวัติการอัปเดต» ด้านบน Inspector รายละเอียดฟังก์ชันร่วมยังอ่านได้ที่ «Packages > Unisaki Posing System > README» ใน Project ของ Unity

  • คู่มือทางการ
  • ติดต่อสอบถาม

รายงานปัญหาพร้อมเวอร์ชันสินค้านี้และ Unisaki Posing System, เวอร์ชัน Unity, VRChat SDK, Modular Avatar, NDMF, อวาตาร์ที่ใช้, ขั้นตอนทำซ้ำ และข้อความผิดพลาด Console

การแจกพรีเซ็ต

คำแนะนำเกี่ยวกับข้อมูลที่สร้างด้วยฟังก์ชันปรับแอนิเมชัน

คุณสามารถแจกหรือขายไฟล์แอนิเมชันปรับแต่งที่สร้างด้วยฟังก์ชันนี้ รวมทั้งพรีเซ็ตที่สร้างโดยตั้งไฟล์เหล่านั้นไว้ ได้อย่างอิสระโดยไม่ต้องขออนุญาต Unisaki Studio ยินดีให้แบ่งปันพร้อมอวาตาร์ที่คุณสร้าง หรือพรีเซ็ตสำหรับอวาตาร์ที่ไม่ได้รวมในเครื่องมือ

สินค้าที่มีการตั้งค่าเชื่อมต่อให้

หมายเหตุ: ร้านของเราสร้างการตั้งค่าเชื่อมต่อเองฝ่ายเดียว โดยเห็นว่าไม่จำเป็นต้องขออนุญาตผู้สร้างสินค้านั้น จึงไม่ได้ขอ หากต้องการให้แจกหรือหยุดแจกการตั้งค่าเชื่อมต่อ โปรดส่งข้อความถึงร้าน การเชื่อมต่อต้องซื้อหรือดาวน์โหลดสินค้าที่เกี่ยวข้อง หากมีปัญหากับการตั้งค่า โปรดติดต่อร้านเรา ไม่ใช่ผู้สร้างสินค้าเหล่านั้น
