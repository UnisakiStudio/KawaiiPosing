Kawaii Posing Tool — คู่มือผู้ใช้ภาษาไทย

Kawaii Posing มี 85 ท่าสำหรับเดสก์ท็อปและ VR ติดตามสามจุด: ยืน 15 ย่อตัว/เก้าอี้ 20 นั่งพื้น 17 นอนหงาย 17 และนอนคว่ำ 16

คู่มือนี้ครอบคลุมการติดตั้ง ตั้งค่าอวาตาร์ ควบคุมใน VRChat แก้ท่า อัปเดต และแก้ปัญหา ZIP ที่ซื้อมี START_HERE.html สำหรับเริ่มติดตั้งอย่างรวดเร็ว

ก่อนเริ่ม

  • ใช้โปรเจกต์ อวาตาร์ VRChat ใน Unity 2022.3 ที่สร้างหรือจัดการด้วย VRChat Creator Companion (VCC) หรือ ALCOM
  • แพ็กเกจที่ต้องใช้: VRChat Avatars SDK 3.10.4 ขึ้นไป; Modular Avatar สาย 1.x ตั้งแต่ 1.15.1; NDMF สาย 1.x ตั้งแต่ 1.14.0
  • เครื่องมือสำหรับ Humanoid บนเดสก์ท็อปและ VR ติดตามสามจุด (แว่นและคอนโทรลเลอร์สองอัน) ไม่รองรับล็อกท่าระหว่างฟูลบอดี้แทร็กกิง
  • สำรองโปรเจกต์เดิมก่อนติดตั้งหรืออัปเดต แก้ข้อผิดพลาดคอมไพล์ Unity ให้เสร็จก่อน
  • ตัวติดตั้งดาวน์โหลดสินค้าและแพ็กเกจที่ต้องใช้จากที่เก็บ จึงต้องเชื่อมอินเทอร์เน็ต โมเดลอวาตาร์ VRChat SDK, Modular Avatar และ NDMF ไม่รวมใน ZIP นี้

1. ติดตั้งสิทธิ์ใช้งานและสินค้า

  1. แตก ZIP ทั้งหมดลงโฟลเดอร์ปกตินอกโปรเจกต์ Unity
  2. เปิดโปรเจกต์อวาตาร์ที่ต้องการใน Unity นำเข้า Installer/KawaiiPosing_Installer.unitypackage ด้วย Assets > Import Package > Custom Package หรือเปิดไฟล์ด้วย Unity
  3. อ่านข้อความนำเข้าและติดตั้ง การยืนยันสิทธิ์อธิบายว่าจะติดตั้งสิทธิ์ของสินค้าใด ใช้ ภาษา… (หรือ 言語...) ในกล่องยืนยันเพื่อเปลี่ยนภาษาตัวติดตั้ง
  4. ยืนยันติดตั้งสิทธิ์ สิทธิ์ครอบคลุม Unisaki Posing System ร่วมที่สินค้านี้ใช้ด้วย ตัวติดตั้งอาจเสนอให้ลบไฟล์ตั้งค่าของตัวเองภายหลัง การล้างนี้ไม่ลบสิทธิ์สินค้าที่ติดตั้ง
  5. ตรวจข้อความยืนยันตัวติดตั้งแพ็กเกจอัตโนมัติ ซึ่งระบุแพ็กเกจและที่เก็บที่จะเพิ่ม รวมทั้งไฟล์/โฟลเดอร์เก่าที่เสนอให้ลบ ดำเนินต่อเมื่อเป็นรายการที่ต้องการ
  6. รอ Unity นำเข้าและคอมไพล์เสร็จ หากติดตั้งแพ็กเกจไม่เสร็จอัตโนมัติ ให้เปิดโปรเจกต์ใน VCC หรือ ALCOM แล้วเพิ่ม Kawaii Posing Tool และ Modular Avatar ระบบร่วม Unisaki Posing System และ NDMF เป็นแพ็กเกจที่ต้องใช้ Optional-VCC-Links มีทางลัดที่เก็บต้นฉบับที่ให้มากับสินค้าสำหรับ VCC บน Windows
  7. หากยกเลิกการยืนยัน ให้นำเข้าตัวติดตั้งอีกเมื่อพร้อม หรือใช้คำสั่งติดตั้งสิทธิ์ใน Tools > Unisaki Studio ตราบที่ตัวเปิดใช้ยังอยู่ ในรุ่นเก่าเมนูย่อยชื่อ ゆにさきスタジオ

การดาวน์โหลดนี้ติดตั้งอะไร

Kawaii Posing Tool 3.2.0 พร้อม Unisaki Posing System 3.2.0 เวอร์ชันนี้กำลังพัฒนาและยังไม่เผยแพร่ เพิ่มกล่องตั้งค่า Inspector/เมนู Unity ชื่อท่ามาตรฐาน เมนูเกม และเอกสารออฟไลน์สามสิบภาษา ยังไม่กำหนดวันเผยแพร่ ใช้ตัวเลือกภาษาด้านบน Inspector เพื่อเปลี่ยนภาษาเครื่องมือ หลังเผยแพร่ ตัวติดตั้งจะดาวน์โหลดเวอร์ชันเหล่านี้และแพ็กเกจที่ใช้ร่วมกันได้จาก VPM การเตรียมเผยแพร่เฉพาะเครื่องไม่ทำให้แพ็กเกจถูกเผยแพร่

Kawaii Posing Tool มีคลังท่า เครื่องมือตั้งค่า และพรีเซ็ตปรับอวาตาร์ ตัวติดตั้งเปิดใช้สิทธิ์ภายในเครื่องที่สินค้ามีอยู่ ไม่ต้องใช้ช่องคีย์สิทธิ์ Gumroad ใหม่ ห้ามลงไฟล์ตัวติดตั้งหรือข้อมูลสิทธิ์ในคำขอสนับสนุนสาธารณะ

ค่าภาษาเก็บผ่าน Unity EditorPrefs สำหรับผู้ใช้ OS ปัจจุบัน และใช้ร่วมกันระหว่างโปรเจกต์ Unity บนคอมพิวเตอร์นี้ หากไม่มีค่าที่บันทึก ตัวติดตั้งใช้ภาษา OS และใช้ภาษาอังกฤษเมื่อไม่รองรับ สิทธิ์สินค้ายังคงเก็บแบบเดิม: คีย์รีจิสทรี Software/UnisakiStudio ของผู้ใช้ใน Windows และไฟล์สิทธิ์รายผู้ใช้ใน macOS/Linux การเปลี่ยนภาษาไม่ลบสิทธิ์

2. เพิ่มเครื่องมือในอวาตาร์

  1. ใน Hierarchy เลือกอวาตาร์ที่มี VRC Avatar Descriptor หรือออบเจ็กต์ลูก ใช้อวาตาร์ในซีน ไม่ใช่แอสเซ็ต Prefab ใน Project หรือ Prefab Mode
  2. คลิกขวาอวาตาร์และเลือก Unisaki Studio > เพิ่ม Kawaii Posing หากรุ่นที่ติดตั้งใช้เมนูญี่ปุ่น ให้เลือก ゆにさきスタジオ > 可愛いポーズツール追加
  3. เครื่องมือจะเพิ่มในอวาตาร์ ชื่อออบเจ็กต์ที่บันทึกอาจยังเป็น 可愛いポーズ แม้ป้ายแสดงผลแปลแล้ว
  4. หากมีพรีเซ็ตตรงอวาตาร์ ให้ใช้เป็นจุดเริ่ม หากไม่มี ให้เปิด ตั้งค่าอวาตาร์ เลือกพรีเซ็ตหรือปรับท่าเอง
  5. ตัวติดตั้งอาจเสนอพรีบิลด์ ซึ่งเป็นตัวเลือก การบิลด์ปกติก็สร้างข้อมูลที่ต้องใช้ นำพรีบิลด์กลับมาใช้เพื่อลดเวลาบิลด์ภายหลังได้
  6. เลือกออบเจ็กต์เครื่องมือ กำหนดท่าและฟังก์ชันที่ต้องการ แล้วอัปโหลดผ่าน VRChat SDK ตามปกติ

เลือกภาษาและชื่อที่คุ้นเคย

เวอร์ชันนี้มี Language / 言語 ด้านบน Inspector ของเครื่องมือ ตัวเลือกเดียวควบคุม Inspector และเมนูเกมที่สร้าง อวาตาร์เก็บภาษาของตนและจดจำตัวเลือกล่าสุดให้เครื่องมือ/โปรเจกต์อื่นบนคอมพิวเตอร์นี้ อัปโหลดอวาตาร์ใหม่เพื่อเปลี่ยนภาษาที่เห็นใน VRChat

ใช้ตารางต่อไปนี้เมื่อทำตามบทสอนภาษาญี่ปุ่นเก่า เวอร์ชันนี้มีตัวเลือกภาษา Inspector ที่แปล ชื่อท่ามาตรฐานที่แปล และเมนูในเกมครบ 30 ภาษา

Inspector กล่อง Editor/ตั้งค่า ชื่อท่ามาตรฐาน และเมนูที่สร้างซึ่งให้มามีคำแปลครบทั้ง 30 ภาษาที่เลือกได้ README ประวัติการอัปเดต และคู่มือออฟไลน์ให้ไว้ในทุกภาษา ชื่ออวาตาร์ ชื่อออบเจ็กต์ที่บันทึก ชื่อท่ากำหนดเอง ชื่อไฟล์แอสเซ็ต และตัวระบุพารามิเตอร์ภายในอาจสะกดแบบเดิม

เอกสารอ้างอิงด่วน 30 ภาษา ครอบคลุมคำอธิบายฟังก์ชันและตารางชื่อท่ามาตรฐาน เป็นเอกสารสั้นสำหรับอ้างอิง ใช้สารบัญภาษาเพื่ออ่านเอกสารเต็ม

3. เลือกท่าและฟังก์ชัน

Inspector มีสามแท็บหลัก:

แท็บใช้สำหรับ
ฟังก์ชันตัวควบคุมเมนูเกม พฤติกรรมเสริม หายใจ ตัวเลือกไอคอน และการใช้พารามิเตอร์สีหน้า
ท่าท่าที่เปิด ประเภท/ค้นหา ลำดับ เพิ่มแอนิเมชัน ตัวอย่าง รายละเอียด และปรับแอนิเมชัน
ตั้งค่าอวาตาร์การแก้ไขเฉพาะอวาตาร์/เข่า นำเข้าการเคลื่อนไหวเดิมหรือกำหนดเอง และพรีเซ็ต

เปิดเฉพาะตัวควบคุมเมนูที่จะใช้ เช่น เพิ่ม กลับซ้ายขวา เพื่อสลับใน VRChat ไม่ได้บังคับให้ทุกท่ากลับซ้ายขวาตลอด

Kawaii Posing มีพรีเซ็ตอวาตาร์และ IK สำหรับท่าที่รองรับ ท่านอนหงายมาตรฐานสามท่ามีการเคลื่อนไหวด้านข้างกำหนดไว้แล้ว: เหยียดขา (足伸ばし), ผ่อนคลาย (リラックス) และ ชันเข่าข้างเดียว (膝立て) ใช้พรีเซ็ตที่ตรงกัน และตรวจค่าพลิกตัวแต่ละท่าหากเคยแก้หรือแทนรายการเหล่านี้

พรีเซ็ตและการปรับให้พอดี

พรีเซ็ตอยู่ใกล้ท้าย ตั้งค่าอวาตาร์ ค้นด้วยชื่ออวาตาร์แล้วใช้พรีเซ็ตเพื่อแทนค่าท่าปัจจุบัน บันทึกหรือสำรองสิ่งที่ปรับก่อนเปลี่ยน พรีเซ็ตเป็นจุดเริ่ม สัดส่วนร่างกาย เสื้อผ้า และการดัดแปลงอาจยังต้องแก้เอง

ใช้ ปรับแอนิเมชัน ในท่าเพื่อดูและแก้ตำแหน่งร่างกาย/แขนขา เมื่อเสร็จให้บันทึกแอนิเมชันปรับแต่งจากหน้าต่างนั้น เปิดปรับมือ/เท้าอัตโนมัติ (IK) ทั้งระบบและรายท่าได้เมื่อรองรับ การบันทึกผล IK ปัจจุบันลงการปรับแต่งจะสร้างแอนิเมชันปรับแต่งและปิด IK ท่านั้นให้คุณทำต่อเอง โดยเก็บคลิปต้นฉบับไว้

ป้องกันเข่างอกลับด้าน มีค่าละเอียด เช่น มุมงอเข่าต่ำสุด การแก้ไขเฉพาะอวาตาร์ใช้ได้เมื่อมีข้อมูลตรงกันเท่านั้น และบางการแก้ไขใช้ร่วมกับ IK รายท่าไม่ได้

การเคลื่อนไหวเดิมและกำหนดเอง

ใช้ท่ายืน ย่อตัว และนอนคว่ำเดิมของอวาตาร์ ตรวจการเคลื่อนไหวจากเลเยอร์ Base ขณะสร้าง ส่วน ใช้การเคลื่อนไหวของคุณ เปิดค่าตั้งนำเข้าแยกแต่ละประเภท เลือกหนึ่งการเคลื่อนไหวต่อประเภท ค่าระบุเองมีความสำคัญก่อนนำเข้าอัตโนมัติของประเภทนั้น

นำเข้าอัตโนมัติมีผลกับสำเนาสำหรับบิลด์ ไม่เขียนแอนิเมชันที่พบกลับลงรายการระบุเองในซีน และไม่แก้ Controller เดิม ล้างค่าระบุเองของประเภทหากต้องการตรวจอัตโนมัติอีกครั้ง Base แบบกำหนดเองและระบบเดินอื่นอาจต้องปรับเฉพาะกรณี

4. ใช้เครื่องมือใน VRChat

เปิดเมนู Expressions ของอวาตาร์ แล้วเข้า Kawaii Posing เลือกท่าสำหรับแต่ละประเภทที่ต้องการ การเลือกท่าและเลือกฟังก์ชันเป็นคนละขั้นตอน

  • VR ติดตามสามจุด: ลดหรือยกศีรษะเพื่อเปลี่ยนระหว่างยืน ย่อตัว/เก้าอี้ นั่งพื้น และนอน หากเปลี่ยนเร็วหรือช้าเกิน ให้ปรับเกณฑ์ความสูงในเมนูตั้งค่าเครื่องมือ
  • เดสก์ท็อป: ใช้ C ย่อตัวและ Z นอน หาก Z ยังนั่งอยู่ ให้เพิ่มเกณฑ์ความสูงท่านอนในเมนูตั้งค่า
  • คว่ำ/หงาย: เครื่องมือเลือกจากทิศใบหน้า เมื่อเลือกทั้งสอง กระโดดอยู่กับที่สลับได้ ปิดการกระโดดได้ใน Unity ที่ ฟังก์ชัน > ฟังก์ชันอำนวยความสะดวก ไม่ใช้พารามิเตอร์ซิงค์เพิ่ม
  • ล็อก: ใช้ล็อกศีรษะ แขน และเท้าตามต้องการ ปิดท่ามือหากต้องการรูปมือของท่าแทนข้อมูลท่ามือจากคอนโทรลเลอร์
  • กลับซ้ายขวา: กลับท่าที่เลือกเพื่อหันหาหรือจัดองค์ประกอบภาพกับเพื่อน

ความสูงเท้าและความสูงพื้น

ความสูงเท้า ปรับเท้าโดยรักษาตำแหน่งศีรษะ ใช้เมื่อเท้าลอยหรือจมทั้งที่ศีรษะอยู่ความสูงถูกต้องแล้ว

ความสูงพื้น ย้ายทั้งตัวรวมศีรษะ ใช้กับโซฟา เตียง หรือพื้นที่ยกสูง รวมเฟอร์นิเจอร์ที่ไม่มี collider ในตัวควบคุมแบบกึ่งกลางปัจจุบันของระบบร่วม 50% คือความสูงเดิม, 0% ต่ำลง 3 m, 100% สูงขึ้น 3 m คืนใกล้ 50% เพื่อจบการเลื่อน รุ่นเก่าอาจควบคุมต่างกัน ให้ตรวจเวอร์ชันติดตั้งและอัปเดตระบบร่วมพร้อมสินค้า

เปิดรายการเมนู โหมดถ่ายภาพ ใน Unity ก่อนอัปโหลด ใน VRChat เลือกท่า ใช้ ระยะ ย้ายหน้าสูงสุด 3 m และ ทิศทาง หมุนอวาตาร์ จะล็อกเท้าหรือไม่ก็ได้ระหว่างจัดภาพ จบการถ่ายภาพ คืนระยะ/การหมุนและปลดล็อกเท้า

โหมดถ่ายภาพเป็นเฉพาะเครื่องโดยค่าเริ่มต้น ให้ผู้อื่นเห็นตำแหน่งและการหมุนด้วยการเปิด ซิงค์โหมดถ่ายภาพ ใน Unity ก่อนอัปโหลด ใช้ 16 bit ซิงค์ ส่วน แสดงศีรษะในโหมดถ่ายภาพ มีผลเฉพาะมุมมองคุณและไม่ใช้ bit ซิงค์

หายใจและพลิกตัว

ตั้งหายใจรายประเภทท่าที่ ฟังก์ชัน > ฟังก์ชันอำนวยความสะดวก > เพิ่มแอนิเมชันหายใจ เลือกไม่มี เบา กลาง แรง เร็ว หรือแอนิเมชันหายใจกำหนดเอง การเคลื่อนไหวเองไม่ใช้ bit ซิงค์ สวิตช์หายใจในเมนูใช้ 1 bit

พลิกตัวต้องใช้ท่านอนที่รองรับและรายการ พลิกตัว ในเมนู เปิดพลิกสำหรับท่าและกำหนดแอนิเมชันด้านข้างหากจำเป็น ใน VRChat เลือกท่านั้น เปิดพลิกตัว และปลดล็อกศีรษะ/คอ การเอียงศีรษะด้านข้างจะควบคุมการพลิก ระหว่างใช้พลิกตัว ตัวควบคุม MotionTime ปกติของท่านั้นไม่พร้อมใช้

ท่านอนหงายมาตรฐานสามท่าที่กล่าวข้างต้นมีการเคลื่อนไหวด้านข้าง ท่าอื่นต้องใช้การเคลื่อนไหวและค่าตั้งที่เหมาะสม พรีเซ็ตนำเข้าหรือกำหนดเองอาจมีการกำหนดต่างออกไป

5. แก้ เพิ่ม และดูตัวอย่างท่า

ใน ท่า เลือกประเภทหรือแท็บค้นหา ค้นได้ทั้งชื่อญี่ปุ่นเดิมและคำแปลที่มี เปิด รายละเอียด ของท่าเพื่อแก้แอนิเมชัน ไอคอน ลำดับ และตัวเลือกเวลา

เพิ่มหลายแอนิเมชันด้วยลากคลิปลงพื้นที่เพิ่ม หรือเลือกในหน้าต่าง Project แล้วใช้คำสั่งนำเข้าคลิปที่เลือก การอ้างอิงคลิปเดียวกันซ้ำจะถูกตัดออก เปลี่ยนลำดับปลายทางในรายละเอียดหรือใช้ปุ่มขึ้นลง

ตัวอย่าง แสดงท่าใน Scene โดยไม่เปิดหน้าต่างปรับแต่งเต็ม ตัวอย่างเบานี้ไม่รัน Modular Avatar หรือ NDMF จึงต้องตรวจเสื้อผ้า การแก้พื้น และฟังก์ชันตอนบิลด์จากบิลด์อวาตาร์สุดท้าย

ไอคอนท่าที่สร้างจากอวาตาร์ช่วยจำแนกท่า แต่ใช้เวลาสร้างและอาจเพิ่มขนาดข้อมูลอวาตาร์ ลดความละเอียดไอคอนเพื่อประหยัดพื้นที่ บิลด์ Android ไม่สร้างไอคอนท่า สร้างใหม่ตามจำเป็นเมื่อเปลี่ยนอวาตาร์หรือเสื้อผ้า

6. หน่วยความจำพารามิเตอร์

Inspector แสดงเฉพาะส่วนของเครื่องมือท่า ไม่ใช่ยอดรวมอวาตาร์ เสื้อผ้าและระบบอื่นอาจใช้หน่วยความจำพารามิเตอร์เพิ่ม การตั้งค่าที่หลายเครื่องมือใช้ร่วมกันไม่ถูกนับซ้ำ ชุดกำหนดเองที่เพิ่มท่ามากอาจใช้ bit เลือกท่าเพิ่ม

พลิกตัวใช้ 1 bit ร่วมกับการลดท่าผิดรูปจากทิศคอ เปิดทั้งสองก็ยังรวม 10 bit สำหรับสองฟังก์ชันนี้ ยอดที่แสดงในเวอร์ชันติดตั้งคือข้อมูลอ้างอิงจริงสำหรับชุดที่คุณเลือก

7. อัปเดตและพรีบิลด์

  1. สำรองโปรเจกต์และบันทึกซีนที่ทำงาน
  2. อัปเดต Kawaii Posing Tool และระบบร่วม Unisaki Posing System พร้อมกันใน VCC หรือ ALCOM รักษาเวอร์ชัน SDK, Modular Avatar และ NDMF ที่จำเป็นให้เข้ากันด้วย
  3. รอคอมไพล์เสร็จ เลือกเครื่องมือที่ติดตั้งอยู่และตรวจท่า การตั้งค่า และการใช้พารามิเตอร์
  4. หากใช้พรีบิลด์ ให้เลือก อัปเดตพรีบิลด์ แล้วอัปโหลดอวาตาร์อีกครั้ง

การตั้งค่าเดิมยังอยู่ Prefab 8-bit เก่าคงไว้เพื่อความเข้ากันได้ การอ้างอิงเดิมไม่ต้องลบหรือแทนเครื่องมือ การติดตั้งใหม่ใช้ Prefab ปกติ และปิดฟังก์ชันที่ไม่ใช้เพื่อลดพารามิเตอร์ได้

คำเตือนพรีบิลด์เก่าหมายถึงการตั้งค่าเปลี่ยนหลังสร้างข้อมูลบิลด์ในแคช อัปเดตพรีบิลด์เพื่อสร้างข้อมูลใหม่ การซ่อนคำเตือนไม่อัปเดตพรีบิลด์หรือแก้ต้นเหตุ การบิลด์ปกติสร้างข้อมูลที่จำเป็นได้แม้ไม่พรีบิลด์เองทุกครั้ง

8. แก้ปัญหา

อาการสิ่งที่ควรตรวจ
ไม่มีเมนูเพิ่มเครื่องมือตรวจว่าติดตั้งทั้งสินค้า และ Unisaki Posing System แล้ว และแก้ข้อผิดพลาดคอมไพล์ใน Unity Console ตัวติดตั้งสิทธิ์อย่างเดียวไม่ใช่คลังท่า
ยกเลิกติดตั้งหรือไฟล์ถูกลบนำเข้าตัวติดตั้งที่ซื้ออีกเมื่อพร้อม และอ่านข้อความยืนยันใหม่
สิทธิ์ดูเหมือนหายในโปรเจกต์อื่นนำเข้าตัวติดตั้งภายใต้บัญชี OS เดียวกัน หากเปลี่ยนคอมพิวเตอร์/บัญชี ให้ติดตั้งสิทธิ์ที่นั่นด้วย ค่าภาษาไม่ย้ายระหว่างคอมพิวเตอร์อัตโนมัติ
ไม่มีท่าใน VRChatเพิ่มเครื่องมือในอวาตาร์ซีนที่ถูกต้อง เปิดท่าที่ต้องการ ตรวจคำเตือน Inspector และอัปโหลดอวาตาร์นั้น ตรวจ SDK กับเครื่องมือเดินอื่น
Z ไม่ถึงท่านอนเพิ่มเกณฑ์ความสูงท่านอนในการตั้งค่าในเกม
มือหรือเข่าไม่ตรงลองพรีเซ็ตตรงอวาตาร์ แล้วใช้ IK ที่รองรับและ/หรือปรับแอนิเมชัน ตรวจเสื้อผ้าผิดรูปในบิลด์สุดท้าย
พลิกตัวไม่ทำงานใช้ท่านอนที่รองรับ เปิดค่าพลิกตัวทั้งในท่าและเมนู และปลดล็อกศีรษะ/คอ ลองหนึ่งในสามท่ามาตรฐานที่รองรับก่อน
เพื่อนไม่เห็นการเคลื่อนถ่ายภาพเปิด ซิงค์โหมดถ่ายภาพ ใน Unity ตรวจพารามิเตอร์ และอัปโหลดใหม่
ภาษาเปลี่ยนใน Unity แต่ไม่เปลี่ยนใน VRChatอัปโหลดอวาตาร์ใหม่ ตรวจตัวเลือกภาษาเดียวด้านบน Inspector ในรุ่นรองรับหลายภาษา
บิลด์/พรีบิลด์ผิดพลาดอ่านข้อผิดพลาดที่เกี่ยวข้อง รายการแรก ใน Console สำรองซีน อัปเดตหรือดาวน์โหลดสินค้าและระบบร่วมใหม่ผ่าน VCC/ALCOM และติดต่อหากยังเป็น เก็บออบเจ็กต์ที่ปรับและ GeneratedResources ไว้ เว้นแต่ฝ่ายสนับสนุนให้ขั้นตอนกู้คืนเฉพาะ

เมื่อติดต่อให้ส่งเวอร์ชันสินค้า/ระบบร่วม เวอร์ชัน Unity/SDK/Modular Avatar/NDMF ชื่ออวาตาร์ ขั้นตอนทำซ้ำที่ชัดเจน และข้อผิดพลาด Console ที่เกี่ยวข้อง ลบไฟล์ส่วนตัว เนื้อหาตัวติดตั้ง ค่าสิทธิ์ และข้อมูลบัญชีจากโพสต์สาธารณะ

  • ติดต่อสอบถาม
  • คู่มือออนไลน์พร้อมภาพ (ญี่ปุ่น)
  • หน้าสินค้า Gumroad
