更新记录

[3.2.0] - 尚未发布

新增

  • Inspector、编辑操作、安装对话框、标准姿势名和生成的VRChat菜单现支持30种显示语言。
  • 统一了Inspector和游戏内菜单的语言选择。初始使用计算机语言，同一OS用户的其他项目也会使用最后的选择。
  • 支持以所选语言打开README、更新记录和离线使用说明。
  • 依照现有术语，补齐了128个标准姿势的显示名和各功能说明。

兼容性

  • 保留虚拟形象的现有设置、自定义名称、资源引用、参数标识符和许可证保存方式。

[3.1.2] - 2026-11-09

  • 即使关闭“脚部高度”，也可通过EX菜单的“设置 → 仰卧时自动锁定头部”切换头部固定。旧版中该项目消失的虚拟形象，更新后构建即可恢复。
  • 支持Unisaki Posing System 3.1.2。修复了使用“减轻头部旋转造成的姿势变形”时，从俯卧站起后面部仍保持朝上的问题。

请在ALCOM / VCC中将Kawaii Posing Tool更新为3.1.2。Unisaki Posing System也须为3.1.2。如果此前使用过预构建，请点击“更新预构建”并保存场景，然后重新构建、上传虚拟形象。

[3.1.1] - 2026-11-08

  • 即使关闭“左右镜像”，已启用的“地面高度”和“翻身”也会显示在VRChat EX菜单的“设置”中。
  • 即使旧版中对姿势进行了排序、删除或改名，也能将正确的翻身分别继承到“伸腿坐”“放松”“支起单膝”。完全Unpack后，只要能识别原始姿势，也能继承。自定义姿势、用户自行关闭的翻身及替换的侧躺动作会保留。
  • 修复了在VRChat选择虚拟形象时会瞬间俯卧的问题，也修复了仅选择俯卧姿势时跳跃会瞬间仰卧的问题。跳跃切换可通过“功能 → 便捷功能 → 跳跃切换躺姿”关闭，默认启用。
  • 更新后，如果共用姿势Animator Controller的引用丢失，在可恢复时会显示警告并根据设置重建。多个虚拟形象共用的Controller引用也会保留。
  • 即使存在用户自行保存的同名“可愛いポーズ”Prefab，也可通过添加工具菜单放置正式Prefab。
  • 选择“添い寝ツール追加”时，若找不到联动所需的添い寝ツール，会提示先安装对应商品。

请在ALCOM / VCC中将Kawaii Posing Tool和Unisaki Posing System均更新为3.1.1。如果此前使用过预构建，请在场景中的“可愛いポーズ”上点击“更新预构建”并保存场景。要在VRChat中生效，请重新构建、上传虚拟形象。

[3.1.0] - 2026-11-07

  • 收录的85种姿势中，53种可根据虚拟形象体型，通过IK自动调整手脚。
  • 仰卧姿势“伸腿坐”“放松”“支起单膝”支持根据头部倾斜翻身。
  • 拍照模式可调整虚拟形象的位置和朝向，也可选择同步位置、朝向，以及拍照时显示自己的头部。
  • “地面高度”可上下移动整个身体，最大距离为3m，可与“脚部高度”分别使用。
  • 新增呼吸动作、关闭默认待机摇摆及减轻头部朝向造成姿势变形的设置。
  • 可在Inspector查看启用功能和参数用量，并支持姿势搜索、批量添加、排序及Scene简易预览。
  • 加快桌面模式中站立、半蹲和坐姿的切换。
  • 改善设置变化后的预构建警告、Inspector滚动负担及清理生成资源时的长时间停顿。
  • 支持Unisaki Posing System 3.1.0。

[3.1.0-beta.2] - 公开测试版（2026-11-05）

  • 开始通过GitHub Releases和VPM分发公开测试版。收录的85种姿势中，53种可根据体型通过IK自动调整手脚。
  • 支持共用软件包3.1.0-beta.2。改善预构建后的变化提示、Inspector滚动负担及清理生成资源时的停顿。

[3.1.0-beta.1] - 公开测试版（2026-11-04）

  • 支持Unisaki Posing System 3.1.0-beta.1。
  • 将桌面模式的普通姿势切换改为1次求值方式。普通构建和预构建均启用，VR及特殊条件下保留原有流程。
  • 将alpha.3及更早版本的预构建识别为需要更新。
  • 拍照期间改变地面高度时保持视点，并在结束拍照后恢复至最新地面高度。
  • 纳入截至alpha.3对自动导入、导入动作调整及生成Controller管理的改进。

[3.1.0-alpha.2] - 封闭测试版（2026-10-26）

修复与更改

  • 将共用姿势系统更新为3.1.0-alpha.2，并纳入调试修复。
  • 将地面高度扩展为上下3m。50%为原始高度及初始值。
  • 将未选择工具姿势时的默认和自定义动作，也纳入拍照和地面高度修正范围。
  • 修复手动修正、同名姿势、初始姿势及旧预设翻身设置等问题。

[3.1.0-alpha.1] - 发布前

新增

  • 新增根据体型进行的手脚自动调整（IK）。
  • 新增IK整体和各姿势的开关，以及烘焙到调整动画的操作。
  • 仰卧姿势“伸腿坐”“放松”“支起单膝”支持根据头部倾斜翻身。
  • 新增各姿势的翻身设置及侧躺动画指定。
  • 新增可调整向前移动和旋转的拍照模式。
  • 新增拍照模式同步设置。仅本地显示为0 bit，同步时为16 bit。
  • 新增拍照模式中保持自身虚拟形象头部可见的设置。
  • 新增可抬高包含头部的整个身体的“地面高度”。
  • 新增呼吸动作、强度设置及游戏内开关菜单。
  • 新增关闭VRChat默认站立摇摆的设置。
  • 新增减轻头部朝向不同造成姿势变形的设置。
  • 新增防止膝盖反折及最小弯曲角度设置。
  • 新增各功能开关和ExpressionParameters用量显示。
  • 新增Scene简易预览、姿势搜索、批量添加及指定目标顺序。
  • 新增Inspector内的更新记录显示。

更改

  • 将Inspector整理为“功能”“姿势”“头像设置”3个选项卡。
  • 整理呼吸详情、自定义动作导入及预设的设置位置。
  • 减少脚部高度调整生成动画的重复。
  • 为姿势图片更新添加确认对话框，并将警告设置集中到“检查设置”中。
  • 取消8bit版本的新建菜单，统一为普通Prefab的功能选择。保留现有引用。
  • 支持Unisaki Posing System 3.1.0-alpha.1。将VRChat Avatars SDK的最低版本改为3.10.4。

修复

  • 修复了姿势名输入转移到其他姿势，以及排序时详情关闭的问题。
  • 修复了预览重叠、放置位置偏移及某些虚拟形象报错的问题。
  • 修复了设置变化后警告和预构建状态的更新，以及部分构建错误。
