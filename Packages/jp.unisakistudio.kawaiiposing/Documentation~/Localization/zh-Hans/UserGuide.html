Kawaii Posing Tool — 简体中文用户指南

Kawaii Posing为桌面和3点VR提供85种姿势：15种站姿、20种半蹲/椅子坐姿、17种地面坐姿、17种仰卧和16种俯卧姿势。

本指南涵盖安装、头像设置、VRChat操作、姿势编辑、更新和故障排查。购买的ZIP内包含START_HERE.html，可快速进入安装说明。

开始前

  • 使用通过VRChat Creator Companion（VCC）或ALCOM创建、管理的Unity 2022.3 VRChat虚拟形象项目。
  • 所需软件包：VRChat Avatars SDK 3.10.4或更高版本；Modular Avatar 1.x，版本1.15.1或更高；NDMF 1.x，版本1.14.0或更高。
  • 工具适用于桌面模式和3点VR（头显与两个控制器）的Humanoid虚拟形象。不支持全身跟踪启用期间的姿势固定。
  • 安装或更新前请备份现有项目，并先解决Unity中所有编译错误。
  • 安装程序会从软件包仓库下载商品和依赖，需要互联网连接。此ZIP不包含虚拟形象模型、VRChat SDK、Modular Avatar或NDMF。

1. 安装许可证与商品

  1. 将整个ZIP解压到Unity项目以外的普通文件夹。
  2. 在Unity中打开目标虚拟形象项目。通过Assets > Import Package > Custom Package导入Installer/KawaiiPosing_Installer.unitypackage，也可使用Unity打开该文件。
  3. 阅读导入和安装提示。许可证确认框会说明将安装哪些商品许可证。可通过确认框中的语言…（或言語...）更改安装程序语言。
  4. 确认安装许可证。许可证也涵盖本商品所用的共用Unisaki Posing System。安装程序之后可能提议删除自身的安装文件；此清理不会移除已安装的商品许可证。
  5. 查看自动软件包安装程序的确认内容，其中会列出拟添加的软件包与仓库，以及拟删除的旧文件或文件夹。确认这些项目正是所需内容后再继续。
  6. 等待Unity完成导入和编译。如果未自动完成软件包安装，请在VCC或ALCOM中打开此项目，添加Kawaii Posing Tool和Modular Avatar。共用Unisaki Posing System和NDMF会作为依赖安装。Optional-VCC-Links包含商品原附的仓库快捷方式，供Windows VCC用户使用。
  7. 若取消了确认，准备好后可重新导入安装程序。激活程序仍在项目中时，也可使用Tools > Unisaki Studio中的许可证安装命令。旧版中此子菜单名为ゆにさきスタジオ。

此下载会安装什么

Kawaii Posing Tool 3.2.0与Unisaki Posing System 3.2.0。此版本正在开发，尚未发布。它为安装对话框、Unity Inspector与菜单、标准姿势名、游戏内菜单和离线文档新增30种语言。发布日期尚未确定。可通过Inspector顶部的语言选择器切换工具语言。发布后，安装程序将从VPM仓库下载这些版本及其兼容依赖。本地发布准备不会公开这些软件包。

Kawaii Posing Tool包含姿势库、配置工具和虚拟形象调整预设。安装程序会激活商品现有的本地许可证，不需要新增的Gumroad许可证密钥输入栏。请勿在公开支持请求中上传安装程序文件或许可证数据。

语言偏好通过Unity EditorPrefs按当前OS用户保存，同一台计算机上的Unity项目共用。未保存偏好时，安装程序遵循OS语言；不支持时使用英语。商品许可证保留原有存储方式：Windows使用当前用户的Software/UnisakiStudio注册表项，macOS/Linux使用按用户保存的许可证文件。更改语言不会删除许可证。

2. 向虚拟形象添加工具

  1. 在Hierarchy中选中带有VRC Avatar Descriptor的虚拟形象，或其子对象。请使用放置在场景中的虚拟形象，不要使用Project窗口中的Prefab资源或Prefab Mode。
  2. 右键点击虚拟形象，选择Unisaki Studio > 添加Kawaii Posing。如已安装版本使用日语菜单，则选择ゆにさきスタジオ > 可愛いポーズツール追加。
  3. 工具会添加到虚拟形象内部。即使显示标签已翻译，保存的对象名也可能仍为可愛いポーズ。
  4. 如果提示存在适用的虚拟形象预设，请应用它作为初步适配。否则打开头像设置选择预设，或自行调整姿势。
  5. 安装程序可能提议执行预构建。预构建可选；普通虚拟形象构建也会生成所需数据。复用预构建可缩短后续构建时间。
  6. 选中工具对象，选择所需姿势与功能，然后按普通流程通过VRChat SDK上传虚拟形象。

本版本在工具Inspector顶部提供Language / 言語。同一选择控制Inspector和生成的游戏内菜单。所选语言保存在虚拟形象中，最后的选择也会用于此计算机上的其他工具和项目。要更改VRChat中显示的语言，请重新上传虚拟形象。

3. 选择姿势与功能

Inspector有3个主要选项卡：

选项卡用途
功能游戏内菜单控件、可选行为、呼吸、图标选项和表情参数用量。
姿势已启用姿势、分类与搜索、排序、添加动画、预览、详情及动画调整。
头像设置头像专属修正与膝部修正、原始或自定义动作导入及预设。

仅启用计划使用的菜单控件。例如，向菜单添加左右镜像，可让您在VRChat中切换镜像，并不会强制所有姿势始终保持镜像。

Kawaii Posing包含虚拟形象预设及适用姿势的IK。3种标准仰卧姿势已经指定了侧躺动作：伸腿坐（足伸ばし）、放松（リラックス）和支起单膝（膝立て）。如果编辑或替换过这些项目，请使用适用的预设，并检查各姿势的翻身设置。

预设与适配

预设位于头像设置靠下方。按虚拟形象名称搜索，再应用预设以替换当前姿势设置。更改预设前请保存或备份调整。预设是初步适配：体型比例、服装和虚拟形象修改仍可能需要手动修正。

对姿势使用动画调整，即可预览和编辑身体、手脚位置。完成后请从该窗口保存调整动画。对于支持的姿势，可整体及按姿势启用手脚自动调整（IK）。将当前IK结果烘焙到调整中，会创建调整动画并关闭该姿势的IK，以便继续手动细调；原始来源片段会保留。

防止膝盖反折提供最小膝盖弯曲角度等附加设置。仅存在对应修正数据时，才可使用头像专属修正，某些修正无法与姿势IK并用。

原始动作与自定义动作

使用头像原有的站立、蹲下和俯卧姿势会在生成时从虚拟形象的Base层检测动作。使用自定义动作会打开各动作类型的独立导入设置。每种类型选择一个动作。某类型的手动指定优先于该类型的自动导入。

自动导入会应用于构建副本，不会将检测到的动画写回场景中的手动指定列表，也不会修改原始控制器。如果希望重新由自动检测处理某类型，请清除该类型的手动覆盖。自定义Base层和其他移动系统可能需要单独调整。

4. 在VRChat中使用工具

打开虚拟形象的Expressions菜单，进入Kawaii Posing。为需要使用的各姿势分类选择姿势。选择姿势和选择功能是两个独立操作。

  • 3点VR：通过抬高或降低头部，在站立、半蹲/椅子坐姿、地面坐姿和躺姿之间切换。如果切换过早或过晚，可在工具设置菜单中调整高度阈值。
  • 桌面模式：使用C蹲下，使用Z躺下。如果按Z后仍为坐姿，请在设置菜单中提高躺姿高度阈值。
  • 俯卧/仰卧：工具根据面部朝向选择俯卧或仰卧。两者都选择时，可原地跳跃切换。如不需要，可在Unity的功能 > 便捷功能中关闭跳跃切换；此功能不额外消耗同步参数。
  • 固定：按需使用头部、手臂和双脚固定。想使用姿势中的手型而非控制器手势输入时，可禁用手势。
  • 左右镜像：镜像当前姿势，以朝向朋友或配合构图。

脚部高度与地面高度

脚部高度会保持头部位置，仅调整双脚。头部高度已正确，但双脚悬空或陷入地面时，可使用此功能。

地面高度会移动包含头部的整个身体。适用于沙发、床或较高平面，也适用于没有碰撞体的家具。共用系统当前采用居中的控件，50%为原始高度，0%为向下3 m，100%为向上3 m。恢复至50%附近即可结束偏移。旧版控件行为可能不同，请确认已安装版本，并将共用系统与商品一同更新。

拍照模式

上传前在Unity中启用拍照模式菜单项。在VRChat中选择姿势，通过距离向前移动，最远3 m，通过朝向旋转虚拟形象。安排构图时，双脚固定可按需使用。结束拍照会重置距离和朝向，并解除双脚固定。

拍照模式默认仅本地显示。若要让其他人看到位置和朝向，上传前请在Unity中启用同步拍照模式，使用16个同步bit。拍照模式中保持头部可见只影响自己的画面，不消耗同步bit。

呼吸与翻身

可在功能 > 便捷功能 > 启用呼吸动画中按姿势分类设置呼吸。可选择无、弱、中、强、急或自定义呼吸动画。动作本身不消耗同步bit，呼吸菜单开关使用1 bit。

翻身需要支持的躺姿和翻身菜单项。请对该姿势启用翻身，并按需提供侧躺动画。在VRChat中选择该姿势、启用翻身并解除头部/颈部固定，随后头部的侧向倾斜会控制翻身。姿势使用翻身时，无法再使用普通MotionTime控制。

上方列出的3种标准仰卧姿势包含侧躺动作。其他姿势需要合适的动作和姿势设置。导入或自定义预设中的指定可能不同。

5. 编辑、添加与预览姿势

在姿势中选择分类或使用搜索选项卡。搜索支持原始日语名称及已有译名。打开姿势的详情，可编辑动画、图标、顺序和时间设置。

批量添加动画时，可将片段拖放到添加区域，或在Project窗口选中片段后使用导入所选片段的命令。同一片段的重复引用会被移除。可在详情中更改目标顺序，或使用上下移动控件。

预览可直接在Scene视图中显示姿势，无需打开完整调整窗口。此轻量预览不运行Modular Avatar或NDMF，因此服装、地面修正及其他构建期功能，请在最终虚拟形象构建结果中确认。

根据虚拟形象生成的姿势图标有助于辨认姿势，但生成需要时间，也可能增加虚拟形象数据体积。可降低图标分辨率以节省空间。Android构建不会生成姿势图标。更改虚拟形象或服装后，请按需重新生成图标。

6. 参数内存

Inspector显示的是姿势工具占用的部分，而非整个虚拟形象的总量。服装和其他系统可能额外使用参数内存。多个姿势工具共享的设置不会重复计数。增加大量额外姿势的自定义配置，可能需要更多姿势选择bit。

7. 更新与预构建

  1. 备份项目并保存当前工作场景。
  2. 在VCC或ALCOM中，将Kawaii Posing Tool和共用Unisaki Posing System一同更新，同时保持所需SDK、Modular Avatar和NDMF版本兼容。
  3. 等待编译完成。选中已安装的工具，检查姿势、设置和参数用量。
  4. 如果使用预构建，请选择更新预构建，然后重新上传虚拟形象。

现有工具设置会保留。旧8-bit Prefab会为兼容性保留，现有引用无需删除或替换工具。新安装使用普通Prefab，可禁用不需要的功能以降低参数用量。

预构建过期警告表示：缓存构建数据生成后，设置发生了变化。更新预构建会重新生成这些数据。隐藏警告不会更新预构建，也不会解决其根本问题。即使不每次手动预构建，普通虚拟形象构建也能生成所需数据。
