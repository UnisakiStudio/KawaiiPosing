Kawaii Posing Tool

这是一款面向VRChat的姿势固定工具，即使使用3点跟踪或桌面模式，也能使用可爱的坐姿和躺姿。共收录85种姿势：站立15种、半蹲20种、坐姿17种、俯卧16种、仰卧17种。

本README面向开发中的v3.2.0。正式发布日期尚未确定。已安装的版本可在Inspector顶部查看。

显示语言与离线文档

在Inspector最上方的“Language / 言語”中选择显示语言。同一项选择会同时应用于Inspector和生成的VRChat菜单。要更改游戏内的显示语言，请重新上传虚拟形象。

未选择语言时，使用计算机的语言；不支持该语言时使用英语。支持Windows、macOS和Linux。最后选择的语言保存在EditorPrefs中，同一台计算机上同一个OS用户的其他项目也会使用此设置。已明确保存在虚拟形象中的语言选择会予以保留。语言设置不会同步到其他计算机。许可证的保存方式不变。

可通过随附的语言列表选择README、更新记录和使用说明。Inspector中的“使用说明”和“更新记录”也会遵循所选语言。原始使用条款和参考译文仍按原有方式另行提供。

主要功能

  • 拍照模式：可将虚拟形象向前移动，最远达3m，并调整朝向。仅自己的画面使用时为0 bit；向其他人同步位置和朝向时为16 bit。
  • 拍照时的头部显示：可仅在拍照模式中，防止靠近自己的虚拟形象头部被隐藏。
  • 地面高度：可将包含头部的整个身体上下移动3m。50%为原始高度及初始值，0%为向下3m，100%为向上3m。可与保持头部位置、移动脚部一侧的“脚部高度”分别使用。
  • 翻身：在支持的躺姿中，根据头部倾斜向左右翻身。
  • 呼吸：可为胸部等添加呼吸动作。各姿势分类可选择“无、弱、中、强、急、自定义”。
  • 关闭VRChat默认站立摇摆：抑制默认待机摇摆，同时保留姿势工具的呼吸和其他自定义动作。
  • 减轻头部旋转造成的姿势变形：解除颈部固定时，减轻头部朝向与原始姿势不同导致的姿势变形。
  • 功能选择：仅添加所需游戏内菜单，并在Inspector中查看ExpressionParameters用量。
  • 姿势搜索、批量添加与排序：支持跨分类搜索、导入多个片段和指定目标顺序。
  • Scene简易预览：通过姿势列表的“预览”即可原地查看姿势。
  • 手脚自动调整（IK）：在支持的姿势中，根据虚拟形象体型调整手脚位置。可按姿势切换开关，也可将结果烘焙到调整动画中。

使用附带姿势翻身

仰卧姿势“伸腿坐”“放松”“支起单膝”已设置用于翻身的侧躺姿势，分别以“横向き寝”（侧卧）、“午睡”“猫咪小憩”为基础生成翻身。

启用“功能 > 菜单功能 > 翻身”后上传，在VRChat中选择对应姿势和“翻身”。使用时请解除颈部固定。

自行设置支持翻身的姿势时，请启用“姿势 > 详情 > 启用翻身”，并在“翻身侧向姿势”中指定动画。启用翻身的姿势无法再使用普通MotionTime设置。

根据体型调整

可使用附带的手脚自动调整，但并非所有姿势都需要IK。可在动画调整界面通过“启用手脚自动调整”切换整体设置，通过“对此姿势启用IK”切换单个姿势。

“将IK烘焙到调整中”会将当时的自动调整结果写入新的调整动画，并关闭目标姿势的IK，之后可继续手动完成。只有整体和目标姿势的自动调整已启用，且存在可应用的IK设置时才可使用。

“头像设置”中也提供“防止膝盖反折”，以及详情中的“最小膝盖弯曲角度（度）”。

安装方法

  1. 从购买商品的商店页面下载文件。
  2. 将随附的“可愛いポーズツール.unitypackage”导入Unity，注册许可证和软件包来源。
  3. 在VCC或ALCOM中，向所用Unity项目添加Kawaii Posing Tool和Modular Avatar。共用的Unisaki Posing System和NDMF也会作为依赖软件包安装。
  4. 在Hierarchy中右键点击目标虚拟形象，选择“Unisaki Studio > 添加Kawaii Posing”。
  5. 选中添加到虚拟形象内的“可愛いポーズ”，在Inspector中设置所需功能和姿势。
  6. 按普通流程上传虚拟形象。

所需环境为Unity 2022.3、VRChat Avatars SDK 3.10.4或更高版本、Modular Avatar 1.15.1或更高版本的1.x系列，以及NDMF 1.14.0或更高版本的1.x系列。请通过VCC或ALCOM一同更新所需软件包。

从旧版本更新

请将本商品和Unisaki Posing System一同更新。已放置工具的设置会继承。请在Inspector确认启用功能和ExpressionParameters用量；如果使用过预构建，重新上传前请点击“更新预构建”。

从v3.1.0起，新添加对象统一使用普通“可愛いポーズ”Prefab。在“功能”中关闭不需要的项目后，仅使用姿势选择的最小配置为8 bit。姿势数量较多时，姿势选择可能需要额外的bit。

为保留现有虚拟形象和预设的引用，旧8bit版Prefab仍保存在“Editor/Legacy”中。无需删除或替换现有Prefab。Unity新建菜单不会显示8bit版本。

设置位置

选项卡可进行的操作
功能添加游戏内菜单、便捷功能、呼吸设置、图标图片和ExpressionParameters用量确认
姿势选择使用的姿势、详细设置、搜索、批量添加、顺序调整、预览、动画调整
头像设置头像专属修正、膝部修正、导入原始姿势或自定义动作、更改预设

点击“打开设置”，即可在该项目下方展开详细设置。呼吸通过“功能 > 便捷功能 > 启用呼吸动画”设置。

“使用头像原有的站立、蹲下和俯卧姿势”是自动导入虚拟形象原始姿势的功能。如需使用自己准备的动作，请通过单独的“打开导入设置”，为站立、蹲下（Crouching）、俯卧（Prone）等各类型分别指定。

预设位于“头像设置”的最下方。“应用此预设”会替换当前姿势设置，因此切换前请保存已有调整。

各功能用量

  • 呼吸动作使用0 bit。只有使用可在游戏内暂停和恢复的“菜单功能 > 呼吸”时，开关同步才使用1 bit。
  • 拍照模式仅在自己画面中显示时为0 bit。选择“便捷功能 > 同步拍照模式”时使用16 bit。“拍照模式中保持头部可见”为0 bit。
  • “脚部高度”“地面高度”各使用8 bit。地面高度离开中央时会上下移动，恢复至50%附近时结束修正。
  • “翻身”单独使用为10 bit。由于与“减轻头部旋转造成的姿势变形”共用1 bit，两者同时使用时合计仍为10 bit。
  • “左右镜像”“禁用手势”各使用1 bit。

Inspector的合计值仅涵盖安装在虚拟形象中的姿势工具，不包括服装等其他功能组件。即使并用多个姿势工具，共用设置也不会重复计数。

预览与姿势编辑

通过“姿势”中各姿势的“预览”，可在Scene显示姿势。需要细调时，打开“动画调整”，一边确认姿势一边调整并保存。

简易预览不会执行MA或NDMF的构建处理。构建时整合的服装、地面位置修正等，也请在上传前的构建结果中确认。

左侧的放大镜选项卡可搜索姿势名。可在“详情”的“顺序”中选择目标位置，也可通过上下按钮排序。多个动画可拖放到添加区域，或通过“导入Project中选择的片段”批量添加。

“更新姿势缩略图”会在确认对话框后生成图片。“生成姿势图标”可让游戏内菜单中的姿势更容易辨认，但生成图片会增加构建时间。如需降低容量，请选择“减小图标容量”。面向Android时不会生成姿势图标。

游戏内基本操作

  • 在Expressions菜单中选择各分类的姿势。VR模式会根据头部高度切换站立、半蹲、坐姿和躺姿。
  • 躺姿会根据面部朝向切换仰卧与俯卧；两者都已选择时，也可原地跳跃切换。可在Unity的“功能 → 便捷功能 → 跳跃切换躺姿”中关闭跳跃切换（默认启用）。分类切换的高度可通过设置菜单中的阈值调整。
  • 桌面模式使用C键、Z键切换姿势。如果按Z键未进入躺姿，请在设置菜单中提高“躺姿高度阈值”。
  • 启用“禁用手势”后，会使用姿势中设置的手型，代替控制器输入的手指形状。
  • “脚部高度”保持头部位置、调整脚部一侧。“地面高度”上下移动包含头部的整个身体。它们在设置菜单中按此顺序排列。
  • 在“拍照模式”中使用“距离”向前移动后，虚拟形象会朝向自己。通过“朝向”旋转，并在需要时启用“固定双脚”。“结束拍照”会恢复距离和朝向，并解除双脚固定。
  • “呼吸”仅在已启用呼吸动作时可用。强度在Unity中设置，游戏内仅切换开关。

预构建与警告

“更新预构建”通过复用生成数据，加快虚拟形象构建。即使不使用预构建，普通构建时也会生成所需数据。

更改设置后，会通过Inspector顶部的“检查设置”和Hierarchy标记提示更新。“警告显示设置”位于“检查设置”区域内。隐藏提示并不意味着设置问题已解决，或生成数据已更新。

使用注意事项

  • 不支持全身跟踪期间的姿势固定。
  • 根据体型、服装和虚拟形象修改内容，可能需要额外调整。
  • 可能无法与特殊Base层或其他姿势切换组件按预期整合。固定功能不正常时，也请检查“头像设置 > 与其他工具整合跟踪锁定”。
  • 拍照模式的移动、旋转及地面高度，也会修正未选择工具姿势时的默认和自定义动作。VRChat中的视点及默认动作替换后的表现，请在实际客户端中确认。
  • “关闭VRChat默认站立摇摆”针对默认待机动作，并非停止一切原因引起的摇摆。
