# Kawaii Posing Tool — מדריך למשתמש בעברית

Kawaii Posing מספק 85 תנוחות למצב שולחן עבודה ול-VR עם מעקב בשלוש נקודות: 15 עמידה, 20 כריעה/כיסא, 17 ישיבה על הרצפה, 17 שכיבה על הגב ו-16 שכיבה על הבטן.

מדריך זה מכסה התקנה, הגדרת אווטאר, פעולות ב-VRChat, עריכת תנוחות, עדכון ופתרון בעיות. קובץ ה-ZIP שרכשתם כולל את `START_HERE.html` למסלול המהיר ביותר להתקנה.

## לפני שמתחילים

- השתמשו בפרויקט **אווטאר** של VRChat ב-Unity 2022.3, שנוצר או מנוהל באמצעות VRChat Creator Companion (VCC) או ALCOM.
- חבילות נדרשות: VRChat Avatars SDK בגרסה 3.10.4 ומעלה; Modular Avatar מסדרת 1.x, בגרסה 1.15.1 ומעלה; NDMF מסדרת 1.x, בגרסה 1.14.0 ומעלה.
- הכלי מיועד לאווטארים מסוג Humanoid במצב שולחן עבודה וב-VR עם מעקב בשלוש נקודות (משקף ושני בקרים). נעילת תנוחות בזמן מעקב גוף מלא אינה נתמכת.
- גבו פרויקט קיים לפני התקנה או עדכון. פתרו תחילה שגיאות קומפילציה קיימות ב-Unity.
- המתקין מוריד את המוצר ואת התלויות ממאגרי החבילות שלהם. נדרש חיבור לאינטרנט. דגמי אווטארים, VRChat SDK, Modular Avatar ו-NDMF אינם כלולים בקובץ ZIP זה.

## 1. התקנת הרישיון והמוצר

1. חלצו את קובץ ה-ZIP כולו לתיקייה רגילה מחוץ לפרויקט Unity.
2. פתחו ב-Unity את פרויקט האווטאר הרצוי. ייבאו את `Installer/KawaiiPosing_Installer.unitypackage` באמצעות **Assets > Import Package > Custom Package**, או פתחו את הקובץ עם Unity.
3. קראו את הודעות הייבוא וההתקנה. אישור הרישיון מסביר אילו רישיונות מוצר יותקנו. השתמשו ב-**שפה…** (או **言語...**) בחלון אישור כדי לשנות את שפת המתקין.
4. אשרו התקנת רישיון. הרישיון מכסה גם את Unisaki Posing System המשותף שהמוצר משתמש בו. לאחר מכן המתקין עשוי להציע להסיר את קובצי ההתקנה של עצמו; ניקוי זה אינו מסיר את רישיון המוצר שהותקן.
5. בדקו את אישור מתקין החבילות האוטומטי. הוא מפרט חבילות ומאגרים שיתווספו, וקבצים או תיקיות ישנים שהוא מציע להסיר. המשיכו אם אלה הפריטים שהתכוונתם להתקין ולהסיר.
6. המתינו לסיום הייבוא והקומפילציה ב-Unity. אם התקנת החבילות אינה מסתיימת אוטומטית, פתחו את הפרויקט ב-VCC או ב-ALCOM והוסיפו **Kawaii Posing Tool** ו-**Modular Avatar**. המערכת המשותפת **Unisaki Posing System** ו-**NDMF** הן תלויות. `Optional-VCC-Links` מכיל את קיצורי הדרך המקוריים למאגרים שסופקו עם המוצר למשתמשי VCC ב-Windows.
7. אם ביטלתם אישור, ייבאו שוב את המתקין כשתהיו מוכנים. אפשר גם להשתמש בפקודת התקנת הרישיון תחת **Tools > Unisaki Studio** כל עוד רכיב ההפעלה עדיין נמצא בפרויקט. בבניות ישנות שם תפריט המשנה הוא **ゆにさきスタジオ**.

### מה מותקן מהורדה זו

**Kawaii Posing Tool 3.2.0 עם Unisaki Posing System 3.2.0.** גרסה זו נמצאת בפיתוח וטרם שוחררה. היא מוסיפה שלושים שפות לחלונות ההתקנה, ל-Inspector ולתפריטי Unity, לשמות התנוחות הרגילות, לתפריטי המשחק ולתיעוד הלא מקוון. טרם נקבע תאריך שחרור. השתמשו בבורר השפה בראש ה-Inspector כדי לשנות את שפת הכלי. לאחר הפרסום, המתקין יוריד גרסאות אלה ואת התלויות התואמות ממאגרי VPM. הכנת שחרור מקומית אינה מפרסמת את החבילות האלה.

Kawaii Posing Tool כולל ספריית תנוחות, כלי הגדרה ותצורות מוכנות להתאמת האווטאר. המתקין מפעיל את הרישיון המקומי הקיים של המוצר; אין צורך בשדה חדש למפתח רישיון של Gumroad. לעולם אל תפרסמו קובצי מתקין או נתוני רישיון בבקשת תמיכה ציבורית.

העדפות השפה נשמרות באמצעות Unity EditorPrefs עבור המשתמש הנוכחי במערכת ההפעלה, ומשותפות לפרויקטי Unity במחשב זה. ללא העדפה שמורה המתקין משתמש בשפת מערכת ההפעלה; שפות שאינן נתמכות משתמשות באנגלית. רישיונות המוצרים שומרים את האחסון הקיים: מפתח הרישום `Software/UnisakiStudio` של המשתמש הנוכחי ב-Windows, וקובצי רישיון לכל משתמש ב-macOS/Linux. שינוי שפה אינו מסיר רישיון.

## 2. הוספת הכלי לאווטאר

1. ב-**Hierarchy** בחרו את האווטאר עם **VRC Avatar Descriptor**, או אחד מאובייקטי הבן שלו. השתמשו באווטאר שהוצב בסצנה, ולא בנכס Prefab בחלון Project או ב-Prefab Mode.
2. לחצו לחיצה ימנית על האווטאר ובחרו **Unisaki Studio > הוספת Kawaii Posing**. אם הבנייה המותקנת משתמשת בתפריטים יפניים, בחרו **ゆにさきスタジオ > 可愛いポーズツール追加**.
3. הכלי נוסף בתוך האווטאר. שם האובייקט השמור עשוי להישאר **可愛いポーズ** גם כאשר תוויות התצוגה מתורגמות.
4. אם מוצעת תצורה מוכנה התואמת לאווטאר, החילו אותה כהתאמה ראשונית. אחרת פתחו **הגדרת אווטאר**, ובחרו תצורה מוכנה או התאימו את התנוחות בעצמכם.
5. המתקין עשוי להציע חישוב מקדים. חישוב מקדים הוא אופציונלי; גם בנייה רגילה של האווטאר יוצרת את הנתונים הדרושים. שימוש חוזר בחישוב מקדים מקצר בניות מאוחרות יותר.
6. בחרו את אובייקט הכלי ואת התנוחות והתכונות הרצויות, ואז העלו את האווטאר כרגיל באמצעות VRChat SDK.

### בחירת שפה ותוויות מוכרות

גרסה זו מציעה **Language / 言語** בראש ה-Inspector של הכלי. בחירה אחת זו שולטת ב-Inspector ובתפריט המשחק שנוצר. האווטאר שומר את השפה שנבחרה, והבחירה האחרונה זכורה לכלים ולפרויקטים אחרים במחשב זה. העלו את האווטאר מחדש כדי לשנות את השפה המוצגת ב-VRChat.

השתמשו בטבלת התוויות הבאה כשאתם נעזרים במדריכים יפניים ישנים. גרסה זו כוללת בורר שפה, Inspector מתורגם, שמות מתורגמים לתנוחות הרגילות ותפריטי משחק בכל 30 השפות.

## 3. בחירת תנוחות ותכונות

ב-Inspector יש שלוש כרטיסיות עיקריות:

| כרטיסייה | שימוש |
| --- | --- |
| **תכונות** | פקדים בתפריט המשחק, התנהגות אופציונלית, נשימה, אפשרויות סמלים ושימוש בפרמטרי הבעה. |
| **תנוחות** | תנוחות מופעלות, קטגוריות וחיפוש, סדר, הוספת אנימציות, תצוגה מקדימה, פרטים והתאמת אנימציה. |
| **הגדרת אווטאר** | תיקונים ייחודיים לאווטאר ולברכיים, ייבוא תנועות מקוריות ואישיות ותצורות מוכנות. |

הפעילו רק פקדי תפריט שבכוונתכם להשתמש בהם. לדוגמה, הוספת **שיקוף** לתפריט מאפשרת לשנות שיקוף ב-VRChat; היא אינה משאירה כל תנוחה משוקפת תמיד.

Kawaii Posing כולל תצורות מוכנות לאווטארים ו-IK לתנוחות נתמכות. לשלוש תנוחות רגילות של שכיבה על הגב כבר הוקצו תנועות שכיבה על הצד: **רגליים ישרות (足伸ばし)**, **רגוע (リラックス)** ו-**ברך אחת למעלה (膝立て)**. השתמשו בתצורה מוכנה תואמת ובדקו את הגדרת ההתהפכות של כל תנוחה אם ערכתם או החלפתם פריטים אלה.

### תצורות מוכנות והתאמה

התצורות המוכנות נמצאות סמוך לתחתית **הגדרת אווטאר**. חפשו לפי שם האווטאר והחילו תצורה מוכנה כדי להחליף את הגדרות התנוחה הנוכחיות. שמרו או גבו התאמות לפני החלפת תצורה מוכנה. תצורה מוכנה היא נקודת התחלה: ייתכן שמבנה הגוף, הבגדים ושינויים באווטאר עדיין יחייבו תיקונים ידניים.

השתמשו ב-**התאמת אנימציה** של תנוחה כדי להציג ולערוך מיקום גוף וגפיים. בסיום שמרו את אנימציית ההתאמה מאותו חלון. כאשר יש תמיכה, אפשר להפעיל התאמה אוטומטית של ידיים ורגליים (IK) ברמת הכלי ולכל תנוחה. הטמעת תוצאת ה-IK הנוכחית בהתאמה יוצרת אנימציית התאמה ומכבה את ה-IK של התנוחה, כדי שתוכלו להמשיך ידנית; קליפ המקור נשמר.

ל-**מניעת כיפוף ברכיים לאחור** יש הגדרות נוספות, כגון כיפוף ברך מזערי. תיקונים ייחודיים לאווטאר זמינים רק אם קיימים נתוני תיקון מתאימים, וחלק מהתיקונים אינם ניתנים לשילוב עם IK של תנוחה.

### תנועות מקוריות ואישיות

**שימוש בתנוחות העמידה, הכריעה והשכיבה על הבטן המקוריות** מזהה תנועות משכבת Base של האווטאר בזמן היצירה. **שימוש בתנועות שלכם** פותח הגדרות ייבוא נפרדות לכל סוג תנועה. בחרו תנועה אחת לכל סוג. הקצאה ידנית מקבלת עדיפות על הייבוא האוטומטי של אותו סוג.

ייבוא אוטומטי חל על עותק הבנייה. הוא אינו כותב אנימציות שזוהו לרשימת ההקצאות הידניות בסצנה ואינו משנה את ה-Controller המקורי. נקו הקצאה ידנית של סוג כדי לאפשר שוב זיהוי אוטומטי. שכבות Base אישיות ומערכות תנועה אחרות עשויות לדרוש התאמות נפרדות.

## 4. שימוש בכלי ב-VRChat

פתחו את תפריט **Expressions** של האווטאר והיכנסו ל-**Kawaii Posing**. בחרו תנוחה לכל קטגוריית יציבה שתרצו להשתמש בה. בחירת תנוחה ובחירת תכונה הן פעולות נפרדות.

- **VR עם מעקב בשלוש נקודות:** הנמיכו או הגביהו את הראש כדי לעבור בין עמידה, כריעה/כיסא, ישיבה על הרצפה ושכיבה. התאימו את ספי הגובה בתפריט הגדרות הכלי אם היציבה משתנה מוקדם או מאוחר מדי.
- **שולחן עבודה:** השתמשו ב-**C** לכריעה וב-**Z** לשכיבה. אם Z משאיר אתכם בישיבה, הגדילו את סף גובה השכיבה בתפריט ההגדרות.
- **שכיבה על הבטן/הגב:** הכלי בוחר ביניהן לפי כיוון הפנים. כששתיהן נבחרו, קפיצה במקום יכולה להחליף ביניהן. אפשר לבטל החלפה בקפיצה ב-Unity תחת **תכונות > תכונות שימושיות**; היא אינה מוסיפה שימוש בפרמטרים מסונכרנים.
- **נעילות:** השתמשו בנעילות הראש, הזרועות והרגליים לפי הצורך. השביתו מחוות אם תרצו להשתמש בצורת היד של התנוחה במקום במחוות הבקר.
- **שיקוף:** שקפו תנוחה שנבחרה כדי לפנות אל חבר או להתאים לקומפוזיציה.

### גובה כפות רגליים וגובה רצפה

**גובה כפות רגליים** מתאים את הרגליים תוך שמירת מיקום הראש. השתמשו בו כשכפות הרגליים מרחפות או שוקעות והראש כבר בגובה הנכון.

**גובה רצפה** מזיז את הגוף כולו, כולל הראש. השתמשו בו לספה, למיטה או למשטח מוגבה, גם אם לרהיט אין collider. בפקד הממורכז הנוכחי של המערכת המשותפת, **50% הוא הגובה המקורי**, 0% הוא 3 m מתחתיו ו-100% הוא 3 m מעליו. החזירו לקרבת 50% כדי לסיים את ההיסט. בגרסאות ישנות התנהגות הפקד עשויה להיות שונה; בדקו את הגרסה המותקנת ועדכנו את המערכת המשותפת יחד עם המוצר.

### מצב צילום

הפעילו את פריט התפריט **מצב צילום** ב-Unity לפני ההעלאה. ב-VRChat בחרו תנוחה, השתמשו ב-**מרחק** כדי לנוע עד 3 m קדימה, וב-**כיוון** כדי לסובב את האווטאר. נעילת רגליים היא אופציונלית בזמן ארגון הצילום. **סיום צילום** מאפס את המרחק והסיבוב ומשחרר את נעילת הרגליים.

מצב צילום הוא מקומי כברירת מחדל. כדי שאחרים יראו את המיקום והסיבוב, הפעילו **סנכרון מצב צילום** ב-Unity לפני ההעלאה; האפשרות משתמשת ב-16 סיביות מסונכרנות. **השארת הראש גלוי במצב צילום** משפיעה על התצוגה שלכם בלבד ואינה משתמשת בסיביות מסונכרנות.

### נשימה והתהפכות

אפשר להגדיר נשימה לכל קטגוריית יציבה תחת **תכונות > תכונות שימושיות > אנימציית נשימה**. בחרו ללא, חלש, בינוני, חזק, מהיר או אנימציית נשימה מותאמת אישית. התנועה עצמה אינה משתמשת בסיביות מסונכרנות. מתג נשימה בתפריט משתמש ב-1 bit.

התהפכות מחייבת תנוחת שכיבה נתמכת ואת פריט התפריט **התהפכות**. הפעילו התהפכות עבור התנוחה והקצו אנימציית צד בעת הצורך. ב-VRChat בחרו את התנוחה, הפעילו התהפכות ושחררו את נעילת הראש/הצוואר. הטיית הראש הצדה שולטת כעת בהתהפכות. בקרת MotionTime הרגילה אינה זמינה לתנוחה זו בזמן שימוש בהתהפכות.

שלוש תנוחות השכיבה על הגב הרגילות שפורטו לעיל כוללות תנועות צד. תנוחות אחרות דורשות תנועה מתאימה והגדרת תנוחה. תצורות מוכנות מיובאות או אישיות עשויות לכלול הקצאות שונות.

## 5. עריכה, הוספה ותצוגה מקדימה של תנוחות

ב-**תנוחות** בחרו קטגוריה או השתמשו בכרטיסיית החיפוש. החיפוש מקבל את השמות המקוריים ביפנית ואת התרגומים הזמינים. פתחו את **פרטים** של התנוחה כדי לערוך אנימציה, סמל, סדר ואפשרויות תזמון.

כדי להוסיף כמה אנימציות, גררו קליפים לאזור ההוספה או בחרו קליפים בחלון Project והשתמשו בפקודת ייבוא הקליפים שנבחרו. הפניות כפולות לאותו קליפ מוסרות. שנו את מיקום היעד בפרטים או השתמשו בפקדי מעלה/מטה.

**תצוגה מקדימה** מציגה תנוחה ב-Scene בלי לפתוח את חלון ההתאמה המלא. תצוגה קלה זו אינה מפעילה Modular Avatar או NDMF, ולכן בדקו את בניית האווטאר הסופית עבור בגדים, תיקון רצפה ותכונות נוספות המוחלות בזמן הבנייה.

סמלי תנוחות שנוצרים מהאווטאר עוזרים לזהות תנוחות, אך היצירה אורכת זמן ועשויה להגדיל את נתוני האווטאר. הקטינו את רזולוציית הסמלים כדי לחסוך מקום. בבניות Android לא נוצרים סמלי תנוחות. צרו אותם מחדש אחרי שינוי האווטאר או הבגדים לפי הצורך.

## 6. זיכרון פרמטרים

ה-Inspector מציג את חלקם של כלי התנוחות, ולא את הסכום של האווטאר כולו. בגדים ומערכות אחרות עשויים להשתמש בזיכרון פרמטרים נוסף. הגדרות משותפות לכמה כלי תנוחות אינן נספרות פעמיים. תצורות אישיות עם תנוחות נוספות רבות עשויות לדרוש יותר סיביות לבחירת תנוחה.

| תכונה | סיביות מסונכרנות נוספות |
| --- | ---: |
| בחירת תנוחה, תצורה רגילה מזערית | 8 |
| שיקוף | 1 |
| ללא מחוות | 1 |
| תנועת נשימה | 0 |
| מתג נשימה בתפריט | 1 |
| גובה כפות רגליים | 8 |
| גובה רצפה | 8 |
| מצב צילום, מקומי בלבד | 0 |
| סנכרון מצב צילום | 16 |
| השארת הראש גלוי במצב צילום | 0 |
| השבתת תנודות עמידה רגילות של VRChat | 0 |
| התהפכות | 10 |

התהפכות חולקת 1 bit עם תיקון התנוחה לפי כיוון הצוואר: הפעלת שתי התכונות יחד עדיין משתמשת ב-10 סיביות בסך הכול עבור שתיהן. השימוש המוצג בגרסה המותקנת הוא הנתון המעשי עבור התצורה שבחרתם.

## 7. עדכון וחישוב מקדים

1. גבו את הפרויקט ושמרו את הסצנה שאתם עובדים עליה.
2. ב-VCC או ב-ALCOM עדכנו יחד את **Kawaii Posing Tool** ואת **Unisaki Posing System** המשותף. שמרו גם על גרסאות תואמות של SDK, Modular Avatar ו-NDMF הנדרשים.
3. המתינו לסיום הקומפילציה. בחרו את הכלי שכבר מותקן ובדקו את התנוחות, ההגדרות והשימוש בפרמטרים.
4. אם אתם משתמשים בחישוב מקדים, בחרו **עדכון חישוב מקדים** והעלו שוב את האווטאר.

הגדרות הכלי הקיימות נשמרות. קובצי Prefab ישנים של 8-bit נשארים לצורך תאימות; הפניות קיימות אינן מחייבות מחיקה או החלפה של הכלי. התקנות חדשות משתמשות ב-Prefab הרגיל, ואפשר לכבות תכונות שאינן בשימוש כדי לצמצם שימוש בפרמטרים.

אזהרה על חישוב מקדים לא מעודכן פירושה שההגדרות השתנו מאז יצירת נתוני הבנייה שבמטמון. עדכון החישוב המקדים יוצר את הנתונים מחדש. הסתרת אזהרה אינה מעדכנת את החישוב המקדים ואינה פותרת את הבעיה שבבסיסה. בניית אווטאר רגילה יכולה ליצור את הנתונים הדרושים גם בלי לבצע חישוב מקדים ידנית בכל פעם.
