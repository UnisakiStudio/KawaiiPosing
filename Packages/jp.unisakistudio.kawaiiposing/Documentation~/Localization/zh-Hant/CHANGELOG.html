更新紀錄

[3.2.0] - 尚未發佈

新增

  • Inspector、編輯操作、安裝對話框、標準姿勢名和產生的VRChat選單現支援30種顯示語言。
  • 統一了Inspector和遊戲內選單的語言選擇。初始使用電腦語言，同一OS使用者的其他專案也會使用最後的選擇。
  • 支援以所選語言開啟README、更新紀錄和離線使用說明。
  • 依照現有術語，補齊了128個標準姿勢的顯示名和各功能說明。

相容性

  • 保留虛擬化身的現有設定、自訂名稱、資源參照、參數識別碼和授權儲存方式。

[3.1.2] - 2026-11-09

  • 即使關閉“腳部高度”，也可通過EX選單的“設定 → 仰臥時自動鎖定頭部”切換頭部固定。舊版中該項目消失的虛擬化身，更新後建置即可恢復。
  • 支援Unisaki Posing System 3.1.2。修復了使用“減輕頭部旋轉造成的姿勢變形”時，從俯臥站起後面部仍保持朝上的問題。

請在ALCOM / VCC中將Kawaii Posing Tool更新為3.1.2。Unisaki Posing System也須為3.1.2。如果此前使用過預先建置，請按一下“更新預先建置”並儲存場景，然後重新建置、上傳虛擬化身。

[3.1.1] - 2026-11-08

  • 即使關閉“左右鏡像”，已啟用的“地面高度”和“翻身”也會顯示在VRChat EX選單的“設定”中。
  • 即使舊版中對姿勢進行了排序、刪除或改名，也能將正確的翻身分別繼承到“伸腿坐”“放鬆”“支起單膝”。完全Unpack後，只要能識別原始姿勢，也能繼承。自訂姿勢、使用者自行關閉的翻身及替換的側躺動作會保留。
  • 修復了在VRChat選擇虛擬化身時會瞬間俯臥的問題，也修復了僅選擇俯臥姿勢時跳躍會瞬間仰臥的問題。跳躍切換可通過“功能 → 便利功能 → 跳躍切換躺姿”關閉，預設啟用。
  • 更新後，如果共用姿勢Animator Controller的參照丟失，在可恢復時會顯示警告並根據設定重建。多個虛擬化身共用的Controller參照也會保留。
  • 即使存在使用者自行儲存的同名“可愛いポーズ”Prefab，也可通過新增工具選單放置正式Prefab。
  • 選擇“添い寝ツール追加”時，若找不到聯動所需的添い寝ツール，會提示先安裝對應商品。

請在ALCOM / VCC中將Kawaii Posing Tool和Unisaki Posing System均更新為3.1.1。如果此前使用過預先建置，請在場景中的“可愛いポーズ”上按一下“更新預先建置”並儲存場景。要在VRChat中生效，請重新建置、上傳虛擬化身。

[3.1.0] - 2026-11-07

  • 收錄的85種姿勢中，53種可根據虛擬化身體型，通過IK自動調整手腳。
  • 仰臥姿勢“伸腿坐”“放鬆”“支起單膝”支援根據頭部傾斜翻身。
  • 拍照模式可調整虛擬化身的位置和朝向，也可選擇同步位置、朝向，以及拍照時顯示自己的頭部。
  • “地面高度”可上下移動整個身體，最大距離為3m，可與“腳部高度”分別使用。
  • 新增呼吸動作、關閉預設待機搖擺及減輕頭部朝向造成姿勢變形的設定。
  • 可在Inspector查看啟用功能和參數用量，並支援姿勢搜尋、批次加入、排序及Scene簡易預覽。
  • 加快桌面模式中站立、半蹲和坐姿的切換。
  • 改善設定變化後的預先建置警告、Inspector滾動負擔及清理產生資源時的長時間停頓。
  • 支援Unisaki Posing System 3.1.0。

[3.1.0-beta.2] - 公開測試版（2026-11-05）

  • 開始通過GitHub Releases和VPM分發公開測試版。收錄的85種姿勢中，53種可根據體型通過IK自動調整手腳。
  • 支援共用套件3.1.0-beta.2。改善預先建置後的變化提示、Inspector滾動負擔及清理產生資源時的停頓。

[3.1.0-beta.1] - 公開測試版（2026-11-04）

  • 支援Unisaki Posing System 3.1.0-beta.1。
  • 將桌面模式的一般姿勢切換改為1次求值方式。一般建置和預先建置均啟用，VR及特殊條件下保留原有流程。
  • 將alpha.3及更早版本的預先建置識別為需要更新。
  • 拍照期間改變地面高度時保持視點，並在結束拍照後恢復至最新地面高度。
  • 納入截至alpha.3對自動匯入、匯入動作調整及產生Controller管理的改進。

[3.1.0-alpha.2] - 封閉測試版（2026-10-26）

修復與更改

  • 將共用姿勢系統更新為3.1.0-alpha.2，並納入除錯修復。
  • 將地面高度擴充為上下3m。50%為原始高度及初始值。
  • 將未選擇工具姿勢時的預設和自訂動作，也納入拍照和地面高度修正範圍。
  • 修復手動修正、同名姿勢、初始姿勢及舊預設翻身設定等問題。

[3.1.0-alpha.1] - 發佈前

新增

  • 新增根據體型進行的手腳自動調整（IK）。
  • 新增IK整體和各姿勢的開關，以及烘焙到調整動畫的操作。
  • 仰臥姿勢“伸腿坐”“放鬆”“支起單膝”支援根據頭部傾斜翻身。
  • 新增各姿勢的翻身設定及側躺動畫指定。
  • 新增可調整向前移動和旋轉的拍照模式。
  • 新增拍照模式同步設定。僅本機顯示為0 bit，同步時為16 bit。
  • 新增拍照模式中保持自身虛擬化身頭部可見的設定。
  • 新增可抬高包含頭部的整個身體的“地面高度”。
  • 新增呼吸動作、強度設定及遊戲內開關選單。
  • 新增關閉VRChat預設站立搖擺的設定。
  • 新增減輕頭部朝向不同造成姿勢變形的設定。
  • 新增防止膝蓋反折及最小彎曲角度設定。
  • 新增各功能開關和ExpressionParameters用量顯示。
  • 新增Scene簡易預覽、姿勢搜尋、批次加入及指定目標順序。
  • 新增Inspector內的更新紀錄顯示。

更改

  • 將Inspector整理為“功能”“姿勢”“虛擬化身設定”3個頁籤。
  • 整理呼吸詳情、自訂動作匯入及預設的設定位置。
  • 減少腳部高度調整產生動畫的重複。
  • 為姿勢圖片更新新增確認對話框，並將警告設定集中到“檢查設定”中。
  • 取消8bit版本的新建選單，統一為一般Prefab的功能選擇。保留現有參照。
  • 支援Unisaki Posing System 3.1.0-alpha.1。將VRChat Avatars SDK的最低版本改為3.10.4。

修復

  • 修復了姿勢名輸入轉移到其他姿勢，以及排序時詳情關閉的問題。
  • 修復了預覽重疊、放置位置偏移及某些虛擬化身報錯的問題。
  • 修復了設定變化後警告和預先建置狀態的更新，以及部分建置錯誤。
