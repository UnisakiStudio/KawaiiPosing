# Kawaii Posing Tool — 繁體中文使用者指南

Kawaii Posing為桌面和3點VR提供85種姿勢：15種站姿、20種半蹲/椅子坐姿、17種地面坐姿、17種仰臥和16種俯臥姿勢。

本指南涵蓋安裝、虛擬化身設定、VRChat操作、姿勢編輯、更新和疑難排解。購買的ZIP內包含`START_HERE.html`，可快速進入安裝說明。

## 開始前

- 使用通過VRChat Creator Companion（VCC）或ALCOM建立、管理的Unity 2022.3 VRChat**虛擬化身**專案。
- 所需套件：VRChat Avatars SDK 3.10.4或更高版本；Modular Avatar 1.x，版本1.15.1或更高；NDMF 1.x，版本1.14.0或更高。
- 工具適用於桌面模式和3點VR（頭顯與兩個控制器）的Humanoid虛擬化身。不支援全身追蹤啟用期間的姿勢固定。
- 安裝或更新前請備份現有專案，並先解決Unity中所有編譯錯誤。
- 安裝程式會從套件儲存庫下載商品及相依套件，需要網際網路連線。此ZIP不包含虛擬化身模型、VRChat SDK、Modular Avatar或NDMF。

## 1. 安裝授權與商品

1. 將整個ZIP解壓到Unity專案以外的一般資料夾。
2. 在Unity中開啟目標虛擬化身專案。通過**Assets > Import Package > Custom Package**匯入`Installer/KawaiiPosing_Installer.unitypackage`，也可使用Unity開啟該檔案。
3. 閱讀匯入和安裝提示。授權確認框會說明將安裝哪些商品授權。可通過確認框中的**語言…**（或**言語...**）更改安裝程式語言。
4. 確認安裝授權。授權也涵蓋本商品所用的共用Unisaki Posing System。安裝程式之後可能提議刪除自身的安裝檔案；此清理不會移除已安裝的商品授權。
5. 查看自動套件安裝程式的確認內容，其中會列出擬新增的套件與儲存庫，以及擬刪除的舊檔案或資料夾。確認這些項目正是所需內容後再繼續。
6. 等待Unity完成匯入和編譯。如果未自動完成套件安裝，請在VCC或ALCOM中開啟此專案，新增**Kawaii Posing Tool**和**Modular Avatar**。共用**Unisaki Posing System**和**NDMF**會作為相依套件安裝。`Optional-VCC-Links`包含商品原附的儲存庫捷徑，供Windows VCC使用者使用。
7. 若取消了確認，準備好後可重新匯入安裝程式。啟用程式仍在專案中時，也可使用**Tools > Unisaki Studio**中的授權安裝命令。舊版中此子選單名為**ゆにさきスタジオ**。

### 此下載會安裝什麼

**Kawaii Posing Tool 3.2.0與Unisaki Posing System 3.2.0。**此版本正在開發，尚未發佈。它為安裝對話框、Unity Inspector與選單、標準姿勢名、遊戲內選單和離線文件新增30種語言。發佈日期尚未確定。可通過Inspector頂部的語言選擇器切換工具語言。發佈後，安裝程式將從VPM儲存庫下載這些版本及其相容的相依套件。本機發佈準備不會公開這些套件。

Kawaii Posing Tool包含姿勢庫、設定工具和虛擬化身調整預設。安裝程式會啟用商品現有的本機授權，不需要新增的Gumroad授權金鑰輸入欄。請勿在公開支援請求中上傳安裝程式檔案或授權資料。

語言偏好通過Unity EditorPrefs按當前OS使用者儲存，同一臺電腦上的Unity專案共用。未儲存偏好時，安裝程式遵循OS語言；不支援時使用英語。商品授權保留原有儲存方式：Windows使用當前使用者的`Software/UnisakiStudio`登錄機碼，macOS/Linux使用按使用者儲存的授權檔案。更改語言不會刪除授權。 所有姿勢工具和虛擬化身都使用同一種語言。在任意工具的Inspector中變更語言，都會更新共用設定；不採用個別虛擬化身的語言選擇。 僅在尚未儲存語言時的首次安裝確認中顯示語言按鈕。之後請在Inspector中變更語言。

## 2. 向虛擬化身新增工具

1. 在**Hierarchy**中選取帶有**VRC Avatar Descriptor**的虛擬化身，或其子物件。請使用放置在場景中的虛擬化身，不要使用Project視窗中的Prefab資源或Prefab Mode。
2. 右鍵按一下虛擬化身，選擇**Unisaki Studio > 加入Kawaii Posing**。如已安裝版本使用日語選單，則選擇**ゆにさきスタジオ > 可愛いポーズツール追加**。
3. 工具會新增到虛擬化身內部。即使顯示標籤已翻譯，儲存的物件名也可能仍為**可愛いポーズ**。
4. 如果提示存在適用的虛擬化身預設，請套用它作為初步適配。否則開啟**虛擬化身設定**選擇預設，或自行調整姿勢。
5. 安裝程式可能提議執行預先建置。預先建置可選；一般虛擬化身建置也會產生所需資料。重複使用預先建置可縮短後續建置時間。
6. 選取工具物件，選擇所需姿勢與功能，然後按一般流程通過VRChat SDK上傳虛擬化身。

## 3. 選擇姿勢與功能

Inspector有3個主要頁籤：

| 頁籤 | 用途 |
| --- | --- |
| **功能** | 遊戲內選單控制項、可選行為、呼吸、圖示選項和表情參數用量。 |
| **姿勢** | 已啟用姿勢、分類與搜尋、排序、新增動畫、預覽、詳情及動畫調整。 |
| **虛擬化身設定** | 虛擬化身專屬修正與膝部修正、原始或自訂動作匯入及預設。 |

僅啟用計劃使用的選單控制項。例如，向選單新增**左右鏡像**，可讓您在VRChat中切換鏡像，並不會強制所有姿勢始終保持鏡像。

Kawaii Posing包含虛擬化身預設及適用姿勢的IK。3種標準仰臥姿勢已經指定了側躺動作：**伸腿坐（足伸ばし）**、**放鬆（リラックス）**和**支起單膝（膝立て）**。如果編輯或替換過這些項目，請使用適用的預設，並檢查各姿勢的翻身設定。

### 預設與適配

預設位於**虛擬化身設定**靠下方。按虛擬化身名稱搜尋，再套用預設以替換當前姿勢設定。更改預設前請儲存或備份調整。預設是初步適配：體型比例、服裝和虛擬化身修改仍可能需要手動修正。

對姿勢使用**動畫調整**，即可預覽和編輯身體、手腳位置。完成後請從該視窗儲存調整動畫。對於支援的姿勢，可整體及按姿勢啟用手腳自動調整（IK）。將當前IK結果烘焙到調整中，會建立調整動畫並關閉該姿勢的IK，以便繼續手動細調；原始來源片段會保留。

**防止膝蓋反折**提供最小膝蓋彎曲角度等附加設定。僅存在對應修正資料時，才可使用虛擬化身專屬修正，某些修正無法與姿勢IK並用。

### 原始動作與自訂動作

**使用虛擬化身原有的站立、蹲下和俯臥姿勢**會在產生時從虛擬化身的Base層檢測動作。**使用自訂動作**會開啟各動作類型的獨立匯入設定。每種類型選擇一個動作。某類型的手動指定優先於該類型的自動匯入。

自動匯入會套用於建置副本，不會將檢測到的動畫寫回場景中的手動指定清單，也不會修改原始控制器。如果希望重新由自動偵測處理某類型，請清除該類型的手動覆蓋。自訂Base層和其他移動系統可能需要單獨調整。

## 4. 在VRChat中使用工具

開啟虛擬化身的**Expressions**選單，進入**Kawaii Posing**。為需要使用的各姿勢分類選擇姿勢。選擇姿勢和選擇功能是兩個獨立操作。

- **3點VR：**通過抬高或降低頭部，在站立、半蹲/椅子坐姿、地面坐姿和躺姿之間切換。如果切換過早或過晚，可在工具設定選單中調整高度閾值。
- **桌面模式：**使用**C**蹲下，使用**Z**躺下。如果按Z後仍為坐姿，請在設定選單中提高躺姿高度閾值。
- **俯臥/仰臥：**工具根據面部朝向選擇俯臥或仰臥。兩者都選擇時，可原地跳躍切換。如不需要，可在Unity的**功能 > 便利功能**中關閉跳躍切換；此功能不額外消耗同步參數。
- **固定：**按需使用頭部、手臂和雙腳固定。想使用姿勢中的手型而非控制器手勢輸入時，可停用手勢。
- **左右鏡像：**鏡像當前姿勢，以朝向朋友或配合構圖。

### 腳部高度與地面高度

**腳部高度**會保持頭部位置，僅調整雙腳。頭部高度已正確，但雙腳懸空或陷入地面時，可使用此功能。

**地面高度**會移動包含頭部的整個身體。適用於沙發、床或較高平面，也適用於沒有碰撞體的家具。共用系統當前採用居中的控制項，**50%為原始高度**，0%為向下3 m，100%為向上3 m。恢復至50%附近即可結束偏移。舊版控制項行為可能不同，請確認已安裝版本，並將共用系統與商品一同更新。

### 拍照模式

上傳前在Unity中啟用**拍照模式**選單項。在VRChat中選擇姿勢，通過**距離**向前移動，最遠3 m，通過**朝向**旋轉虛擬化身。安排構圖時，雙腳固定可按需使用。**結束拍照**會重設距離和朝向，並解除雙腳固定。

拍照模式預設僅本機顯示。若要讓其他人看到位置和朝向，上傳前請在Unity中啟用**同步拍照模式**，使用16個同步bit。**拍照模式中保持頭部可見**只影響自己的畫面，不消耗同步bit。

### 呼吸與翻身

可在**功能 > 便利功能 > 啟用呼吸動畫**中按姿勢分類設定呼吸。可選擇無、弱、中、強、急或自訂呼吸動畫。動作本身不消耗同步bit，呼吸選單開關使用1 bit。

翻身需要支援的躺姿和**翻身**選單項。請對該姿勢啟用翻身，並按需提供側躺動畫。在VRChat中選擇該姿勢、啟用翻身並解除頭部/頸部固定，隨後頭部的側向傾斜會控制翻身。姿勢使用翻身時，無法再使用一般MotionTime控制。

上方列出的3種標準仰臥姿勢包含側躺動作。其他姿勢需要合適的動作和姿勢設定。匯入或自訂預設中的指定可能不同。

## 5. 編輯、新增與預覽姿勢

在**姿勢**中選擇分類或使用搜尋頁籤。搜尋支援原始日語名稱及已有譯名。開啟姿勢的**詳情**，可編輯動畫、圖示、順序和時間設定。

批次加入動畫時，可將片段拖放到新增區域，或在Project視窗選取片段後使用匯入所選片段的命令。同一片段的重複參照會被移除。可在詳情中更改目標順序，或使用上下移動控制項。

**預覽**可直接在Scene視圖中顯示姿勢，無需開啟完整調整視窗。此輕量預覽不執行Modular Avatar或NDMF，因此服裝、地面修正及其他建置期功能，請在最終虛擬化身建置結果中確認。

根據虛擬化身產生的姿勢圖示有助於辨認姿勢，但產生需要時間，也可能增加虛擬化身資料體積。可降低圖示解析度以節省空間。Android建置不會產生姿勢圖示。更改虛擬化身或服裝後，請按需重新產生圖示。

## 6. 參數記憶體

Inspector顯示的是姿勢工具佔用的部分，而非整個虛擬化身的總量。服裝和其他系統可能額外使用參數記憶體。多個姿勢工具共用的設定不會重複計數。增加大量額外姿勢的自訂設定，可能需要更多姿勢選擇bit。

| 功能 | 額外同步bit |
| --- | ---: |
| 姿勢選擇，最低標準設定 | 8 |
| 左右鏡像 | 1 |
| 停用手勢 | 1 |
| 呼吸動作 | 0 |
| 呼吸選單開關 | 1 |
| 腳部高度 | 8 |
| 地面高度 | 8 |
| 拍照模式，僅本機 | 0 |
| 同步拍照模式 | 16 |
| 拍照模式中保持頭部可見 | 0 |
| 關閉VRChat預設站立搖擺 | 0 |
| 翻身 | 10 |

翻身與頸部朝向姿勢修正共用1 bit，因此同時啟用這兩個功能時合計仍為10 bit。所選設定的實際參考值，以已安裝版本顯示的用量為準。

## 7. 更新與預先建置

1. 備份專案並儲存當前工作場景。
2. 在VCC或ALCOM中，將**Kawaii Posing Tool**和共用**Unisaki Posing System**一同更新，同時保持所需SDK、Modular Avatar和NDMF版本相容。
3. 等待編譯完成。選取已安裝的工具，檢查姿勢、設定和參數用量。
4. 如果使用預先建置，請選擇**更新預先建置**，然後重新上傳虛擬化身。

現有工具設定會保留。舊8-bit Prefab會為相容性保留，現有參照無需刪除或替換工具。新安裝使用一般Prefab，可禁用不需要的功能以降低參數用量。

預先建置過期警告表示：快取建置資料產生後，設定發生了變化。更新預先建置會重新產生這些資料。隱藏警告不會更新預先建置，也不會解決其根本問題。即使不每次手動預先建置，一般虛擬化身建置也能產生所需資料。

## 8. 疑難排解

| 現象 | 檢查內容 |
| --- | --- |
| 沒有新增工具選單 | 確認商品**和**Unisaki Posing System都已安裝，並解決Unity Console中的編譯錯誤。僅安裝授權程式並不包含姿勢庫。 |
| 取消安裝或刪除了檔案 | 準備好後重新匯入購買的安裝程式，並再次閱讀確認內容。 |
| 其他專案中似乎缺少授權 | 在同一OS帳戶下匯入購買的安裝程式。如更換電腦或帳戶，也需在新的環境安裝授權。語言偏好不會自動跨電腦轉移。 |
| VRChat中沒有姿勢 | 將工具新增到正確的場景虛擬化身下，啟用所需姿勢，檢查Inspector警告，並上傳該虛擬化身。檢查SDK及其他移動工具。 |
| Z無法進入躺姿 | 在工具遊戲內設定中提高躺姿高度閾值。 |
| 手或膝蓋位置不對 | 嘗試適用的虛擬化身預設，再使用支援的IK和/或動畫調整。在最終建置中檢查服裝變形。 |
| 翻身不起作用 | 使用支援的躺姿，同時啟用姿勢的翻身設定與選單項，並解除頭部/頸部固定。請先檢查3種支援的標準姿勢之一。 |
| 朋友看不到拍照移動 | 在Unity中啟用**同步拍照模式**，確認參數用量並重新上傳。 |
| Unity語言已更改，但VRChat未變化 | 重新上傳虛擬化身。在支援本機化的版本中，檢查Inspector頂部唯一的語言選擇器。 |
| 建置/預先建置錯誤 | 閱讀Console中相關的**第一條**錯誤。備份場景，通過VCC/ALCOM更新或重新獲取商品與共用系統。如問題持續，請聯絡支援。除非支援提供具體恢復步驟，否則請保留已調整的物件和GeneratedResources。 |

請求支援時，請提供商品和共用系統版本，Unity、SDK、Modular Avatar、NDMF版本，虛擬化身名稱，準確重現步驟及相關Console錯誤。公開發帖前，請移除私人檔案、安裝程式內容、授權值和帳戶資訊。
