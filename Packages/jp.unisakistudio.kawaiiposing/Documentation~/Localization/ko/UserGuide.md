# Kawaii Posing — 사용 설명서

Kawaii Posing은 데스크톱과 3점 VR용 포즈 85개를 제공합니다. 서기 15·웅크리기/의자 20·바닥 앉기 17·바로 눕기 17·엎드리기 16개입니다.

이 설명서는 설치, 아바타 설정, VRChat 조작, 포즈 편집, 업데이트, 문제 해결을 다룹니다. 구매한 ZIP의 `START_HERE.html`에서 설치 안내를 빠르게 열 수 있습니다.

## 시작하기 전에

- VRChat Creator Companion(VCC) 또는 ALCOM으로 만들거나 관리하는 Unity 2022.3 VRChat **아바타** 프로젝트를 사용하세요.
- 필요한 패키지는 VRChat Avatars SDK 3.10.4 이상, Modular Avatar 1.x의 1.15.1 이상, NDMF 1.x의 1.14.0 이상입니다.
- 데스크톱과 3점 VR(헤드셋과 컨트롤러 두 개)에서 Humanoid 아바타용으로 사용합니다. 풀 바디 트래킹 중의 자세 고정은 지원하지 않습니다.
- 설치·업데이트 전 기존 프로젝트를 백업하고 Unity 컴파일 오류를 먼저 해결하세요.
- 설치 프로그램은 각 패키지 배포처에서 상품과 의존 패키지를 내려받으므로 인터넷 연결이 필요합니다. 아바타 모델·VRChat SDK·Modular Avatar·NDMF는 이 ZIP에 포함되지 않습니다.

## 1. 라이선스와 상품 설치

1. ZIP 전체를 Unity 프로젝트 밖의 일반 폴더에 풉니다.
2. 대상 아바타 프로젝트를 Unity로 열고 **Assets > Import Package > Custom Package**에서 `Installer/KawaiiPosing_Installer.unitypackage`를 가져오거나 파일을 Unity로 엽니다.
3. 가져오기와 설치 안내를 읽습니다. 라이선스 확인에는 등록될 상품 라이선스가 표시됩니다. 확인 창의 **언어…**(일본어 표시에서는 **言語…**)에서 설치 언어를 바꿀 수 있습니다.
4. 라이선스 등록을 확인합니다. 이 상품이 사용하는 공통 Unisaki Posing System도 포함됩니다. 이후 설치 파일 자체의 삭제가 제안될 수 있지만 이 정리는 등록한 상품 라이선스를 지우지 않습니다.
5. 패키지 자동 설치 확인을 읽습니다. 추가할 패키지·배포처와 삭제할 이전 파일·폴더가 표시됩니다. 원하는 항목이 맞으면 계속하세요.
6. Unity의 가져오기와 컴파일이 끝날 때까지 기다립니다. 자동 설치가 완료되지 않으면 VCC 또는 ALCOM에서 프로젝트를 열고 **Kawaii Posing**과 **Modular Avatar**를 추가합니다. 공통 **Unisaki Posing System**과 **NDMF**는 의존 패키지입니다. `Optional-VCC-Links`에는 Windows VCC 사용자를 위해 상품에 원래 포함된 배포처 바로가기가 들어 있습니다.
7. 확인을 취소했다면 준비가 된 후 설치 프로그램을 다시 가져오세요. Activator가 남아 있는 동안 **Tools > Unisaki Studio**의 라이선스 설치 명령도 사용할 수 있습니다. 이전 빌드에서는 이 하위 메뉴 이름이 **ゆにさきスタジオ**입니다.

### 이 다운로드가 설치하는 것

**Kawaii Posing 3.2.0과 Unisaki Posing System 3.2.0입니다.** 이 버전은 개발 중이며 아직 출시되지 않았습니다. 설치 대화 상자·Unity Inspector와 메뉴·표준 포즈 이름·게임 내 메뉴·오프라인 문서를 30개 언어로 제공합니다. 출시일은 정해지지 않았습니다. Inspector 최상단의 언어 선택으로 표시 언어를 바꿉니다. 공개 후 설치 프로그램은 VPM 배포처에서 이 버전들과 호환 의존 패키지를 내려받습니다. 로컬 출시 준비만으로 패키지가 공개되지는 않습니다.

Kawaii Posing에는 포즈 라이브러리·설정 도구·아바타 조정 프리셋이 포함됩니다. 설치 프로그램은 기존 로컬 상품 라이선스를 활성화하며 새로운 Gumroad 라이선스 키 입력란을 요구하지 않습니다. 공개 문의에 설치 파일이나 라이선스 데이터를 게시하지 마세요.

언어 설정은 현재 OS 사용자의 Unity EditorPrefs에 저장하며 이 컴퓨터의 다른 Unity 프로젝트와 공유합니다. 저장한 선택이 없으면 OS 언어를 따르고 지원하지 않는 언어는 영어로 표시합니다. 상품 라이선스는 기존 방식대로 Windows에서는 현재 사용자의 `Software/UnisakiStudio` 레지스트리 키에, macOS/Linux에서는 사용자별 라이선스 파일에 저장합니다. 언어를 바꿔도 라이선스는 삭제되지 않습니다.

## 2. 아바타에 도구 추가

1. **Hierarchy**에서 **VRC Avatar Descriptor**가 있는 아바타 또는 그 자식을 선택합니다. Project의 Prefab 에셋이나 Prefab Mode가 아닌 씬에 배치한 아바타를 사용하세요.
2. 아바타를 우클릭하고 **Unisaki Studio > Kawaii Posing 추가**를 선택합니다. 설치된 빌드의 메뉴가 일본어라면 **ゆにさきスタジオ > 可愛いポーズツール追加**를 선택하세요.
3. 아바타 안에 도구가 추가됩니다. 표시 문구를 번역해도 저장된 오브젝트 이름은 **可愛いポーズ**로 남을 수 있습니다.
4. 일치하는 아바타 프리셋이 제안되면 초기 조정으로 적용합니다. 그렇지 않으면 **아바타 설정**에서 프리셋을 고르거나 포즈를 직접 조정합니다.
5. 프리빌드가 제안될 수 있습니다. 프리빌드는 선택 사항이며 일반 아바타 빌드도 필요한 데이터를 생성합니다. 반복 빌드 시간을 줄이는 데 사용하세요.
6. 도구 오브젝트를 선택해 원하는 포즈·기능을 정하고 VRChat SDK로 일반적인 업로드를 진행합니다.

### 언어 선택과 익숙한 표시 이름

이 버전은 도구 Inspector 최상단에 **Language / 言語**를 제공합니다. 하나의 선택이 Inspector와 생성되는 게임 내 메뉴를 제어합니다. 선택 언어는 아바타에 저장되고 마지막 선택은 이 컴퓨터의 다른 도구·프로젝트에서도 기억합니다. VRChat에 보이는 언어를 바꾸려면 아바타를 다시 업로드하세요.

이전 일본어 설명을 따라갈 때 아래 대조표를 참고하세요. 이 버전은 언어 선택, 현지화한 Inspector, 번역된 표준 포즈 이름, 30개 언어의 게임 내 메뉴를 제공합니다.

| 영어 | 이전 빌드의 일본어 표시 |
| --- | --- |
| Unisaki Studio | ゆにさきスタジオ |
| Features | 機能 |
| Poses | ポーズ一覧 |

Inspector, 편집·설치 대화 상자, 표준 포즈 이름, 생성 메뉴에는 선택 가능한 모든 30개 언어의 번역이 포함됩니다. README·변경 내역·오프라인 설명서도 각 선택 언어로 제공합니다. 아바타 이름·저장된 오브젝트 이름·자체 포즈 이름·에셋 파일명·내부 파라미터 식별자는 원래 표기를 유지할 수 있습니다.

## 3. 포즈와 기능 선택

Inspector에는 다음 세 가지 주요 탭이 있습니다.

| 탭 | 용도 |
| --- | --- |
| **기능** | 게임 내 메뉴, 선택 동작, 호흡, 아이콘 설정, ExpressionParameters 사용량 |
| **포즈** | 사용할 포즈, 분류·검색, 순서, 애니메이션 추가, 미리보기, 상세, 애니메이션 조정 |
| **아바타 설정** | 아바타별·무릎 보정, 원래·자체 모션 가져오기, 프리셋 |

사용할 메뉴 기능만 켜세요. 예를 들어 **좌우 반전**을 메뉴에 추가하면 VRChat에서 반전을 전환할 수 있습니다. 모든 포즈를 항상 반전시키는 설정은 아닙니다.

Kawaii Posing에는 아바타 프리셋과 지원 포즈의 IK가 있습니다. 바로 누운 표준 세 자세 **다리 뻗기(足伸ばし)**·**릴랙스(リラックス)**·**한쪽 무릎 세우기(膝立て)**에는 옆으로 눕는 모션이 지정되어 있습니다. 맞는 프리셋을 사용하고 이 항목들을 편집·교체했다면 각 포즈의 뒤척이기 설정을 확인하세요.

### 프리셋과 체형 조정

프리셋은 **아바타 설정** 아래쪽에 있습니다. 아바타 이름으로 검색하고 적용하여 현재 포즈 설정을 교체합니다. 전환하기 전에 조정을 저장하거나 백업하세요. 프리셋은 초기 기준이며 신체 비율·의상·아바타 개조에 따라 수동 보정이 필요할 수 있습니다.

포즈의 **애니메이션 조정**을 사용하면 미리보기를 보며 몸·팔다리 위치를 편집합니다. 작업 후 해당 창에서 조정 애니메이션을 저장하세요. 지원되는 포즈의 손발 자동 조정(IK)은 전체와 개별 포즈에서 전환할 수 있습니다. 현재 IK 결과를 조정에 저장하면 새 조정 애니메이션이 생성되고 해당 포즈의 IK가 꺼져 수동 마무리를 할 수 있습니다. 원본 클립은 유지합니다.

**무릎이 반대로 꺾이지 않게 하기**에는 최소 무릎 굽힘 등의 상세 설정이 있습니다. 아바타별 보정은 대응 데이터가 있을 때만 사용할 수 있으며 일부 보정은 포즈 IK와 함께 쓸 수 없습니다.

### 원래 포즈와 자체 모션

**아바타의 원래 서기·웅크리기·엎드리기 포즈 사용**은 생성 시 Base 레이어에서 모션을 검출합니다. **자신의 모션 사용**은 종류별로 분리된 가져오기 설정을 엽니다. 종류마다 하나의 모션을 선택하세요. 수동 지정은 해당 종류의 자동 가져오기보다 우선합니다.

자동 가져오기는 빌드 복사본에 적용합니다. 검출한 애니메이션을 씬의 수동 지정 목록에 기록하거나 원본 Controller를 수정하지 않습니다. 다시 자동 검출을 사용하려면 해당 종류의 수동 지정을 지우세요. 자체 Base 레이어와 다른 이동 시스템은 개별 조정이 필요할 수 있습니다.

## 4. VRChat에서 사용

아바타의 **Expressions** 메뉴에서 **Kawaii Posing**을 엽니다. 사용할 자세 분류마다 포즈를 고르세요. 포즈 선택과 기능 선택은 별개의 작업입니다.

- **3점 VR:** 머리를 올리고 내려 서기·웅크리기/의자·바닥 앉기·눕기를 전환합니다. 전환이 너무 빠르거나 느리면 도구 설정 메뉴에서 높이 임계값을 조절하세요.
- **데스크톱:** **C**로 웅크리고 **Z**로 눕습니다. Z를 눌러도 앉기에서 멈추면 설정의 눕기 높이 임계값을 올리세요.
- **엎드리기/바로 눕기:** 얼굴 방향으로 선택합니다. 둘 다 선택하면 제자리 점프로도 전환합니다. 원하지 않으면 Unity의 **기능 > 편의 기능**에서 점프 전환을 끌 수 있으며 추가 동기화 파라미터는 사용하지 않습니다.
- **고정:** 필요에 따라 머리·팔·발을 고정하세요. 컨트롤러 제스처 대신 포즈의 손 모양을 쓰려면 제스처 끄기를 사용합니다.
- **좌우 반전:** 선택한 포즈를 반전하여 친구나 촬영 구도에 맞출 수 있습니다.

### 발 높이와 바닥 높이

**발 높이**는 머리 위치를 유지하고 발을 조절합니다. 머리는 적절한 높이인데 발이 뜨거나 묻힐 때 사용하세요.

**바닥 높이**는 머리를 포함한 몸 전체를 움직입니다. 소파·침대·높은 표면 등에 사용할 수 있으며 콜라이더가 없는 가구도 가능합니다. 공통 시스템의 현재 중앙 기준 조작에서는 **50%가 원래 높이**, 0%가 3 m 아래, 100%가 3 m 위입니다. 50% 부근으로 되돌리면 보정이 종료됩니다. 이전 버전은 조작 방식이 다를 수 있으므로 설치 버전을 확인하고 상품과 공통 시스템을 함께 업데이트하세요.

### 촬영 모드

업로드 전에 Unity에서 **촬영 모드** 메뉴를 켭니다. VRChat에서 포즈를 고르고 **거리**로 앞쪽 최대 3 m까지 이동하며 **방향**으로 회전합니다. 구도를 잡는 동안 발 고정은 선택 사항입니다. **촬영 종료**로 거리·방향을 초기화하고 발 고정을 해제합니다.

촬영 모드는 기본적으로 자신의 화면에만 적용됩니다. 다른 사람에게도 위치·방향을 보이려면 업로드 전에 Unity에서 **촬영 모드 동기화**를 켜세요. 동기화 파라미터 16 bit를 사용합니다. **촬영 모드에서 머리 표시 유지**는 자신의 화면에만 적용되며 동기화 bit를 쓰지 않습니다.

### 호흡과 뒤척이기

호흡은 **기능 > 편의 기능 > 호흡 애니메이션 사용**에서 자세 분류별로 설정합니다. 없음·약·중·강·빠름 또는 사용자 지정 호흡 애니메이션을 선택하세요. 움직임 자체는 동기화 bit를 쓰지 않습니다. 호흡 메뉴 전환에는 1 bit를 사용합니다.

뒤척이기에는 지원되는 누운 자세와 **뒤척이기** 메뉴 항목이 필요합니다. 해당 포즈의 뒤척이기를 켜고 필요하면 옆으로 누운 애니메이션을 지정합니다. VRChat에서 그 포즈를 선택하고 뒤척이기를 켠 뒤 머리/목 고정을 해제하세요. 머리를 좌우로 기울이면 몸이 뒤척입니다. 사용 중에는 해당 포즈의 일반 MotionTime 조작을 사용할 수 없습니다.

앞서 소개한 바로 눕기 표준 세 포즈에는 옆으로 누운 모션이 포함됩니다. 다른 포즈는 적절한 모션과 포즈 설정이 필요합니다. 가져온 프리셋이나 자체 프리셋은 할당 내용이 다를 수 있습니다.

## 5. 포즈 편집·추가·미리보기

**포즈**에서 분류를 선택하거나 검색 탭을 사용합니다. 원래 일본어 이름과 제공되는 번역 이름으로 검색할 수 있습니다. 포즈의 **상세**를 열어 애니메이션·아이콘·순서·재생 위치 등을 편집합니다.

여러 애니메이션은 클립을 추가란에 끌어 놓거나 Project에서 선택하고 선택 클립 가져오기 명령으로 추가합니다. 같은 클립의 중복 참조는 제거됩니다. 상세에서 이동 순서를 바꾸거나 위아래 버튼을 사용하세요.

**미리보기**는 전체 조정 창을 열지 않고 Scene에서 포즈를 표시합니다. 이 간단한 미리보기는 Modular Avatar·NDMF를 실행하지 않으므로 의상·바닥 보정·다른 빌드 시 기능은 최종 아바타 빌드에서 확인하세요.

아바타에서 생성한 포즈 아이콘은 포즈를 구분하기 쉽게 하지만 생성 시간이 필요하고 아바타 데이터가 늘 수 있습니다. 해상도를 낮추면 용량을 줄일 수 있습니다. Android 빌드에서는 포즈 아이콘을 생성하지 않습니다. 아바타나 의상을 바꾼 뒤 필요에 따라 아이콘을 다시 만드세요.

## 6. 파라미터 사용량

Inspector는 아바타 전체가 아닌 포즈 도구의 사용량을 표시합니다. 의상이나 다른 시스템도 별도로 파라미터를 쓸 수 있습니다. 여러 포즈 도구의 공통 설정은 중복 계산하지 않습니다. 포즈를 많이 추가한 자체 구성은 자세 선택에 더 많은 bit가 필요할 수 있습니다.

| 기능 | 추가 동기화 bit |
| --- | ---: |
| 자세 선택(표준 최소 구성) | 8 |
| 좌우 반전 | 1 |
| 제스처 끄기 | 1 |
| 호흡 동작 | 0 |
| 호흡 메뉴 전환 | 1 |
| 발 높이 | 8 |
| 바닥 높이 | 8 |
| 촬영 모드(자신의 화면만) | 0 |
| 촬영 모드 동기화 | 16 |
| 촬영 모드에서 머리 표시 유지 | 0 |
| VRChat 기본 대기 흔들림 끄기 | 0 |
| 뒤척이기 | 10 |

뒤척이기는 목 방향 자세 보정과 1 bit를 공유하므로 두 기능을 모두 켜도 해당 두 기능의 합계는 10 bit입니다. 선택한 구성의 실제 사용량은 설치 버전에 표시된 값을 확인하세요.

## 7. 업데이트와 프리빌드

1. 프로젝트를 백업하고 작업 중인 씬을 저장합니다.
2. VCC 또는 ALCOM에서 **Kawaii Posing**과 공통 **Unisaki Posing System**을 함께 업데이트합니다. SDK·Modular Avatar·NDMF도 호환되는 버전을 유지하세요.
3. 컴파일이 끝나면 이미 설치한 도구를 선택하여 포즈·설정·파라미터 사용량을 확인합니다.
4. 프리빌드를 사용한다면 **프리빌드 업데이트**를 누르고 아바타를 다시 업로드합니다.

기존 도구 설정은 유지됩니다. 이전 8-bit Prefab은 호환성을 위해 남아 있으므로 기존 참조를 삭제하거나 도구를 교체할 필요가 없습니다. 새로 설치할 때는 일반 Prefab을 쓰고 불필요한 기능을 꺼 파라미터 사용량을 줄일 수 있습니다.

프리빌드 업데이트 경고는 캐시된 데이터 생성 이후 설정이 바뀌었음을 뜻합니다. 프리빌드를 업데이트하면 데이터를 다시 만듭니다. 경고를 숨겨도 프리빌드가 갱신되거나 원인이 해결되지는 않습니다. 매번 수동으로 프리빌드하지 않아도 일반 아바타 빌드가 필요한 데이터를 생성합니다.

## 8. 문제 해결

| 증상 | 확인 사항 |
| --- | --- |
| 도구 추가 메뉴가 없음 | 상품 **및** Unisaki Posing System을 모두 설치하고 Unity Console의 컴파일 오류를 해결하세요. 라이선스 설치 프로그램 자체는 포즈 라이브러리가 아닙니다. |
| 설치를 취소했거나 파일을 삭제함 | 준비되면 구매한 설치 프로그램을 다시 가져오고 확인 내용을 다시 읽으세요. |
| 다른 프로젝트에서 라이선스가 안 보임 | 같은 OS 계정으로 구매한 설치 프로그램을 가져오세요. 컴퓨터·계정을 바꿨다면 그곳에도 라이선스를 설치합니다. 언어 설정은 다른 컴퓨터로 자동 이전되지 않습니다. |
| VRChat에 포즈가 없음 | 올바른 씬 아바타 안에 도구를 추가하고 원하는 포즈를 켜세요. Inspector 경고를 확인하고 해당 아바타를 업로드합니다. SDK와 다른 이동 도구도 확인하세요. |
| Z로 눕지 않음 | 게임 내 설정의 눕기 높이 임계값을 올리세요. |
| 손·무릎 위치가 맞지 않음 | 대응 아바타 프리셋을 시도하고 지원 IK 또는 애니메이션 조정을 사용하세요. 최종 빌드에서 의상 변형도 확인합니다. |
| 뒤척이기가 작동하지 않음 | 지원되는 누운 포즈를 사용하고 포즈의 뒤척이기 설정과 메뉴를 모두 켠 뒤 머리/목 고정을 해제하세요. 먼저 지원되는 표준 세 포즈 중 하나로 확인합니다. |
| 친구에게 촬영 이동이 안 보임 | Unity에서 **촬영 모드 동기화**를 켜고 파라미터 사용량을 확인한 뒤 다시 업로드하세요. |
| Unity 언어만 바뀌고 VRChat은 그대로임 | 아바타를 다시 업로드하세요. 다국어 지원 빌드에서는 Inspector 최상단의 단일 언어 선택을 확인합니다. |
| 빌드/프리빌드 오류 | 관련 Console 오류 중 **첫 번째**를 읽으세요. 씬을 백업하고 VCC/ALCOM에서 상품·공통 시스템을 업데이트하거나 다시 받은 뒤 문제가 계속되면 문의하세요. 지원팀이 구체적인 복구 절차를 안내하기 전에는 조정한 오브젝트와 GeneratedResources를 유지합니다. |
