Kawaii Posing

3점 트래킹이나 데스크톱에서도 귀여운 앉기·눕기 자세를 사용할 수 있는 VRChat 포즈 고정 도구입니다. 서기 15·웅크리기 20·앉기 17·엎드리기 16·바로 눕기 17로 총 85개 포즈를 제공합니다.

이 README는 개발 중인 v3.2.0용입니다. 정식 출시일은 정해지지 않았습니다. 설치된 버전은 Inspector 상단에서 확인할 수 있습니다.

표시 언어와 오프라인 문서

Inspector 최상단의 Language / 言語에서 표시 언어를 선택합니다. 하나의 선택이 Inspector와 생성되는 VRChat 메뉴에 모두 적용됩니다. 게임 내 표시 언어를 바꾸려면 아바타를 다시 업로드하세요.

선택한 언어가 없으면 컴퓨터의 언어를 사용하고, 지원하지 않는 언어이면 영어를 사용합니다. Windows·macOS·Linux를 지원합니다. 마지막으로 선택한 언어를 EditorPrefs에 저장하여 이 컴퓨터의 같은 OS 사용자에 속한 다른 프로젝트에서도 사용합니다. 모든 포즈 도구와 아바타는 같은 언어를 사용합니다. 어느 도구의 Inspector에서 변경하든 공통 설정에 반영되며, 아바타별 언어 선택은 사용하지 않습니다. 다른 컴퓨터에는 동기화하지 않습니다. 라이선스 저장 방식은 변경하지 않습니다. 저장된 언어가 없을 때 최초 설치 확인에만 언어 버튼을 표시합니다. 이후에는 Inspector에서 언어를 변경합니다.

동봉된 언어 목록에서 README·변경 내역·사용 설명서를 선택할 수 있습니다. Inspector의 사용 설명서와 변경 내역도 선택한 언어를 따릅니다. 원본 이용 약관과 참고 번역은 기존처럼 별도로 제공합니다.

주요 기능

  • 촬영 모드: 아바타를 앞쪽 최대 3m까지 움직이고 방향을 조절할 수 있습니다. 자신의 화면만 사용할 때 0 bit, 다른 사람에게도 위치·방향을 보일 때 16 bit입니다.
  • 촬영 중 머리 표시: 가까이 있는 자신의 아바타 머리가 사라지는 현상을 촬영 모드 중에만 방지할 수 있습니다.
  • 바닥 높이: 머리를 포함한 몸 전체를 위아래 3m 이동합니다. 50%가 원래 높이와 기본값, 0%가 3m 아래, 100%가 3m 위입니다. 머리 위치를 유지하고 발 쪽을 움직이는 발 높이와 구분하여 쓸 수 있습니다.
  • 뒤척이기: 지원하는 누운 자세에서 머리 기울기에 따라 좌우로 뒤척입니다.
  • 호흡: 가슴 등에 호흡 동작을 추가하고 자세 분류마다 없음·약·중·강·빠름·사용자 지정을 선택할 수 있습니다.
  • VRChat 기본 대기 흔들림 끄기: 기본 대기 흔들림을 줄이면서 도구의 호흡이나 다른 사용자 지정 동작은 사용할 수 있습니다.
  • 머리 회전에 의한 포즈 변형 줄이기: 머리 고정을 해제했을 때 원래 포즈와 목 방향이 달라 생기는 자세 변형을 줄입니다.
  • 기능 선택: 필요한 게임 내 메뉴만 추가하고 Inspector에서 ExpressionParameters 사용량을 확인할 수 있습니다.
  • 포즈 검색·일괄 추가·정렬: 분류를 넘나드는 검색, 여러 클립 가져오기, 이동 순서 지정을 지원합니다.
  • Scene 간단 미리보기: 포즈 목록의 미리보기에서 그 자리의 자세를 확인할 수 있습니다.
  • 팔다리 자동 조정(IK): 지원되는 포즈에서 아바타 체형에 맞춰 손발 위치를 조정합니다. 포즈별 ON/OFF와 결과를 조정 애니메이션에 저장하는 기능도 있습니다.

기본 제공 포즈로 뒤척이기

바로 누운 다리 뻗기·릴랙스·한쪽 무릎 세우기에는 뒤척이기용 옆으로 누운 자세가 설정되어 있습니다. 각각 横向き寝·낮잠·고양이 낮잠을 바탕으로 한 뒤척이기입니다.

기능 > 메뉴 기능 > 뒤척이기를 켜고 업로드한 뒤 VRChat에서 대응 포즈와 뒤척이기를 선택하세요. 머리 고정을 해제하고 사용합니다.

직접 설정하려면 포즈 > 상세 > 뒤척이기 사용을 켜고 뒤척이기용 옆으로 누운 포즈에 애니메이션을 지정합니다. 뒤척이기를 쓰는 포즈에서는 일반 MotionTime 설정을 사용할 수 없습니다.

체형에 맞춘 조정

기본 제공 팔다리 자동 조정을 사용할 수 있지만 모든 포즈가 IK를 필요로 하는 것은 아닙니다. 애니메이션 조정 화면의 팔다리 자동 조정 사용으로 전체를, 이 포즈에 IK 사용으로 개별 포즈를 전환합니다.

IK 결과를 조정에 저장은 현재 자동 조정 결과를 새 조정 애니메이션에 기록하고 해당 포즈의 IK를 끕니다. 이후 수동으로 마무리할 수 있습니다. 전체와 해당 포즈의 자동 조정이 켜져 있고 적용 가능한 IK 설정이 있어야 사용할 수 있습니다.

아바타 설정에는 무릎이 반대로 꺾이지 않게 하기와 그 상세 설정인 최소 무릎 굽힘(도)도 있습니다.

설치 방법

  1. 구매한 스토어의 상품 페이지에서 파일을 받습니다.
  2. 동봉된 可愛いポーズツール.unitypackage를 Unity로 가져와 라이선스와 패키지 배포처를 등록합니다.
  3. VCC 또는 ALCOM에서 사용할 Unity 프로젝트에 Kawaii Posing과 Modular Avatar를 추가합니다. 공통 Unisaki Posing System과 NDMF도 의존 패키지로 설치됩니다.
  4. Hierarchy에서 대상 아바타를 우클릭하고 Unisaki Studio > Kawaii Posing 추가를 선택합니다.
  5. 아바타 내부에 추가된 可愛いポーズ를 선택하고 Inspector에서 사용할 기능과 포즈를 설정합니다.
  6. 일반적인 방법으로 아바타를 업로드합니다.

필요 환경은 Unity 2022.3, VRChat Avatars SDK 3.10.4 이상, Modular Avatar 1.x의 1.15.1 이상, NDMF 1.x의 1.14.0 이상입니다. VCC·ALCOM에서 필요한 패키지도 함께 업데이트하세요.

이전 버전에서 업데이트할 때

이 상품과 Unisaki Posing System을 함께 업데이트합니다. 이미 배치된 도구 설정은 유지됩니다. Inspector에서 사용할 기능과 ExpressionParameters 사용량을 확인하고, 프리빌드를 썼다면 프리빌드 업데이트를 누른 뒤 다시 업로드하세요.

v3.1.0부터 새로 추가할 때는 일반 可愛いポーズ Prefab으로 통일했습니다. 기능에서 불필요한 항목을 끄면 자세 선택만 사용하는 최소 구성은 8 bit입니다. 포즈가 많은 구성은 자세 선택에 추가 bit가 필요할 수 있습니다.

이전 8bit Prefab은 기존 아바타·프리셋 참조를 유지하기 위해 Editor/Legacy에 남아 있습니다. 기존 Prefab을 삭제·교체할 필요는 없습니다. Unity의 새로 추가 메뉴에는 8bit 버전이 표시되지 않습니다.

설정 위치

탭가능한 작업
기능게임 내 메뉴 추가, 편의 기능, 호흡 설정, 아이콘·ExpressionParameters 사용량 확인
포즈사용할 포즈 선택, 상세 설정, 검색, 일괄 추가, 정렬, 미리보기, 애니메이션 조정
아바타 설정아바타별 보정, 무릎 보정, 원래 포즈·자체 모션 가져오기, 프리셋 변경

설정 열기를 누르면 해당 항목 아래에 상세 설정이 펼쳐집니다. 호흡은 기능 > 편의 기능 > 호흡 애니메이션 사용에서 설정합니다.

아바타의 원래 서기·웅크리기·엎드리기 포즈 사용은 아바타에 원래 있는 자세를 자동으로 가져옵니다. 자체 모션을 쓸 때는 별도의 가져오기 설정 열기에서 서기·웅크리기(Crouching)·엎드리기(Prone) 등 종류마다 지정합니다.

프리셋은 아바타 설정 맨 아래에 있습니다. 이 프리셋 적용은 현재 포즈 설정을 덮어쓰므로 조정한 내용을 저장한 뒤 전환하세요.

기능별 사용량

  • 호흡 동작은 0 bit입니다. 게임 안에서 멈추거나 재개하는 메뉴 기능 > 호흡을 쓸 때만 ON/OFF 동기화에 1 bit를 사용합니다.
  • 촬영 모드는 자신의 화면만 사용할 때 0 bit입니다. 편의 기능 > 촬영 모드 동기화를 고르면 16 bit를 사용합니다. 촬영 모드에서 머리 표시 유지는 0 bit입니다.
  • 발 높이·바닥 높이는 각각 8 bit입니다. 바닥 높이를 중앙에서 움직이면 위아래로 이동하고 50% 부근으로 되돌리면 보정이 끝납니다.
  • 뒤척이기 단독은 10 bit입니다. 머리 회전에 의한 포즈 변형 줄이기와 1 bit를 공유하므로 두 기능을 모두 사용해도 합계는 10 bit입니다.
  • 좌우 반전·제스처 끄기는 각각 1 bit입니다.

Inspector의 합계는 아바타의 포즈 도구 사용량입니다. 의상 등 다른 기믹은 포함하지 않습니다. 여러 포즈 도구를 함께 사용해도 공통 설정은 중복 계산하지 않습니다.

미리보기와 포즈 편집

포즈 탭의 각 포즈에 있는 미리보기로 Scene에 자세를 표시합니다. 세밀하게 고치려면 애니메이션 조정을 열고 자세를 확인하며 조정한 뒤 저장합니다.

간단 미리보기는 MA·NDMF 빌드를 실행하지 않습니다. 빌드 시 통합되는 의상이나 바닥 위치 보정은 업로드 전 빌드 결과에서도 확인하세요.

왼쪽 돋보기 탭에서 포즈 이름을 검색할 수 있습니다. 상세의 순서에서 이동 위치를 고르거나 위아래 버튼으로 정렬합니다. 여러 애니메이션은 추가란에 드래그 앤 드롭하거나 Project에서 선택한 클립 가져오기로 일괄 추가할 수 있습니다.

포즈 미리보기 이미지 업데이트는 확인 대화 상자 뒤에 이미지를 생성합니다. 포즈 아이콘 생성은 게임 내 포즈 구분을 쉽게 하지만 이미지 생성만큼 빌드 시간이 늘어납니다. 용량을 줄이려면 아이콘 용량 줄이기를 선택하세요. Android에서는 포즈 아이콘을 생성하지 않습니다.

게임 내 기본 조작

  • Expressions 메뉴에서 분류별 포즈를 선택합니다. VR에서는 머리 높이에 따라 서기·웅크리기·앉기·눕기가 전환됩니다.
  • 누운 상태에서는 얼굴 방향으로 바로 눕기·엎드리기를 전환하며 둘 다 선택한 경우 제자리 점프로도 전환할 수 있습니다. Unity의 기능 > 편의 기능 > 점프로 누운 자세 전환에서 끌 수 있습니다(기본값 켜짐). 분류 전환 높이는 설정 메뉴의 임계값으로 조절합니다.
  • 데스크톱에서는 C·Z 키로 자세를 전환합니다. Z로 눕지 않으면 설정 메뉴의 눕기 높이 임계값을 올리세요.
  • 제스처 끄기를 켜면 컨트롤러 손가락 모양 대신 포즈에 설정한 손 모양을 사용합니다.
  • 발 높이는 머리 위치를 유지하고 발 쪽을 조절하며 바닥 높이는 머리를 포함한 몸 전체를 위아래로 움직입니다. 설정 메뉴에는 이 순서로 배치됩니다.
  • 촬영 모드의 거리로 전진하면 아바타가 자신을 바라봅니다. 방향으로 회전하고 필요한 때 발 고정을 켜세요. 촬영 종료로 거리·방향을 되돌리고 발 고정을 해제합니다.
  • 호흡은 호흡 동작이 켜져 있을 때 사용할 수 있습니다. 강도는 Unity에서 정하고 게임 안에서는 ON/OFF를 전환합니다.

프리빌드와 경고

프리빌드 업데이트는 생성 데이터를 재사용하여 아바타 빌드를 빠르게 합니다. 프리빌드를 하지 않아도 일반 빌드 시 필요한 데이터를 생성합니다.

설정 변경 후 Inspector 상단의 설정 확인이나 Hierarchy 표시로 업데이트 필요 상태를 알립니다. 경고 표시 설정은 설정 확인 영역 안에 있습니다. 표시를 숨겨도 설정 문제를 해결하거나 생성 데이터를 갱신하지는 않습니다.

사용 시 주의 사항

  • 풀 바디 트래킹 중의 자세 고정은 지원하지 않습니다.
  • 체형·의상·아바타 개조 내용에 따라 추가 조정이 필요할 수 있습니다.
  • 특수한 Base 레이어나 다른 자세 변경 기믹과 의도대로 통합되지 않을 수 있습니다. 고정이 잘 작동하지 않으면 아바타 설정 > 다른 도구와 트래킹 고정 통합도 확인하세요.
  • 촬영 모드의 이동·회전과 바닥 높이는 포즈 미선택 시의 기본·자체 모션도 보정합니다. VRChat 시점과 기본 모션 교체 후 동작은 실제 클라이언트에서 확인하세요.
  • VRChat 기본 대기 흔들림 끄기는 기본 대기 동작이 대상이며 다른 원인의 흔들림까지 모두 멈추지는 않습니다.

프리셋 배포에 관하여
