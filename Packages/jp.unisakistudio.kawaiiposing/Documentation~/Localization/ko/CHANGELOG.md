# 변경 내역

## [3.2.0] - 미출시

### 추가

- Inspector, 편집 작업, 설치 대화 상자, 표준 포즈 이름, 생성되는 VRChat 메뉴를 30개 언어로 표시할 수 있도록 했습니다.
- Inspector와 게임 내 메뉴의 언어 선택을 통합했습니다. 기본값은 컴퓨터의 언어를 사용하고 마지막 선택을 같은 OS 사용자의 다른 프로젝트에서도 재사용합니다.
- README·변경 내역·오프라인 사용 설명서를 선택한 언어로 열 수 있게 했습니다.
- 표준 포즈 128개의 표시 이름과 각 기능 설명을 기존 용어에 맞춰 준비했습니다.

### 호환성

- 기존 아바타 설정, 자체 이름, 에셋 참조, 파라미터 식별자, 라이선스 저장 방식은 유지합니다.

## [3.1.2] - 2026-11-09

- 발 높이를 꺼도 EX 메뉴의 설정 > 바로 누울 때 머리 자동 고정에서 머리 고정을 전환할 수 있습니다. 이전 버전에서 항목이 사라진 아바타도 업데이트 후 빌드하면 복원됩니다.
- Unisaki Posing System 3.1.2를 지원합니다. 머리 회전에 의한 포즈 변형 줄이기를 사용할 때 엎드린 상태에서 일어나도 얼굴이 계속 위를 향하는 문제를 수정했습니다.

ALCOM / VCC에서 Kawaii Posing을 3.1.2로 업데이트하세요. Unisaki Posing System도 3.1.2가 필요합니다. 프리빌드를 사용했다면 프리빌드 업데이트를 누르고 씬을 저장한 뒤 아바타를 다시 빌드·업로드하세요.

## [3.1.1] - 2026-11-08

- 좌우 반전을 꺼도 활성화한 바닥 높이와 뒤척이기가 VRChat EX 메뉴의 설정에 표시됩니다.
- 이전 버전에서 포즈를 재정렬·삭제·개명해도 다리 뻗기·릴랙스·한쪽 무릎 세우기에 맞는 뒤척이기 설정을 유지합니다. 완전히 Unpack한 경우도 원래 포즈를 식별할 수 있으면 유지합니다. 자체 포즈, 직접 끈 뒤척이기, 교체한 옆으로 눕기 모션은 보존합니다.
- VRChat에서 아바타 선택 시 잠깐 엎드리는 문제를 수정했습니다. 엎드리기만 선택하고 점프할 때 잠깐 바로 눕는 문제도 수정했습니다. 점프 전환은 기능 > 편의 기능 > 점프로 누운 자세 전환에서 끌 수 있으며 기본값은 켜짐입니다.
- 업데이트 후 공통 포즈 Animator Controller 참조가 끊어지면 복구 가능한 경우 경고를 표시하고 설정에서 다시 생성합니다. 여러 아바타가 공유하는 Controller 참조도 유지합니다.
- 직접 저장한 같은 이름의 可愛いポーズ Prefab이 있어도 도구 추가 메뉴에서 공식 Prefab을 배치할 수 있습니다.
- 添い寝ツール 추가를 선택했을 때 필요한 연동 상품이 없으면 먼저 설치할 상품을 안내합니다.

ALCOM / VCC에서 Kawaii Posing과 Unisaki Posing System을 모두 3.1.1로 업데이트하세요. 프리빌드를 사용했다면 씬의 可愛いポーズ에서 프리빌드 업데이트를 누르고 씬을 저장합니다. VRChat에 반영하려면 아바타를 다시 빌드·업로드하세요.

## [3.1.0] - 2026-11-07

- 포함된 85개 포즈 중 53개에서 아바타 체형에 맞춰 손발을 IK로 자동 조정합니다.
- 바로 누운 다리 뻗기·릴랙스·한쪽 무릎 세우기에 머리 기울기 뒤척이기를 추가했습니다.
- 촬영 모드에서 위치와 방향을 조절하고 동기화와 촬영 중 자신의 머리 표시를 선택할 수 있습니다.
- 바닥 높이로 몸 전체를 위아래 최대 3m 이동하며 발 높이와 구분하여 사용할 수 있습니다.
- 호흡, 기본 대기 흔들림 끄기, 목 방향에 의한 포즈 변형 줄이기를 추가했습니다.
- Inspector에서 사용 기능·파라미터 사용량을 확인하며 검색·일괄 추가·정렬·Scene 간단 미리보기를 사용할 수 있습니다.
- 데스크톱의 서기·웅크리기·앉기 전환을 빠르게 했습니다.
- 설정 변경 후 프리빌드 경고, Inspector 스크롤 부하, 생성 데이터 정리의 긴 멈춤을 개선했습니다.
- Unisaki Posing System 3.1.0을 지원합니다.

## [3.1.0-alpha.1] - 공개 전

### 추가

- 체형에 맞춘 팔다리 자동 조정(IK)을 추가했습니다.
- IK 전체·포즈별 ON/OFF와 조정 애니메이션 저장을 추가했습니다.
- 바로 누운 다리 뻗기·릴랙스·한쪽 무릎 세우기가 머리 기울기 뒤척이기를 지원합니다.
- 포즈별 뒤척이기 설정과 옆으로 눕기 애니메이션 지정을 추가했습니다.
- 전진·회전을 조절하는 촬영 모드를 추가했습니다.
- 촬영 모드 동기화를 추가했습니다. 로컬 0 bit, 동기화 16 bit입니다.
- 촬영 중 자신의 아바타 머리를 숨기지 않는 설정을 추가했습니다.
- 머리를 포함한 몸 전체를 올리는 바닥 높이를 추가했습니다.
- 호흡 동작·강도·게임 내 ON/OFF 메뉴를 추가했습니다.
- VRChat 기본 대기 흔들림 끄기를 추가했습니다.
- 목 방향 차이에 의한 포즈 변형 줄이기를 추가했습니다.
- 무릎 역방향 굽힘 방지와 최소 굽힘 각도를 추가했습니다.
- 기능별 ON/OFF와 ExpressionParameters 사용량 표시를 추가했습니다.
- Scene 간단 미리보기, 포즈 검색, 일괄 추가, 이동 순서 지정을 추가했습니다.
- Inspector 내부 변경 내역 표시를 추가했습니다.

### 변경

- Inspector를 기능·포즈·아바타 설정의 세 탭으로 정리했습니다.
- 호흡 상세, 자체 모션 가져오기, 프리셋의 설정 위치를 정리했습니다.
- 발 높이용 생성 애니메이션의 중복을 줄였습니다.
- 포즈 이미지 업데이트 확인을 추가하고 경고 설정을 설정 확인에 모았습니다.
- 8bit 버전의 새로 추가 메뉴를 폐지하고 일반 Prefab의 기능 선택으로 통일했습니다. 기존 참조는 유지합니다.
- Unisaki Posing System 3.1.0-alpha.1을 지원하며 VRChat Avatars SDK 최소 버전을 3.10.4로 변경했습니다.

### 수정

- 포즈 이름 입력이 다른 포즈로 이동하는 문제와 정렬 시 상세가 닫히는 문제를 수정했습니다.
- 미리보기 겹침·위치 어긋남·일부 아바타의 오류를 수정했습니다.
- 설정 변경 후 경고·프리빌드 상태 갱신과 일부 빌드 오류를 수정했습니다.
