# Kawaii Posing Tool 3.2.0

Open [the English offline user guide](Documentation~/UserGuide.en.html) in a browser, or use **Manual** in the tool Inspector.

Choose **Language / 言語** at the top of the Inspector. The choice controls the editor and generated in-game menu. Re-upload the avatar to update its in-game language. Without a saved choice the tool follows the OS language.
