# Kawaii Posing

Kildekode og ressourcer til Kawaii Posing, som sælges på BOOTH.

## Vejledning og ændringshistorik

- [README: installation, opdatering og opsætning](Packages/jp.unisakistudio.kawaiiposing/Documentation~/Localization/da/README.md)
