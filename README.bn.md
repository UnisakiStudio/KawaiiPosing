# Kawaii Posing Tool

এটি BOOTH-এ বিক্রি হওয়া Kawaii Posing Tool-এর সোর্স কোড ও রিসোর্স।

- [README: ইনস্টল, হালনাগাদ ও সেটিংস](Packages/jp.unisakistudio.kawaiiposing/Documentation~/Localization/bn/README.md)
- [পরিবর্তনের ইতিহাস](Packages/jp.unisakistudio.kawaiiposing/Documentation~/Localization/bn/CHANGELOG.md)

Unity-তে পোজ টুল নির্বাচন করলে Inspector-এর উপরে ইনস্টল করা সংস্করণ দেখা যায়। ব্যবহারের নির্দেশ প্যাকেজের README-তে রয়েছে।

## এই রিপোজিটরি ও ব্যবহারের শর্ত

এই রিপোজিটরির সোর্স কোড ও রিসোর্স ওপেন সোর্স নয়। ব্যবহারের জন্য BOOTH-এ পণ্য কেনা এবং ব্যবহারের শর্তে সম্মতি দেওয়া প্রয়োজন।
